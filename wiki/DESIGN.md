# 自由发展地图：交互与文件边界

更新：2026-09-09。当前实现用于示例与讨论。

## 画布的角色

画布承载发展地图。物品、方块、文字、箭头、线条、自由虚线框、虚线画笔、3D/2D 空间和自定义展示是同层可摆放对象。章节以文字和标注表达，不预设章节容器。格点仅提供视觉参照，不参与吸附、排版或实体注册。

物品实体与画布实例分开：实体定义名称、贴图、说明、关系和状态；地图实例定义位置、尺寸及局部标注。同一实体可在不同位置和不同地图引用。

## 点击、拖动和详情

1. 指针悬停：沿实际贴图轮廓发光，并轻微抬升；不显示大卡片替代贴图。
2. 按下后移动不足 4 屏幕像素再释放：作为点击。实体弹窗以点击位置为锚点，背景变暗，原地图坐标、尺寸和视角都不改变。
3. 超过阈值：作为拖动，只改变该对象的位置。放开后不打开详情。一次拖动只产生一个撤销记录。
4. 详情支持 Markdown、图片、贴图图注、关联实体、NBT 表格、结构、模型与独立渲染。
5. 弹窗优先出现在对象下方；空间不足时贴近对象并限制在视口中，正文内部滚动。视口缩小时重新计算边界。打开动画的变换原点来自点击位置。
6. 原生 modal dialog 管理焦点和背景不可交互状态。Escape、关闭按钮或背景点击退出，焦点回到触发对象。关联实体在同一弹窗替换内容，完整档案链接进入独立页面。

查看状态与编辑状态分离：打开详情不会触发布局回流，也不写入地图文件。

## 尺寸和绘制

`屏幕坐标 = 世界坐标 × zoom + pan`。缩放以指针为中心，拖动和尺寸变化转换为世界坐标，保留小数。组件支持手柄与属性数值两种尺寸编辑方式。

实体贴图随尺寸变化，字幕保留；文字在指定范围内重排并滚动；空间组件保留视口并提供内部滚动。布局允许覆盖，组件顺序决定叠放顺序。置顶/置底与内容保存到地图。

虚线框从任意起点拖到终点，可以反向绘制。笔迹记录连续世界坐标，再转换为局部 points。标注没有“框内成员”关系，移动框不会移动里面的对象。

箭头和线条默认是自由端点；从一个对象拖到另一个对象时记录 from/to，后续端点跟随对象边缘。删除目标时先保留线条当前外观，再解除相应绑定。对象语义关系仍在实体 relations 中定义，不能从空间接近或箭头方向推导游戏配方依赖。

## 交互范围

- 画布空白：平移、缩放与绘制。
- 对象本体：选择、拖动；实体额外支持打开详情。
- 空间顶栏：拖动；空间内部：模型滑块、轨道旋转、剖层、播放等局部交互。
- 标注笔迹/边框：点击选中、拖动；框内部保持可穿透。
- 属性与组件库：独立滚动，避免触发地图手势。

键盘通过 Tab 访问工具和对象，Enter 查看实体或编辑其他组件；方向键移动，尺寸手柄的方向键调整大小；Ctrl/Cmd+Z 撤销。减少动态效果偏好关闭详情和悬停过渡。

## 视觉与观测节律

视觉基底采用深空蓝黑、灰青仪器面板、低饱和薄荷信号和少量琥珀素材色。像素用于物品轮廓、状态格和精确端点；正文使用清晰字体。细边框区分画布、控件和内容层，只有打开的实体详情获得显著明暗差。共享主题集中在 `src/visual/theme.css`，时空参考网格由 `SpaceField.tsx` 生成 SVG，放大保持清晰。

- 环境层：低亮度时空环面、缓慢轨道刻度和指针局部照明。参考线不参与对象坐标或格点吸附。
- 关联层：悬停或选中实体时，带 from/to 绑定的关系线出现定向信号；普通自由线仍保持静态标注。
- 对象层：贴图轮廓发光、精确角标、原位详情短暂展开和一次信息采集扫描。正文阅读期间不持续闪烁。
- 观测层：首次查看文件实体会留下状态点，侧栏索引按实体 ID 去重累积；波形幅度随已观测比例增强。关联跳转同样记录，重复阅读不增加计数。
- 节律控制：显示频率为 0.2–1.6 Hz，默认 0.6 Hz；波形周期为 `1 / frequency` 秒，关联信号使用同比例节律。它表示界面显示节律，不是游戏实体的物理参数。
- 暂停按钮和系统 `prefers-reduced-motion` 都关闭环境动画、悬停过渡与弹窗背景动画。移动端通过顶栏观测按钮打开相同设置。模型参数和结构操作仍由用户主动控制。

观测 ID、显示频率、动效开关只保存于当前浏览器的 `kamaen-observation-v1`。重置只清除阅读痕迹，不改变地图、笔记、实体或源文件。地图中原有颜色由 `displayInk` 在显示时调整亮度以适应暗底，保存时保留作者写入的色值。独立 HTML 渲染器使用自己的样式和交互，不隐式继承父页面状态。

## 文件契约

注册器读取固定目录，路径限制在 content 内；实体、地图、场景、模型、渲染各有类型。Schema 提供编辑辅助，运行时还会校验跨文件引用。新增已有类型的内容不需要改前端；新的独立交互可以使用自定义 HTML 渲染文件。若未来增加新的原生组件类型，则需要扩展 renderer 和校验器。

3D 当前支持文件化体素与分步关系；2D 当前支持文件化参数曲线。任意 glTF、结构 NBT 二进制、完整公式编辑器、跨组件共享运行状态尚未实现，可通过后续适配器扩展。

## 保存与恢复

API 根据已注册地图 ID 解析服务端文件路径，不接受客户端任意写入路径。读取返回 document 和内容哈希；保存必须匹配该哈希，随后原子替换文件并增加 revision。浏览器保留未保存草稿，版本不同时不直接恢复覆盖。

切换地图期间禁用编辑和导入；读取完成后才接收修改。保存期间允许后续编辑，服务端响应只标记已提交快照；较新的编辑保留为未保存状态。静态模式通过 JSON 导出回收修改。
