# 世界画布：交互与扩展约定

状态：可运行的首版示例，允许在后续讨论中修改。视觉为 Minecraft 启发的轻像素、物品槽和体素结构，不复制以撒站点外观。

## 内容组织

`物品实体 → 分组 → 章节团簇 → 发展/反馈连线`。同一物品可在多个团簇被引用，实体 ID 不因展示位置变化。E1、R4、R1 使用不同 ID 命名空间，避免相似名称被当成同一版本规则。

画布组件类型：

| 类型 | 内容 | 调整尺寸后的行为 |
| --- | --- | --- |
| cluster | 分组＋贴图 ID；可就地展开物品详情 | 图标换行，长内容滚动；点击物品时按实际内容增高 |
| text | 标题＋Markdown＋可选来源 | 文字重排，保留手动高度 |
| recipe | 引用一个候选配方 | 原料/工位/产物完整保留，内部可滚动 |
| scene | 引用一个可交互体素示意场景 | 视口根据组件宽度适配；场景操作不拖动画布 |

组件只引用实体、配方和场景，避免复制内容。布局文件可版本管理，rebuild 原文继续是设计依据。物品状态、产物数量、可达性与实际游戏实现不能由画布空间位置推断。

## 点击贴图

1. 同一团簇未展开：记录原高度，在所在分组之后插入详情。
2. 同一贴图再次点击：收起详情，恢复原高度及同列下方位置。
3. 同一团簇换另一物品：替换详情，重新测量高度，不叠加上一次的增量。
4. 不同团簇点击：各团簇可以独立保留一份详情。
5. 详情中的关联对象：优先定位现有团簇，显示对应物品；没有现成团簇才创建补充团簇。

物品名称在贴图下截断为一行；完整名称通过悬停及展开显示。小贴图用 nearest/pixelated 保持边缘，不用统一大卡片代替图像索引。

## 展开与布局

世界坐标与屏幕坐标分离：`屏幕 = 世界 × zoom + pan`。拖动/缩放组件时按缩放率还原位移，页面和3D场景各自拥有手势范围。

自动增高使用内容实际高度，保持当前组件上边缘不变。同列判定为横向投影相交（含24单位间隔）；只移动原来位于其下方的组件，传播至同列下游。负增量用于收起或切换到更短详情。手动布局允许交叠，不对全画布执行强制排版。

手动调整尺寸后暂停该组件的自动增高，保留用户指定高度并提供内部滚动。再次选择物品恢复自动测量。最小尺寸260×120，最大1400×1600，超出内容滚动阅读。

当前局限：这不是通用约束布局引擎。用户主动将两个组件拖入同一位置不会自动避让；复杂跨列嵌套关系后续可扩展空间约束。章节连线为叙事组织，不参与布局求解或科技前置判定。

## 保存与冲突

文件有独立 revision。保存只接受读取到的 revision，成功后递增。并发旧写入返回409，编辑状态保留，不静默覆盖。画布草稿先存当前浏览器；笔记草稿保留当前标签页；正式保存写固定路径。

画布打开物品与基础高度一起保存，避免刷新后只留下增高的空白组件。导出包含当前布局；静态版本需以导出文件回收修改。服务端不接受客户端指定路径。

## 可访问与动效

拖动与缩放手柄都有方向键替代，设置面板可输入尺寸。图标可聚焦，有完整名称和展开状态。顶部章节导航提供缩略图以外的键盘定位方式。保留系统减少动态效果偏好；动画主要用于详情出现、轻微悬停及反馈线流动，3D视口不强制自动旋转。

窄屏保留画布坐标，通过平移、缩放和章节定位访问内容；侧栏变为抽屉，设置面板占满可用宽度。页面本身不出现横向滚动条，单个图文表格可以有局部横向滚动。
