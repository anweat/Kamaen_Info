# Kamaen Info 完整科技树计划

版本：v0.5 Design Plan  
状态：主线科技树整合稿，结合非电信息网络、信息系统与全光计算路线修订；阶段说明见 `Kamaen_Info_Stage_Content_Line.md`，逐物品/方块开发表单见 `Kamaen_Info_Item_Block_Dictionary.md`。  

## 1. 设计总纲

Kamaen Info 的主线不是让玩家从头造一台通用计算机，也不是强制训练模型通关。主线是让玩家逐步掌握“物质、能量、信息和熵”之间的工程关系：

```text
圆石频谱
-> 白噪晶种
-> 卡玛恩晶体
-> 向量爆破与力学合成
-> 共振调谐与信息读取
-> 掺杂晶片与光路工艺
-> 共振信息自动化（频率总线、信号缓存、红石边界触发）
-> 全光计算硬件（光控制核、光协处理器、光GPU、光脉冲处理器、光RAM）
-> 世界底噪采样
-> 凝聚态费曼过程
-> 量子光学协处理器
-> 人造视界框架
-> 黑洞发电、存储、运算
-> 维度创世
```

信息学与自动化系统在主线中的定位：

- **电只做供能和边界接口，不做中游主信息媒介**：FE/电力用于驱动机器、泵浦、加热、刻蚀、退火和执行器。EDA 中允许电逻辑门作为早期接口、存储、桥接和低速控制元件，但第 6 阶段主计算路线走光逻辑；后期协处理走量子光学。自动化信息通过探针、InfoSignal、频率总线、晶体共振、光路和红石边界触发传递，不恢复旧电气 CPU/GPU/NPU 主线。
- **模型系统是可选上限**：自定义模型、算子、反馈、外部 API 可以提高良率、发现隐藏属性或优化复杂工艺，但主线材料可以通过固定工艺窗口完成。
- **卡玛恩晶体解释元件合成**：晶片、导波介质、阈值滤波片、探测结、相位调谐片、激光源、EDA 逻辑门、量子光学协处理器和视界约束材料都由卡玛恩晶体的频谱、张量、掺杂、相干性和底噪响应解释。
- **合成框架是研究站**：每个时代的关键合成不是单步配方，而是由合成框架读取结构、解释参数、调度机器并记录研究进度。

核心原则：

- **所有宏大概念落进有限系统**：不在 tick 内跑真实神经网络，不直接模拟天体级黑洞，不动态生成失控维度。
- **前期永不硬卡死**：圆石分馏与晶种获得使用确定性进度，随机只影响副产物和品质。
- **爆破是模拟加工，不是真破坏**：爆炸室和力学框架计算向量、压力和评分，不调用大范围真实爆炸。
- **晶体有统一数据模型**：频谱签名、三轴张量、应力值、掺杂浓度、噪声指数、相干度和底噪响应。
- **合成框架可扩展**：通过功能方块、传感器、结构材料、活动机构和摆放位置生成机器能力。
- **世界底噪可扩展**：底噪不是单一资源，而是一组可注册、可解释、可继续扩充的背景场层。
- **黑洞科技是汇合点**：宏观信息中心提供控制和世界数据，微观凝聚态线提供约束材料和物理过程，二者在人造视界框架汇合。

## 2. 主线分层

完整科技树分为三条交织的工程线。

### 2.1 材料与合成主线

```text
圆石分馏
-> 白噪晶种
-> 粗卡玛恩晶体
-> 偏振/稳谱/导波晶体
-> 掺杂晶片
-> 光路元件与调谐片
-> 凝聚态材料
-> 视界约束材料
-> 维度核心材料
```

### 2.2 信息与自动化支线

```text
探针读取
-> InfoSignal
-> 频率总线
-> 信号缓存与共振控制网络
-> 全光计算硬件（光控制核/光协处理器/光GPU/光脉冲处理器/光RAM、相干能、F4 光频协议落地）

-> 信息中心
-> 世界底噪数据库
-> 视界控制网络
-> 后期 WDM/长期光存储/全光网络
```

这条线只要求主线玩家达到“能够自动化生产卡玛恩相关材料”。更复杂的模型、训练、反馈、服务注册、外部 API 都是扩展玩法。

### 2.3 微观物理后期线

```text

-> 凝聚态准粒子
-> 费曼过程蓝图
-> 拓扑/隧穿逻辑链路
-> 单光子源 + SNSPD（凝聚态产物）
-> 量子光学协处理器（单光子+线性光路+后选择测量）
-> 人造视界框架
-> 黑洞发电/存储/运算
```

## 3. 合成框架总系统

合成框架是贯穿全科技树的研究站和多步骤合成控制平台。它不替代所有机器，而是读取周围结构，判断当前工艺可以达到什么精度、可观测什么参数、能执行哪些阶段。

```text
合成框架成型方块
+ 功能方块
+ 传感器方块
+ 结构方块
+ 作用器
+ 活动机构
+ 输入/输出接口
= FrameworkProfile
```

### 3.1 FrameworkProfile

框架成型后缓存一个结构画像：

```text
tier
structure_integrity
functional_modules
sensor_modules
actuator_modules
movable_modules
axis_layout
symmetry_score
field_closure
frequency_domain
precision_budget
coherence_budget
thermal_budget
parameter_channels
dynamic_control_ports
supported_processes
```

结构变化时重新扫描，运行中只读取缓存和少量动态状态。

### 3.2 方块类型

- **成型方块**：扫描结构、缓存画像、承载 GUI 和配方调度。
- **功能方块**：提供工艺能力，例如注入、刻蚀、退火、低温、相干场、隧穿耦合。
- **传感器方块**：读取应力、频谱、掺杂、温度、相干度、底噪、波函数稳定度。
- **结构方块**：提供刚性、屏蔽、热容量、频率域、拓扑边界、视界约束。
- **作用方块**：施加压力、冲击、电场、磁场、相干能、熵流抽取、视界模拟力。
- **活动粘连方块**：允许框架在合成阶段移动、夹持、旋转、压合或改变相对位置。
- **接口方块**：接收红石、频率总线、InfoSignal、物品、流体、FE、相干能和模型控制输出。

### 3.3 摆放位置规则

位置不是装饰，而是参数来源：

- 靠近中心：提高作用精度，降低作用范围。
- 轴向排列：决定加工方向和张量主轴。
- 成对对称：提高场稳定度和噪声抵消能力。
- 闭环结构：提供约束场、锁相和视界边界。
- 线路长度差：影响同步损耗和动态调参延迟。
- 传感器视线遮挡：降低读数可信度。
- 活动机构自由度：决定是否能在步骤之间改变夹角、距离和压力。

### 3.4 三层等级

| 等级 | 时代 | 解读能力 | 主线用途 |
| --- | --- | --- | --- |
| I 型力学合成框架 | 爆炸室、偏振、共振 | 向量、压力、冲击波、应力椭球、晶格对齐 | 粗晶体、偏振晶体、共振材料 |
| II 型光路工艺框架 | 掺杂、光刻、刻蚀、光学元件 | 频谱、掺杂、导波损耗、阈值、相位精度 | P/N 晶片、导波材料、探测结、相位调谐片 |
| III 型视界合成框架 | 凝聚态、底噪、费曼过程、黑洞 | 世界底噪、相干性、准粒子、拓扑、熵流、视界边界 | 高级凝聚态材料、人造视界核心、黑洞设备 |

框架可以接收外部信号并调整运行参数：


可调参数随等级和模块解锁：

```text

```

主线可以使用固定工艺窗口。可选模型系统可以通过传感器和反馈提高良率、缩短时间、发现隐藏过程或自动补偿底噪。

### 3.6 成型器范式

合成框架是最通用的研究站，但其他大型机器也可以使用同一套“成型器 + 自选方块”规则：

```text
机器成型器
+ 工艺功能方块
+ 传感器
+ 结构材料
+ 作用器
+ 输入/输出接口
= MachineProfile
```

示例：

- 爆炸室成型器：解释刚体板、缓冲层、靶座、引爆器和冲击传感器。
- 电路工艺成型器：解释光刻、刻蚀、掺杂、退火、对准传感器和洁净结构。
- 凝聚态框架成型器：解释低温、场线圈、底噪谱仪、准粒子捕获器和相干屏蔽。
- 视界框架成型器：解释约束环、熵流泵、戈古尔斯弦锚点、全息膜和紧急熄灭器。

因此实现上可以抽象出通用 `MultiblockFormer`，不同机器只提供模块白名单、位置评分规则、配方类型和运行状态机。

## 4. 阶段一：圆石频谱初炼

### 核心目标

从圆石的宽频谱中剥离基础资源，获得频谱滤渣，并把剩余物质推进到白噪均值化状态。

### 关键物品

- 圆石
- 粗频谱碎屑
- 粗频谱泥浆
- 频谱滤渣
- 铁粉、煤粉、沙子、砂砾、铜粉
- 均值化圆石
- 白噪晶种

### 机器

- **手摇频谱筛**：右键积累工作量，保障空岛局起步。
- **搅拌分馏塔**：输入圆石和水，按分馏配方积累频段积分。
- **热噪坩埚**：加热频谱滤渣，让尖锐谱线松动。
- **滤膜**：植物纤维偏向碳谱线，铁网偏向金属谱线，玻璃纤维偏向硅砂谱线。
- **初级分光镜**：显示物品频谱、峰值偏差和白噪潜势。

### 工艺流程

```text
圆石 + 水 -> 粗频谱泥浆
粗频谱泥浆 -> 基础粉末 + 频谱滤渣
频谱滤渣 + 热噪坩埚 -> 均值化圆石
均值化圆石 + 频谱滤渣 -> 白噪晶种
```

分馏使用确定性积分。连续处理相同输入会积累谱线污染，降低副产率和速度。更换滤膜、插入不同石材或升级搅拌轴可降低污染。

### 下一阶段门槛

稳定产出白噪晶种，并用初级分光镜确认均值偏差低于阈值。

## 5. 阶段二：白噪结晶与力学合成时代

### 核心目标

通过模拟爆破、应力塑形和 I 型力学合成框架制造第一代卡玛恩晶体。

### 关键物品

- 白噪晶种
- 粗卡玛恩晶体
- 裂纹晶体
- 频谱粉尘
- 理想刚体板
- 爆震粉
- 导波型卡玛恩晶体
- 抗压型卡玛恩晶体
- 稳谱型卡玛恩晶体
- 应力记录片

### 机器与多方块

- **小型爆炸室控制器**：扫描爆炸室结构并缓存向量评分。
- **理想刚体板**：模拟反射冲击波。
- **缓冲砂层**：降低向量强度，提高容错。
- **靶座**：放置晶种或晶体，记录受击方向。
- **I 型力学合成框架**：作为爆炸室的研究升级，读取冲击、压力、应力椭球和偏振方向。
- **应力传感器**：提高应力读数精度。
- **轴向压头**：提供可控压力和晶格对齐。

### 向量爆破机制

爆炸室不调用原版 `Level.explode()`。控制器在结构变化时扫描有限体积，并计算：

```text
VectorImpulse = direction + strength + waveform_purity + impulse_width
```

加工评分：

- 方向匹配度：目标向量与实际向量的点积。
- 能量匹配度：强度是否落在目标窗口。
- 波形纯净度：结构是否闭合、是否泄漏、是否过度反射。
- 应力稳定度：I 型框架额外读取晶体受击后的应力椭球。

### 晶体初始属性

```text
axis_x = waveguide
axis_y = compression_resistance
axis_z = spectrum_retention
stress
noise_index
```

### 代表配方

```text
白噪晶种 + 模拟爆破评分 >= 60 -> 粗卡玛恩晶体
粗卡玛恩晶体 + X 轴爆破 -> 导波型卡玛恩晶体
粗卡玛恩晶体 + Y 轴爆破 -> 抗压型卡玛恩晶体
粗卡玛恩晶体 + Z 轴爆破 -> 稳谱型卡玛恩晶体
粗卡玛恩晶体 + I 型框架压合 + 应力记录 -> 偏振卡玛恩晶体
失败加工 -> 裂纹晶体 / 频谱粉尘
```

### 下一阶段门槛

获得稳定的一代卡玛恩晶体，并制作晶体干涉仪读取内部张量。

## 6. 阶段三：共振调谐与信息读取

### 核心目标

把卡玛恩晶体从材料升级为可调谐的共振催化器，并开始读取世界中的类型化信息。

### 关键物品

- 一代卡玛恩晶体
- 调谐晶片
- 固有频谱样本
- 信息单元
- 共振催化晶体
- 低噪 FE 缓存
- 频率总线
- InfoSignal 封装片
- **光学元件原型（光计算前体）**：一阶光栅、衍射网格、初级波导原型（固定权重，不可重写）、初级相位调制器

### 机器

- **晶体干涉仪**：显示应力椭球、频谱签名、三轴张量。
- **频谱锁相器**：把目标物品或方块的固有频谱写入晶体。
- **卡玛恩探针台**：把可读数据转为 `InfoSignal`。
- **调谐阵列**：中心晶体，周围放样本、透镜、低噪能源节点。
- **频率转红石模块**：把 InfoSignal 输出为 0-15 红石信号。
- **光栅雕刻台（光计算前体）**：在导波晶体上雕刻一阶光栅；本阶段产出的光栅、原型波导是第 6 阶段光GPU 的工艺基础。详见 `docs/Kamaen_Info_Optical_Computing_Design.md` 第 3.1 节。

### 信息读取边界

探针不做任意反射读取。读取统一经过 capability 和 adapter：

- 方块状态
- 红石信号
- 公开方块实体 NBT 摘要
- FE 能量
- 流体
- 物品槽
- 已注册的 `IKamaenReadable` 数据

统一输出：

```text
InfoSignal = type + value + frequency_vector + confidence + timestamp
```

### 共振机制

未经调谐的晶体可自适应目标机器，但速度慢。预先锁相的晶体可立即提供高共振效率。

```text
speed = base * (1 + log1p(total_resonance) * tier_multiplier)
```

### 代表配方

```text
卡玛恩晶体 + 铁粉样本 + 频谱锁相器 -> 金属冶炼共振晶体
卡玛恩晶体 + 熔炉运行信息单元 -> 熔炉加速催化晶体
探针读取作物 age -> 生长阶段信息单元
信息单元 + 调谐晶片 -> 频率转红石模块
```

### 下一阶段门槛

玩家需要至少三类专用共振晶体，并用探针和频率总线构建一个闭环自动化控制系统。

## 7. 阶段四：掺杂晶片与光路工艺

### 核心目标

通过掺杂、退火、光刻和刻蚀制造导波材料、阈值滤波片、探测结、相位调谐片和激光源前体。电力只驱动机器与泵浦，不作为信息传递媒介。

本阶段同时建立 EDA 的基础元件库、版图概念和分级时序概念：电逻辑门片可以用于早期接口、桥接、低速控制和经典存储；光路元件用于第 6 阶段主计算；二者不能在同一裸片中无隔离混放。芯片设计应像轻量微电子/光电子设计软件：先画原理图，再进入微结构版图，放置器件、波导、互连、冷却管线和端口，并设置 F1-F5 频率域与 T0-T5 时序域。频率决定信息载体等级，时序决定信息节拍、采样、流水、刷新、相位窗口和观测窗口。DRC/时序检查通过后才能导出分层掩膜组。完整规则见 `docs/Kamaen_Info_Computing_EDA_Design.md`。

### 关键物品

- 二代卡玛恩晶体
- 施主掺杂剂
- 受主掺杂剂
- N 型卡玛恩晶片
- P 型卡玛恩晶片
- 掺杂导波晶片
- 阈值滤波片
- 卡玛恩探测结
- 相位调谐片
- 掺杂缺陷片
- 光刻掩膜
- 分层光刻掩膜组
- 微结构单元
- 时序结构单元
- 工艺防护套件
- 晶圆流片任务单
- 未封装裸片
- 晶体导波线
- 信号缓存片
- F1/F2/F3 晶振
- 相干能缓存
- 相干能稳压器
- **光学元件铺垫（光计算前置）**：硅光波导毛坯、光探测器、相位调谐器（声光/热光仅作工艺手段）、单频激光源前体（稳谱晶体腔 + F2 晶振泵浦）

### 机器与框架

- **离子注入器**：按方向将掺杂剂注入晶体。
- **晶格退火炉**：修复掺杂缺陷，降低噪声。
- **导波晶片处理台**：组合 P/N 晶片，结算导波损耗、阈值和探测响应。
- **光刻投影器**：写入光路图案。本阶段升级为「光刻精密化」（短波长曝光 + 相位掩模），服务光波导、探测结和相位调谐片制造。
- **刻蚀槽**：按图案移除材料，形成波导槽、耦合口和滤波结构。
- **相干能稳压器**：把普通 FE 与稳谱晶体的共振输出整理为低噪相干能。
- **II 型光路工艺框架**：读取掺杂、频谱、导波损耗、阈值、相位精度和泵浦稳定度。
- **信息诊断台**：输出信号质量、频率拥塞、相干噪声和结构失配。
- **光路耦合工艺台（光计算前置）**：封装光探测器与波导耦合接口；本阶段产出的光探测器、相位调谐器、激光源前体是第 6 阶段光GPU 与光协处理器的关键工艺基础。详见 `docs/Kamaen_Info_Optical_Computing_Design.md` 第 3.2 节。
- **芯片蓝图台（EDA 前置）**：提供原理图视图、微结构版图视图和时序路径视图，记录 `die_domain`、逻辑族、端口、`frequency_tier`、`timing_tier`、同步域、流水级、刷新周期、相位窗口、观测窗口、冷却口和相干接口。阶段四只开放电逻辑与基础光路元件，阶段五开始导出分层掩膜组、流片并封装为芯片/集成板。

### 掺杂数据

卡玛恩晶体数据模型扩展为：

```text
spectrum_signature
axis_tensor
stress
doping_concentration
noise_index
coherence
waveguide_axis
threshold_axis
phase_axis
```

掺杂槽位：

- 导波轴：决定光路主通道。
- 阈值轴：决定滤波与激活门槛。
- 相位轴：决定调谐精度和校准稳定性。

P/N 掺杂在本路线中用于调整折射率、阈值、探测响应和泵浦稳定度，不发展为电气计算硬件。

EDA 约束：

- 电逻辑门片只能在 `die_domain=electronic` 裸片中承担主逻辑。
- 光逻辑门、MZI、双稳态腔只能在 `die_domain=photonic` 裸片中承担主逻辑。
- 跨电/光域必须通过调制注入器、光电探测结或桥接封装连接，并显式消耗延迟、噪声和相干能预算。
- 时序必须通过 timing check 才能稳定运行；检查 T0-T5 时序等级、F1-F5 频率域、`sync_domain_id`、`sync_distance_delta`、跨域桥接、流水缓存、刷新周期、光路相位窗口和量子观测窗口，但不要求玩家做电平/阻抗/晶体管级时序收敛。

### 光路工艺流程

```text
稳谱卡玛恩晶体 -> 切片 -> 晶片坯
晶片坯 + 施主掺杂剂 + 离子注入 -> N 型卡玛恩晶片
晶片坯 + 受主掺杂剂 + 离子注入 -> P 型卡玛恩晶片
N/P 晶片 + 晶格退火 -> 掺杂导波晶片 / 阈值滤波片
掺杂晶片 + 光刻掩膜 + 刻蚀 -> 波导毛坯 / 探测结 / 相位调谐片
稳谱晶体 + 泵浦结构 + 相位调谐片 -> 单频激光源前体
```

### 中期能源

光路工艺的高精度过程需要相干能，但不要求玩家提前进入黑洞科技。相干能来自稳谱晶体对普通 FE 的低噪整理：

```text
FE + 稳谱卡玛恩晶体 + 相干能稳压器 -> 相干能缓存
相干能缓存 + II 型框架 -> 高精度掺杂 / 光刻 / 退火
```

相干能不是更大的 FE，而是更低噪、更可锁相的工艺能源。它用于调谐、掺杂、光刻、低温凝聚和视界前置约束。

### 信息自动化接入

主线只要求非电信息网络能支撑自动化生产：

- F1 控制频段：红石转换、触发器、低速 InfoSignal、小型控制器。
- F2 数据频段：传感器汇聚、信号缓存、底噪样本和信息中心查询。
- F3 调谐频段：多参数工艺调节、调谐阵列、批量采样和光路前置校准。

可选扩展包括参数库、模型内网、模型外网、服务注册和外部 API，但它们仍以 InfoSignal、频率总线和后续光路为媒介，不建立电气算力占位。详见 `docs/Kamaen_Info_Optical_Computing_Design.md`。

### 代表配方

```text
卡玛恩晶体 + 施主掺杂剂 + 离子注入器 -> N 型卡玛恩晶片
卡玛恩晶体 + 受主掺杂剂 + 离子注入器 -> P 型卡玛恩晶片
N/P 晶片 + 晶格退火 -> 掺杂导波晶片 / 阈值滤波片
掺杂晶片 + 光刻掩膜 + 刻蚀 -> 波导毛坯 / 探测结 / 相位调谐片
调谐晶片 + 信号缓存片 + F2 晶振 -> 共振信号缓存器
探针台 + 频率总线 + 红石转换模块 -> 自动化控制链
FE + 稳谱晶体 + 相干能稳压器 -> 相干能缓存
```

### 下一阶段门槛

完成卡玛恩晶片、导波材料和信号缓存的自动化生产，并能让 II 型光路工艺框架根据 InfoSignal 动态调整至少两个工艺参数。

## 9. 阶段六：全光计算

### 核心目标

将中游计算推进到全光形态。第 5 阶段的频率总线和信号缓存只负责组织信息；第 6 阶段开始由五件套全光系统执行模型计算。FE 仍用于生产机器供能，不进入计算域。物质基础：卡玛恩晶体的 χ⁽²⁾ 非线性光学特性（由第 2–3 阶段应力张量决定）。

本阶段的完整规范、配方、相干能模型、可视化方案详见 `docs/Kamaen_Info_Optical_Computing_Design.md`。全光五件套在 EDA 体系中属于 `die_domain=photonic` 的主计算工艺族；电控接口芯片只能作为外层桥接、传感器汇聚或封装测试元件。

### 关键物品（全光五件套）

**核心计算单元**：
- 光控制核（`photonic_control_core`）— 全光 FSM，承担控制、路由、脚本、调度和 I/O
- 光GPU 单元（`photonic_gpu_unit`）— MZI 网络矩阵运算（不变）
- 光脉冲处理器（`photonic_pulse_processor`）— 饱和吸收体腔；稀疏激活与非线性算子
- 光协处理器（`photonic_coprocessor`）— 光数据通路；批量搬运与互连
- 光RAM（`photonic_ram_unit`）— 受激辐射循环腔；短时状态存储

**新增基元组件**：
- 卡玛恩双稳态晶胞（`kamaen_bistable_cell`）— 光逻辑门基本存储单元
- 光逻辑门（`photonic_logic_gate`）— 可配置非线性光开关（AND/OR/NOT/NAND/XOR）
- 卡玛恩非线性介质（`kamaen_nonlinear_medium`）— 导波晶体+稳谱晶体共掺杂，提供 χ⁽²⁾

**沿用工艺组件**（不变）：
- 硅光波导（`silicon_photonic_waveguide`）
- 马赫-曾德尔调制器（`mzi_modulator`）
- 相位调谐器（`phase_tuner`，升级为声光效应版——光信号控制）
- 单频激光源（`single_freq_laser_source`）
- F4 光频晶振（`kamaen_oscillator (F4)`）

**资源**：
- 相干能（`coherent_energy`）— 维持全光路径相干；独立资源，不是 FE 子类
- 光路校准令牌（`calibration_token`）

### 机器与框架

- **卡玛恩非线性介质制备台**：导波晶体 + 稳谱晶体 → 共掺杂非线性腔（χ⁽²⁾ 基元）
- **光逻辑门封装台**：非线性介质 + 波导 + 分束器 → AND/OR/NOT 门单元
- **双稳态晶胞组装台**：两个卡玛恩共振腔 → 光学 SR 触发器（寄存器基元）
- **光控制核封装台**：晶胞阵列 + 光逻辑门阵列 + F4 光时钟 → 全光 FSM
- **光脉冲处理器封装台**：饱和吸收体腔 + 时分复用波导 → 稀疏激活处理器
- **光RAM 封装台**：受激辐射循环腔 + 部分反射镜 → 短时光存储
- **波导刻蚀台**：硅光波导毛坯 → 反应离子刻蚀 → 波导芯片（沿用）
- **MZI 编织台**：波导 + 调制器 → N×N Clements 矩形拓扑（沿用）
- **激光泵浦塔**：稳谱晶体 + F4 晶振 → 全系统相干能来源（沿用）
- **光路校准台**：重新写入 MZI 权重；消耗校准令牌 + 60 秒（沿用）
- **诊断台升级模块**：新增 `logic_error_rate`、`bistable_cell_health`、`pulse_threshold_drift`、`ram_coherence_life`（扩展原有 coherence_avg 等指标）

### 全光系统核心机制

**激发-湮灭操作周期**（五件套共同的基本操作单元）：
```
激发：光子进入卡玛恩共振腔 → 声子模式激活
传播：声子模式修改探针光子路径 → 逻辑运算发生
湮灭：声子弛豫 → 定向释放光子 → 信息读出
```

**光控制核 FSM**：F4 光时钟 → 双稳态晶胞（状态寄存器）→ 光逻辑门（组合逻辑）→ 光路由交换机（输出派发）。晶体品级决定门保真度：低品级晶体 → 随机位翻转 → 调度错误率上升。

**光GPU MZI 网络**（不变）：输入向量编码为光场 → N×N MZI 传播 → 探测器读出。权重 = 声光调谐器相位偏置（稳态）；切换权重需光路再校准。

**光脉冲处理器**：饱和吸收体腔阈值选择（稀疏激活）+ S 型传输曲线（激活函数近似）。

**光RAM**：受激辐射循环腔 → 光子循环存储 → 每次读取消耗腔内约 5–10% 光子 → 需定期刷新。

### 相干能模型（扩展版）

```text
coherent_cost =
  logic_cost × gate_count × crystal_quality_factor      ← 光逻辑层新增
  + matrix_cost × mzi_count × temperature_factor × wavelength_count × duty  ← 光矩阵层保留
```

失稳阈值：
- 光逻辑层（< 70%）：逻辑翻转错误率上升
- 光矩阵层（< 60%）：推理数值噪声
- 全系统（< 30%）：光路崩溃，所有组件暂停

### F4 光频协议落地（扩展版）

| 层 | 用途 | 需求 |
|---|------|------|
| FSM 时钟 | 光控制核 FSM 基准频率 | 1 个 F4 晶振 / 光控制核 |
| 单元内部 | 光GPU MZI 网络光路基准 | 1 个 F4 晶振 / 光GPU |
| 板级总线 | 光协处理器与各单元时钟同步 | 1 个 F4 晶振 / 光协处理器 |
| 短距集群 | 多单元间光纤互连和相位同步 | 1 个 F4 晶振 / 集群节点 |

### 可视化「看得见的信息」

- 光纤亮度对应数据率；颜色按频段（F2 绿、F3 蓝、F4 紫）
- 光GPU 表面渲染 MZI 干涉条纹快照
- **光控制核**顶面显示双稳态晶胞亮点阵列（状态寄存器实时可视化）
- **光脉冲处理器**强脉冲→橙色粒子通过；弱脉冲→暗橙粒子从侧面逸散（湮灭可视化）
- 诊断台打开「费曼描述模式」→ 各组件显示简化费曼图标注（第 7 阶段预习）
- 失稳：光纤闪烁（70%–60%）→ 暗红 + 警告粒子（< 30%）

### 下一阶段门槛

（详见 `docs/Kamaen_Info_Optical_Computing_Design.md` 第 16 章）

3. 至少 1 台光脉冲处理器处理光GPU 输出并正确输出激活值

## 10. 阶段七：凝聚态材料与费曼过程合成

### 核心目标

使用凝聚态物理思路，把卡玛恩晶体推进到准粒子、拓扑态、超导、相变和隧穿逻辑材料阶段。费曼图不作为高能物理装饰，而是作为凝聚态准粒子过程的合成语法。

本阶段同时产出**单光子源**（量子点 / 参量下转换）和**超导纳米线单光子探测器（SNSPD）**，作为第 8 阶段量子光学协处理器的前置材料。这些产物也可反过来升级第 6 阶段光GPU 的探测器，提升信噪比、降低相干能消耗。

### 费曼过程定义

```text
外线 = 输入/输出准粒子或场
顶点 = 允许的相互作用
传播子 = 中间态
闭环 = 修正项、噪声、自能
守恒约束 = 电荷、动量、频率、拓扑数、晶格对称性
```

合成评分由以下因素决定：

- 过程守恒是否成立。
- 传播子是否被框架稳定。
- 底噪层是否干扰目标过程。
- 晶格张量是否支持目标准粒子。
- 传感器是否足够观测中间态。
- 量子光学协处理器（第 8 阶段）是否提供可用模拟结果。

- 相变记忆晶体
- 准粒子滤波器
- 隧穿串联器
- 4 维电路桥

### 机器与框架模块

- **低温凝聚腔**：提供低温和相干保持。
- **准粒子捕获器**：从底噪和材料响应中捕获准粒子迹象。
- **费曼过程编译台**：把外线、顶点、传播子和约束编译成蓝图。
- **拓扑相变炉**：在可控场强中制造拓扑材料。
- **隧穿耦合器**：建立非经典邻接。
- **III 型视界合成框架雏形**：不产生视界，只提供凝聚态所需的高精度力、观测和反馈。

### 凝聚态合成流程

```text
底噪样本 + 卡玛恩晶体 -> 准粒子响应测试
准粒子响应 + 捕获器 -> 传播子片
传播子片 + 顶点片 + 守恒约束 -> 费曼过程蓝图
费曼过程蓝图 + 凝聚态框架 -> 目标凝聚态材料
```

### 代表费曼过程

```text
电子传播子 + 声子顶点 -> 电声耦合材料
电子对过程 + 低温相干场 -> 超导卡玛恩环
自旋波传播子 + 拓扑顶点 -> 自旋逻辑晶片
激子过程 + 光场顶点 -> 光电转换晶格
隧穿传播子 + 维度偏置 -> 4 维电路桥
```

### 4 维电路

普通电路依赖三维空间邻接。4 维电路通过隧穿传播子建立逻辑邻接：

```text
same_tunneling_frequency
same_topology_id
coherent_distance <= limit
background_noise < threshold
```

满足条件的两个元件即使不物理相邻，也可被框架视为逻辑相邻。它用于极高密度电路、视界控制网络和维度级合成框架。

### 模型与量子光学协处理器

主线不要求训练模型。固定费曼过程蓝图可完成主线材料。

可选玩法：

- 模型根据传感器反馈自动调整温度、场强、频率、掺杂和冷却速率（可调用第 6 阶段光GPU 加速密集矩阵推理）。
- 量子光学协处理器（第 8 阶段）通过单光子玻色采样估计波函数稳定区间、准粒子组合和相变路径。
- 高质量数据集可发现隐藏费曼过程或材料属性。

### 下一阶段门槛

制造超导卡玛恩环、拓扑绝缘晶体、隧穿串联器，并搭建至少一条可诊断的凝聚态逻辑链路。

## 11. 阶段八：量子光学协处理器与中观合成框架

### 核心目标

把量子计算定位为专用协处理器，而不是万能计算机。它只处理经典硬件难以高效枚举的微观模拟、波函数稳定、路径采样和凝聚态预测。

**物理路线**：本阶段明确量子计算的实现路径为 **单光子 + 线性光路 + 后选择测量**（玻色采样路线），与第 6 阶段经典光计算形成「经典光 → 量子光」的连续阶梯。第 7 阶段产出的单光子源、SNSPD 是本阶段的关键前置材料。

### 关键物品

- 量子光学协处理核心（原"量子协处理核心"）
- 低温控制片
- 相干控制线
- 纠缠耦合片
- 单光子干涉路径
- 波函数缓存页
- 量子误差校验片
- 准粒子路径样本
- 合成参数曲线
- 中观合成协议

### 机器

- **量子光学协处理器**（原"量子协处理器"）：接收费曼过程蓝图和材料状态，输出稳定窗口。物理实现为单光子源 + 线性光路 + SNSPD 后选择测量。
- **低温控制柜**：提供温度和噪声屏蔽。
- **波函数采样仪**：读取合成过程中的稳定度和坍缩风险。
- **误差校验阵列**：用额外材料和相干能换取更稳定的结果。
- **中观合成调度器**：把协处理器输出转成框架可执行参数曲线。

### 运行闭环

```text
传感器采样
-> 当前材料状态
-> 费曼过程蓝图
-> 量子光学协处理器估计稳定窗口（玻色采样统计）
-> 中观合成调度器生成参数曲线
-> 合成框架调整作用器
-> 新材料状态
```

### 适配限制

- 量子光学协处理器只适合微观模拟、采样和特定优化。
- 输入输出仍由经典信息中心组织（可由第 6 阶段光协处理器搬运）。
- 噪声、退相干和错误率通过低温、屏蔽、误差校验和相干能消耗表现。
- 没有合适费曼过程蓝图时，协处理器不能凭空合成新材料。

### 代表配方

```text
超导卡玛恩环 + 拓扑绝缘晶体 + 单光子源 + F4 晶振 -> 量子光学协处理核心
量子光学协处理核心 + 低温控制片 + 误差校验片 + SNSPD x4 -> 量子光学协处理器
费曼过程蓝图 + 当前材料状态 + 量子光学协处理器 -> 合成参数曲线
合成参数曲线 + III 型框架 -> 高阶凝聚态材料
```

### 下一阶段门槛

得到稳定的合成参数曲线，并用 III 型框架制造视界约束所需的凝聚态材料。

## 12. 阶段九：戈古尔斯弦与人造视界框架

### 核心目标

```text
dimension_rule
horizon_information_membrane
```

### 维度参数

| 参数组 | 内容 | 获取方式 | 风险 |
| --- | --- | --- | --- |
| 地形基底 | 高度、洞穴、浮岛比例、地表材料 | 扫描主世界/下界/末地地形 | 地形断裂、空洞过多 |

| 熵增速率 | 维护成本、方块衰变、规则漂移 | 视界能源 + 戈古尔斯弦 | 维度崩坏 |


## 16. 实现方案

核心玩法的具体开发批次、当前代码基线和验收标准见 `docs/Kamaen_Info_Core_Gameplay_Development_Plan.md`。本章只保留系统类型、代码模块和性能边界。

### 16.1 数据与配方类型

- `fractionating`：圆石分馏配方，定义输入、流体、频段积分、阈值与产物。
- `vector_blasting`：模拟爆破配方，定义目标向量、能量窗口、主产物与失败产物。
- `framework_process`：合成框架流程，定义等级、所需模块、位置约束、步骤和动态参数。
- `spectrum_tuning`：晶体调谐配方，定义样本、频谱签名与晶体输出。
- `doping`：掺杂配方，定义 P/N 型、方向、浓度和退火需求。
- `lithography`：光刻和刻蚀配方，定义掩膜、曝光、刻蚀深度、导波损耗和相位精度。
- `signal_cache_assembly`：信号缓存与频率路由配方，定义缓存寿命、频率通道、路由标签和信号质量。
- `optical_assembly`：光计算硬件配方，定义波导、MZI、调谐器、探测器、激光源的组装顺序和精度需求。
- `coherent_energy_calibration`：相干能与光路校准配方，定义校准令牌消耗、校准时长和目标相干度。
- `background_noise_sampling`：底噪采样配方，定义维度、层、采样成本和解释标签。
- `feynman_process`：费曼过程配方，定义外线、顶点、传播子、守恒约束和输出材料。
- `condensed_matter_synthesis`：凝聚态合成配方，定义目标相、温度、场强、底噪限制和框架需求。
- `quantum_optical_coprocessing`（原 `quantum_coprocessing`）：量子光学协处理任务，定义蓝图、输入状态、玻色采样统计预算和参数曲线。
- `horizon_framework`：人造视界流程，定义约束环、弦锚、熵流、稳定度和用途。
- `black_hole_operation`：黑洞发电、存储、运算配方。
- `dimension_compiling`：创世编译配方，定义世界之心、底噪数据库、规则候选和维度核心。

### 16.2 关键代码模块

- `data_component`：晶体属性、InfoSignal（含 optical_wavelengths、coherence_state 扩展字段）、FrameworkProfile、底噪样本、费曼过程蓝图、维度参数矩阵。
- `blockentity`：分馏塔、爆炸室控制器、三代合成框架、探针、信息诊断台、信号缓存器、波导刻蚀台、MZI 编织台、激光泵浦塔、光控制核、光协处理器、光GPU、光脉冲处理器、光RAM、光路校准台、底噪谱仪、费曼编译台、量子光学协处理器、视界核心、创世编译台。
- `multiblock`：有限体积扫描、结构缓存、dirty 标记、位置评分、模块识别、预算计算。
- `capability`：`IKamaenReadable`、相干能存储（独立资源，不与 FE 共用 Capability）、频率总线、框架控制端口、底噪采样接口。
- `information_network`：InfoSignal、频率总线、信号缓存、红石边界触发、信息中心和诊断报告。
- `optical_computing`：引用 `docs/Kamaen_Info_Optical_Computing_Design.md`，承担光控制核、光协处理器、光GPU、光脉冲处理器、光RAM、相干能模型、可视化渲染。
- `information`：引用信息学文档的数据类型、传感器、路由、反馈、可选模型输出。
- `client`：GUI、tooltip、频谱图、张量预览、框架结构预览、底噪图、费曼过程图、视界粒子效果、光纤亮度渲染、MZI 干涉条纹纹理、相干失稳警告粒子。
- `compat`：JEI/EMI 分类、其他 FE/流体/物品能力 adapter。
- `config`：分馏产物表、能源倍率、多方块规模上限、底噪层开关、视界输出上限、维度模板开关、相干能消耗系数。

### 16.3 性能约束

- 多方块只在结构变化时重扫。
- 合成框架运行时读取缓存画像，不每 tick 遍历完整结构。
- 爆炸室只做向量矩阵，不做真实爆炸射线。
- 探针和底噪采样都有冷却、能耗和预算。
- 信息网络与模型系统只结算抽象性能画像，不强制运行真实模型。
- 全光计算硬件（光控制核/光协处理器/光GPU/光脉冲处理器/光RAM）服务端只算抽象数值（相干度、推理次数、能耗），客户端只渲染光纤亮度、干涉条纹和粒子；不做真实光物理模拟。
- 量子光学协处理器只输出参数窗口和评分，不模拟真实量子态。
- 黑洞装置服务端只算数值，视觉放客户端。
- 维度创世优先使用预注册模板或固定槽位，避免运行时动态注册灾难。
