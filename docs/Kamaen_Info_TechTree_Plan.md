# Kamaen Info 完整科技树计划

版本：v0.3 Design Plan  
状态：主线科技树整合稿，结合 `Kamaen_Info_Hardware_TechTree_Design.md` 与 `Kamaen_Info_Information_System_Design.md` 修订。  

## 1. 设计总纲

Kamaen Info 的主线不是让玩家从头造一台通用计算机，也不是强制训练模型通关。主线是让玩家逐步掌握“物质、能量、信息和熵”之间的工程关系：

```text
圆石频谱
-> 白噪晶种
-> 卡玛恩晶体
-> 向量爆破与力学合成
-> 共振调谐与信息读取
-> 掺杂晶体管与电气合成
-> 卡玛恩硬件自动化
-> 世界底噪采样
-> 凝聚态费曼过程
-> 人造视界框架
-> 黑洞发电、存储、运算
-> 维度创世
```

信息学与硬件系统在主线中的定位：

- **硬件系统是自动化支撑**：CPU、GPU/NPU、内存、储存、通信网络主要用于自动化生产、工艺诊断、参数调节和扩展玩法。主线不强制玩家训练复杂模型。
- **模型系统是可选上限**：自定义模型、算子、反馈、外部 API 可以提高良率、发现隐藏属性或优化复杂工艺，但主线材料可以通过固定工艺窗口完成。
- **卡玛恩晶体解释元件合成**：晶体管、晶片、电路、传感器、量子协处理器和视界约束材料都由卡玛恩晶体的频谱、张量、掺杂、相干性和底噪响应解释。
- **合成框架是研究站**：每个时代的关键合成不是单步配方，而是由合成框架读取结构、解释参数、调度机器并记录研究进度。

核心原则：

- **所有宏大概念落进有限系统**：不在 tick 内跑真实神经网络，不直接模拟天体级黑洞，不动态生成失控维度。
- **前期永不硬卡死**：圆石分馏与晶种获得使用确定性进度，随机只影响副产物和品质。
- **爆破是模拟加工，不是真破坏**：爆炸室和力学框架计算向量、压力和评分，不调用大范围真实爆炸。
- **晶体有统一数据模型**：频谱签名、三轴张量、应力值、掺杂浓度、噪声指数、相干度和底噪响应。
- **合成框架可扩展**：通过功能方块、传感器、结构材料、活动机构和摆放位置生成机器能力。
- **世界底噪可扩展**：底噪不是单一资源，而是一组可注册、可解释、可继续扩充的背景场层。
- **黑洞科技是汇合点**：宏观信息中心提供控制和世界数据，微观凝聚态线提供约束材料和物理过程，二者在人造视界框架汇合。

## 2. 主线分层

完整科技树分为三条交织的工程线。

### 2.1 材料与合成主线

```text
圆石分馏
-> 白噪晶种
-> 粗卡玛恩晶体
-> 偏振/稳谱/导波晶体
-> 掺杂晶片
-> 晶体管与电路
-> 凝聚态材料
-> 视界约束材料
-> 维度核心材料
```

### 2.2 信息与自动化支线

```text
探针读取
-> InfoSignal
-> 频率总线
-> 硬件电路
-> 自动化工艺线
-> 信息中心
-> 世界底噪数据库
-> 视界控制网络
```

这条线只要求主线玩家达到“能够自动化生产卡玛恩相关材料”。更复杂的模型、训练、反馈、服务注册、外部 API 都是扩展玩法。

### 2.3 微观物理后期线

```text
世界底噪采样
-> 凝聚态准粒子
-> 费曼过程蓝图
-> 拓扑/隧穿逻辑链路
-> 量子协处理器辅助模拟
-> 人造视界框架
-> 黑洞发电/存储/运算
```

## 3. 合成框架总系统

合成框架是贯穿全科技树的研究站和多步骤合成控制平台。它不替代所有机器，而是读取周围结构，判断当前工艺可以达到什么精度、可观测什么参数、能执行哪些阶段。

```text
合成框架成型方块
+ 功能方块
+ 传感器方块
+ 结构方块
+ 作用器
+ 活动机构
+ 输入/输出接口
= FrameworkProfile
```

### 3.1 FrameworkProfile

框架成型后缓存一个结构画像：

```text
tier
structure_integrity
functional_modules
sensor_modules
actuator_modules
movable_modules
axis_layout
symmetry_score
field_closure
frequency_domain
precision_budget
coherence_budget
thermal_budget
parameter_channels
dynamic_control_ports
supported_processes
```

结构变化时重新扫描，运行中只读取缓存和少量动态状态。

### 3.2 方块类型

- **成型方块**：扫描结构、缓存画像、承载 GUI 和配方调度。
- **功能方块**：提供工艺能力，例如注入、刻蚀、退火、低温、相干场、隧穿耦合。
- **传感器方块**：读取应力、频谱、掺杂、温度、相干度、底噪、波函数稳定度。
- **结构方块**：提供刚性、屏蔽、热容量、频率域、拓扑边界、视界约束。
- **作用方块**：施加压力、冲击、电场、磁场、相干能、熵流抽取、视界模拟力。
- **活动粘连方块**：允许框架在合成阶段移动、夹持、旋转、压合或改变相对位置。
- **接口方块**：接收红石、频率总线、InfoSignal、物品、流体、FE、相干能和模型控制输出。

### 3.3 摆放位置规则

位置不是装饰，而是参数来源：

- 靠近中心：提高作用精度，降低作用范围。
- 轴向排列：决定加工方向和张量主轴。
- 成对对称：提高场稳定度和噪声抵消能力。
- 闭环结构：提供约束场、锁相和视界边界。
- 线路长度差：影响同步损耗和动态调参延迟。
- 传感器视线遮挡：降低读数可信度。
- 活动机构自由度：决定是否能在步骤之间改变夹角、距离和压力。

### 3.4 三层等级

| 等级 | 时代 | 解读能力 | 主线用途 |
| --- | --- | --- | --- |
| I 型力学合成框架 | 爆炸室、偏振、共振 | 向量、压力、冲击波、应力椭球、晶格对齐 | 粗晶体、偏振晶体、共振材料 |
| II 型电气合成框架 | 掺杂、刻蚀、晶体管、硬件 | 频谱、电荷、掺杂、导通轴、互连精度 | P/N 晶片、晶体管、电路、硬件自动化 |
| III 型视界合成框架 | 凝聚态、底噪、费曼过程、黑洞 | 世界底噪、相干性、准粒子、拓扑、熵流、视界边界 | 高级凝聚态材料、人造视界核心、黑洞设备 |

### 3.5 动态参数控制

框架可以接收外部信号并调整运行参数：

```text
redstone
frequency_bus
InfoSignal
hardware_control_node
model_output
manual_profile
```

可调参数随等级和模块解锁：

```text
pressure
temperature
impact_vector
field_strength
frequency_lock
doping_axis
doping_concentration
etch_depth
exposure_pattern
cooling_rate
coherent_energy_rate
noise_shielding
observation_strength
entropy_extraction
tunneling_phase
horizon_constraint
```

主线可以使用固定工艺窗口。可选模型系统可以通过传感器和反馈提高良率、缩短时间、发现隐藏过程或自动补偿底噪。

### 3.6 成型器范式

合成框架是最通用的研究站，但其他大型机器也可以使用同一套“成型器 + 自选方块”规则：

```text
机器成型器
+ 工艺功能方块
+ 传感器
+ 结构材料
+ 作用器
+ 输入/输出接口
= MachineProfile
```

示例：

- 爆炸室成型器：解释刚体板、缓冲层、靶座、引爆器和冲击传感器。
- 电路工艺成型器：解释光刻、刻蚀、掺杂、退火、对准传感器和洁净结构。
- 凝聚态框架成型器：解释低温、场线圈、底噪谱仪、准粒子捕获器和相干屏蔽。
- 视界框架成型器：解释约束环、熵流泵、戈古尔斯弦锚点、全息膜和紧急熄灭器。

因此实现上可以抽象出通用 `MultiblockFormer`，不同机器只提供模块白名单、位置评分规则、配方类型和运行状态机。

## 4. 阶段一：圆石频谱初炼

### 核心目标

从圆石的宽频谱中剥离基础资源，获得频谱滤渣，并把剩余物质推进到白噪均值化状态。

### 关键物品

- 圆石
- 粗频谱碎屑
- 粗频谱泥浆
- 频谱滤渣
- 铁粉、煤粉、沙子、砂砾、铜粉
- 均值化圆石
- 白噪晶种

### 机器

- **手摇频谱筛**：右键积累工作量，保障空岛局起步。
- **搅拌分馏塔**：输入圆石和水，按分馏配方积累频段积分。
- **热噪坩埚**：加热频谱滤渣，让尖锐谱线松动。
- **滤膜**：植物纤维偏向碳谱线，铁网偏向金属谱线，玻璃纤维偏向硅砂谱线。
- **初级分光镜**：显示物品频谱、峰值偏差和白噪潜势。

### 工艺流程

```text
圆石 + 水 -> 粗频谱泥浆
粗频谱泥浆 -> 基础粉末 + 频谱滤渣
频谱滤渣 + 热噪坩埚 -> 均值化圆石
均值化圆石 + 频谱滤渣 -> 白噪晶种
```

分馏使用确定性积分。连续处理相同输入会积累谱线污染，降低副产率和速度。更换滤膜、插入不同石材或升级搅拌轴可降低污染。

### 下一阶段门槛

稳定产出白噪晶种，并用初级分光镜确认均值偏差低于阈值。

## 5. 阶段二：白噪结晶与力学合成时代

### 核心目标

通过模拟爆破、应力塑形和 I 型力学合成框架制造第一代卡玛恩晶体。

### 关键物品

- 白噪晶种
- 粗卡玛恩晶体
- 裂纹晶体
- 频谱粉尘
- 理想刚体板
- 爆震粉
- 导波型卡玛恩晶体
- 抗压型卡玛恩晶体
- 稳谱型卡玛恩晶体
- 应力记录片

### 机器与多方块

- **小型爆炸室控制器**：扫描爆炸室结构并缓存向量评分。
- **理想刚体板**：模拟反射冲击波。
- **缓冲砂层**：降低向量强度，提高容错。
- **靶座**：放置晶种或晶体，记录受击方向。
- **I 型力学合成框架**：作为爆炸室的研究升级，读取冲击、压力、应力椭球和偏振方向。
- **应力传感器**：提高应力读数精度。
- **轴向压头**：提供可控压力和晶格对齐。

### 向量爆破机制

爆炸室不调用原版 `Level.explode()`。控制器在结构变化时扫描有限体积，并计算：

```text
VectorImpulse = direction + strength + waveform_purity + impulse_width
```

加工评分：

- 方向匹配度：目标向量与实际向量的点积。
- 能量匹配度：强度是否落在目标窗口。
- 波形纯净度：结构是否闭合、是否泄漏、是否过度反射。
- 应力稳定度：I 型框架额外读取晶体受击后的应力椭球。

### 晶体初始属性

```text
axis_x = waveguide
axis_y = compression_resistance
axis_z = spectrum_retention
stress
noise_index
```

### 代表配方

```text
白噪晶种 + 模拟爆破评分 >= 60 -> 粗卡玛恩晶体
粗卡玛恩晶体 + X 轴爆破 -> 导波型卡玛恩晶体
粗卡玛恩晶体 + Y 轴爆破 -> 抗压型卡玛恩晶体
粗卡玛恩晶体 + Z 轴爆破 -> 稳谱型卡玛恩晶体
粗卡玛恩晶体 + I 型框架压合 + 应力记录 -> 偏振卡玛恩晶体
失败加工 -> 裂纹晶体 / 频谱粉尘
```

### 下一阶段门槛

获得稳定的一代卡玛恩晶体，并制作晶体干涉仪读取内部张量。

## 6. 阶段三：共振调谐与信息读取

### 核心目标

把卡玛恩晶体从材料升级为可调谐的共振催化器，并开始读取世界中的类型化信息。

### 关键物品

- 一代卡玛恩晶体
- 调谐晶片
- 固有频谱样本
- 信息单元
- 共振催化晶体
- 低噪 FE 缓存
- 频率总线
- InfoSignal 封装片

### 机器

- **晶体干涉仪**：显示应力椭球、频谱签名、三轴张量。
- **频谱锁相器**：把目标物品或方块的固有频谱写入晶体。
- **卡玛恩探针台**：把可读数据转为 `InfoSignal`。
- **调谐阵列**：中心晶体，周围放样本、透镜、低噪能源节点。
- **频率转红石模块**：把 InfoSignal 输出为 0-15 红石信号。

### 信息读取边界

探针不做任意反射读取。读取统一经过 capability 和 adapter：

- 方块状态
- 红石信号
- 公开方块实体 NBT 摘要
- FE 能量
- 流体
- 物品槽
- 已注册的 `IKamaenReadable` 数据

统一输出：

```text
InfoSignal = type + value + frequency_vector + confidence + timestamp
```

### 共振机制

未经调谐的晶体可自适应目标机器，但速度慢。预先锁相的晶体可立即提供高共振效率。

```text
speed = base * (1 + log1p(total_resonance) * tier_multiplier)
```

### 代表配方

```text
卡玛恩晶体 + 铁粉样本 + 频谱锁相器 -> 金属冶炼共振晶体
卡玛恩晶体 + 熔炉运行信息单元 -> 熔炉加速催化晶体
探针读取作物 age -> 生长阶段信息单元
信息单元 + 调谐晶片 -> 频率转红石模块
```

### 下一阶段门槛

玩家需要至少三类专用共振晶体，并用探针和频率总线构建一个闭环自动化控制系统。

## 7. 阶段四：掺杂晶体管与电气合成时代

### 核心目标

通过掺杂、退火、刻蚀和互连制造卡玛恩晶体管，建立电气时代的自动化硬件生产。

### 关键物品

- 二代卡玛恩晶体
- 施主掺杂剂
- 受主掺杂剂
- N 型卡玛恩晶片
- P 型卡玛恩晶片
- 卡玛恩 PN 结
- 卡玛恩二极管
- 卡玛恩晶体管
- 掺杂缺陷片
- 光刻掩膜
- 晶体互连线
- 基础 CPU 模块
- 基础 GPU/NPU 元函数单元
- 内存页、参数页、状态页
- F1/F2/F3 晶振
- 相干能缓存
- 相干能稳压器

### 机器与框架

- **离子注入器**：按方向将掺杂剂注入晶体。
- **晶格退火炉**：修复掺杂缺陷，降低噪声。
- **晶体管装配台**：组合 P/N 晶片。
- **光刻投影器**：写入电路图案。
- **刻蚀槽**：按图案移除材料，形成互连和门结构。
- **相干能稳压器**：把普通 FE 与稳谱晶体的共振输出整理为低噪相干能。
- **II 型电气合成框架**：读取掺杂、电荷、频谱、互连精度和导通方向。
- **硬件诊断台**：引用硬件文档的性能画像，用于指出生产线瓶颈。

### 掺杂数据

卡玛恩晶体数据模型扩展为：

```text
spectrum_signature
axis_tensor
stress
doping_concentration
noise_index
coherence
gate_axis
cutoff_axis
feedback_axis
```

掺杂槽位：

- 导通轴：决定能量主通道。
- 截止轴：决定信息门控方向。
- 反馈轴：决定比较、锁存和延迟行为。

P 型适合信息门控，N 型适合能量传输，PN 结用于二极管、阈值门、过滤器和晶体管阵列。

### 电气工艺流程

```text
稳谱卡玛恩晶体 -> 切片 -> 晶片坯
晶片坯 + 施主掺杂剂 + 离子注入 -> N 型卡玛恩晶片
晶片坯 + 受主掺杂剂 + 离子注入 -> P 型卡玛恩晶片
N 型晶片 + P 型晶片 + 晶格退火 -> 卡玛恩 PN 结
PN 结 + 光刻掩膜 + 刻蚀 -> 卡玛恩二极管 / 晶体管
晶体管 + 晶体互连线 + 封装 -> 硬件模块
```

### 中期能源

电气时代的高精度工艺需要相干能，但不要求玩家提前进入黑洞科技。相干能来自稳谱晶体对普通 FE 的低噪整理：

```text
FE + 稳谱卡玛恩晶体 + 相干能稳压器 -> 相干能缓存
相干能缓存 + II 型框架 -> 高精度掺杂 / 光刻 / 退火
```

相干能不是更大的 FE，而是更低噪、更可锁相的工艺能源。它用于调谐、掺杂、光刻、低温凝聚和视界前置约束。

### 硬件系统接入

主线只要求硬件能支撑自动化生产：

- F1 控制频段：红石转换、触发器、低速 InfoSignal、小型控制器。
- F2 数据频段：模型内网、内存页、参数页、小模型部署、主板基础通信。
- F3 矩阵/激活频段：高吞吐算子、批处理、工艺预测和量子协处理器前置。

可选扩展包括 CPU/GPU/NPU 蓝图、参数库、模型内网、模型外网、训练集群、服务注册和外部 API。

### 代表配方

```text
卡玛恩晶体 + 施主掺杂剂 + 离子注入器 -> N 型卡玛恩晶片
卡玛恩晶体 + 受主掺杂剂 + 离子注入器 -> P 型卡玛恩晶片
```

## 9. 阶段六：凝聚态材料与费曼过程合成

### 核心目标

使用凝聚态物理思路，把卡玛恩晶体推进到准粒子、拓扑态、超导、相变和隧穿逻辑材料阶段。费曼图不作为高能物理装饰，而是作为凝聚态准粒子过程的合成语法。

### 费曼过程定义

```text
外线 = 输入/输出准粒子或场
顶点 = 允许的相互作用
传播子 = 中间态
闭环 = 修正项、噪声、自能
守恒约束 = 电荷、动量、频率、拓扑数、晶格对称性
```

合成评分由以下因素决定：

- 过程守恒是否成立。
- 传播子是否被框架稳定。
- 底噪层是否干扰目标过程。
- 晶格张量是否支持目标准粒子。
- 传感器是否足够观测中间态。
- 量子协处理器是否提供可用模拟结果。

### 关键物品

- 准粒子晶格
- 声子传播子片
- 电子传播子片
- 激子传播子片
- 自旋波传播子片
- 库珀对种子
- 费曼顶点片
- 费曼过程蓝图
- 拓扑绝缘晶体
- 超导卡玛恩环
- 相变记忆晶体
- 准粒子滤波器
- 隧穿串联器
- 4 维电路桥

### 机器与框架模块

- **低温凝聚腔**：提供低温和相干保持。
- **准粒子捕获器**：从底噪和材料响应中捕获准粒子迹象。
- **费曼过程编译台**：把外线、顶点、传播子和约束编译成蓝图。
- **拓扑相变炉**：在可控场强中制造拓扑材料。
- **隧穿耦合器**：建立非经典邻接。
- **III 型视界合成框架雏形**：不产生视界，只提供凝聚态所需的高精度力、观测和反馈。

### 凝聚态合成流程

```text
底噪样本 + 卡玛恩晶体 -> 准粒子响应测试
准粒子响应 + 捕获器 -> 传播子片
传播子片 + 顶点片 + 守恒约束 -> 费曼过程蓝图
费曼过程蓝图 + 凝聚态框架 -> 目标凝聚态材料
```

### 代表费曼过程

```text

电子对过程 + 低温相干场 -> 超导卡玛恩环
自旋波传播子 + 拓扑顶点 -> 自旋逻辑晶片
激子过程 + 光场顶点 -> 光电转换晶格
隧穿传播子 + 维度偏置 -> 4 维电路桥
```

### 4 维电路

普通电路依赖三维空间邻接。4 维电路通过隧穿传播子建立逻辑邻接：

```text
same_tunneling_frequency
same_topology_id
coherent_distance <= limit
background_noise < threshold
```

满足条件的两个元件即使不物理相邻，也可被框架视为逻辑相邻。它用于极高密度电路、视界控制网络和维度级合成框架。

### 模型与量子协处理器

主线不要求训练模型。固定费曼过程蓝图可完成主线材料。

可选玩法：

- 模型根据传感器反馈自动调整温度、场强、频率、掺杂和冷却速率。
- 量子协处理器估计波函数稳定区间、准粒子组合和相变路径。
- 高质量数据集可发现隐藏费曼过程或材料属性。

### 下一阶段门槛

制造超导卡玛恩环、拓扑绝缘晶体、隧穿串联器，并搭建至少一条可诊断的凝聚态逻辑链路。

### 核心目标

把量子计算定位为专用协处理器，而不是万能计算机。它只处理经典硬件难以高效枚举的微观模拟、波函数稳定、路径采样和凝聚态预测。


## 15. 实现方案

### 15.1 数据与配方类型

- `fractionating`：圆石分馏配方，定义输入、流体、频段积分、阈值与产物。
- `vector_blasting`：模拟爆破配方，定义目标向量、能量窗口、主产物与失败产物。
- `framework_process`：合成框架流程，定义等级、所需模块、位置约束、步骤和动态参数。
- `spectrum_tuning`：晶体调谐配方，定义样本、频谱签名与晶体输出。
- `doping`：掺杂配方，定义 P/N 型、方向、浓度和退火需求。
- `lithography`：光刻和刻蚀配方，定义掩膜、曝光、刻蚀深度和互连结果。
- `hardware_assembly`：硬件模块配方，定义晶体管、晶振、内存页和性能画像。
- `background_noise_sampling`：底噪采样配方，定义维度、层、采样成本和解释标签。
- `feynman_process`：费曼过程配方，定义外线、顶点、传播子、守恒约束和输出材料。
- `condensed_matter_synthesis`：凝聚态合成配方，定义目标相、温度、场强、底噪限制和框架需求。
- `quantum_coprocessing`：量子协处理任务，定义蓝图、输入状态、预算和参数曲线。
- `horizon_framework`：人造视界流程，定义约束环、弦锚、熵流、稳定度和用途。
- `black_hole_operation`：黑洞发电、存储、运算配方。
- `dimension_compiling`：创世编译配方，定义世界之心、底噪数据库、规则候选和维度核心。

### 15.2 关键代码模块

- `data_component`：晶体属性、InfoSignal、FrameworkProfile、底噪样本、费曼过程蓝图、维度参数矩阵。
- `blockentity`：分馏塔、爆炸室控制器、三代合成框架、探针、硬件诊断台、底噪谱仪、费曼编译台、视界核心、创世编译台。
- `multiblock`：有限体积扫描、结构缓存、dirty 标记、位置评分、模块识别、预算计算。
- `capability`：`IKamaenReadable`、相干能存储、频率总线、框架控制端口、底噪采样接口。
- `hardware`：引用硬件文档的性能画像、频率等级、CPU/GPU/NPU 模块和诊断报告。
- `information`：引用信息学文档的数据类型、传感器、路由、反馈、可选模型输出。
- `client`：GUI、tooltip、频谱图、张量预览、框架结构预览、底噪图、费曼过程图、视界粒子效果。
- `compat`：JEI/EMI 分类、其他 FE/流体/物品能力 adapter。
- `config`：分馏产物表、能源倍率、多方块规模上限、底噪层开关、视界输出上限、维度模板开关。

### 15.3 性能约束

- 多方块只在结构变化时重扫。
- 合成框架运行时读取缓存画像，不每 tick 遍历完整结构。
- 爆炸室只做向量矩阵，不做真实爆炸射线。
- 探针和底噪采样都有冷却、能耗和预算。
- 硬件与模型系统只结算抽象性能画像，不强制运行真实模型。
- 量子协处理器只输出参数窗口和评分，不模拟真实量子态。
- 黑洞装置服务端只算数值，视觉放客户端。
- 维度创世优先使用预注册模板或固定槽位，避免运行时动态注册灾难。
