# Visualization Options

## Obsidian

Best for readable project notes and conceptual links. It is useful for curated graphs like this vault.

## Gephi

Best for large exported graphs and layout experiments.

## Cytoscape

Best for network analysis, filtering, and attribute-rich graph exploration.

## Neo4j Browser or Bloom

Best when the graph should be queryable as data, especially if CodeGraph exports nodes and edges to CSV.
