## 1. 每一步独立建模，因子不能全部变成倍率

| 模型层 | 自己负责的数据 | 向下一层提供什么 | 接收的外部影响 |
| --- | --- | --- | --- |
| 材料与工序 | 组成/区域、取向、残余结构、工序历史和实际批次 | 可用于器件模型的真实状态与已测范围 | 本次加工的加载、温度、药剂和实际留存 |
| 器件响应 | 实际端口、响应函数、功能结构、所需供给、内部状态 | 各端口行为、可调范围、容量和合法工作条件 | 接触/加载、入射方向、输入信号及环境 |
| 组合与封装 | 实际内部件、安装变换、局部路径、外部端口、封装条件 | 有明确边界的组件模型和安装接口 | 主板socket、夹持、供能与散热 |
| 主板 | 槽位、已安装件、数据/控制/供能路径、区域和外露端口 | 具体执行单元、本地内存、板口与共享通路 | 机柜供给、托盘姿态、背板和环境 |
| 机柜 | 托盘/板、背板、面板、供能冷却回路、检修空间 | 可调度板与实际对外路径，逐回路故障范围 | 世界位置、管线、邻接设备和运行负载 |
| 集群/任务 | 已注册节点、物理链路、数据位置、任务需求和预约 | 路径与节点上的实际执行计划/时间线 | 节点状态、端口能力、共享资源与任务输入 |

上表是模型职责，不增加六套需要玩家手工填的工程表。默认沿实验台→封装→装板→上架展开，每次只显示当前需要的选择。

“因子”建议至少分为以下种类：

| 种类 | 例子 | 怎样组合 |
| --- | --- | --- |
| 状态变换 | 退火松弛应力、加工改变接触 | 按实际工序依次更新；顺序一般不可交换 |
| 空间映射 | 器件装入封装、主板装入托盘 | 逐层转换位置、朝向和尺寸单位；不乘成质量分 |
| 响应变换 | 选频、相位、门控、光电读出 | 使用对应端口/信号模型；相干合并与强度传输分别处理 |
| 资源与时间 | 算子工作量、装载字节、延迟、供能和冷却 | 按实际需求求和、按共享容量预约，单位必须一致 |
| 硬条件 | 端口不可达、类型不兼容、缺供给、工作窗越界 | 先判是否能运行；其他优点不能抵消硬失败 |
| 观测与不确定性 | 测量误差、未校准范围、共同参考偏差 | 随来源和条件传递；不能把相关误差默认当独立噪声消掉 |

一次影响至少能说明：来源对象/版本、作用目标、值或函数及单位、适用条件、已经覆盖的物理贡献。来源和边界是诊断及避免重复计费所需的信息，不是新增的玩家道具。

### 1.1 一次真实影响怎样跨层传递

```text
装配工序产生接触偏差
→ 改变对应器件/接口的有效传输或读出范围
→ 封装测试得到指定外部端口的可用条件
→ 主板选择兼容接口、节拍与数据精度
→ 机柜为该板提供实际供给和外部路径
→ 集群检查任务能否使用这条路径与能力
```

若板卡发热又导致光路漂移，则是反向运行影响：负载→热状态→下一时刻器件条件→校准/降载→新的负载。候选运行规则采用明确时间步与状态更新；不在同一次求值中无限递归重算整个工厂。需要稳态估算时另用有上限的规划求解，并保留未收敛状态。

## 2. 五种不同的“方向”

| 概念 | 归属 | 影响什么 |
| --- | --- | --- |
| 晶体轴向 | 材料自身的局部参考系 | 给定输入、场和加载相对于晶轴的响应 |
| 安装姿态 | 子件相对于父件的位置/旋转 | 占地、端口位置、接触、线路与环境关系 |
| 端口外法线 | 端口所在表面 | 朝哪一侧对接，是否有接头与路径空间 |
| 信号流向 | 端口功能 | input/output/duplex；旋转物体不会把输出改成输入 |
| 通道基准 | 对应信号及其参考 | 载频/频带、相位参考、时钟域或包协议；不是外观朝向 |

例如，一颗晶体在夹具中转动，会改变它相对入射路径和加载的关系；整块封装连同内部源、路径一起刚体旋转，内部相对关系可以保持。若世界中的场、重力加载、外部光路或冷却方向没有一起转，则仍需重新评估那些外部关系。

不能把“朝北”“X轴”直接设为某种计算加成，也不能把端口朝向用于判断数据是正向还是反向流动。

## 3. 从晶体到机柜，保留逐层参考系

候选层次如下；不要求所有对象都用相同长度单位：

```text
晶体局部轴
→ 器件结构/实验装配参考系
→ 封装参考系
→ 主板参考系
→ 托盘/机柜参考系
→ 世界坐标
```

每次安装记录子件相对于父件的变换，端口再有自己的局部位置和法线。示意关系：

```text
父系位置 = 平移 + 尺度换算 * 旋转 * 子系位置
父系端口法线 = 旋转 * 子系端口法线
```

法线不按长度尺度放大；初版候选仅支持正的均匀尺度换算与明确旋转。镜像不是普通旋转，涉及不同结构时需要专门设计/制造路径。槽位可以限定允许的安装姿态，不能因为世界支持旋转方块就让任意封装插进任意socket。

物理单位换算与界面放大分开。芯片编辑视图放大十倍不会把内部光路变长；内部路径在自身物理/游戏模型尺度内结算，上层按封装外形和外部接口装配。微型化改变实际结构与工艺，不能通过修改显示缩放或安装变换免费完成。

材料应力与响应仍在有明确基准的参考系中解释。只改变世界摆放，不重新随机生成局部材料状态。装配后如新增外部加载，先把加载方向转换到材料参考系，再由已有材料模型处理。

### 3.1 图元位置与物理位置的边界

R3的简化操作继续保留：无需玩家重复绘制原理图和微结构图。但**真实装配位置必须保留**，用于占地、接口、路径、区域与维护判断。

- 实验台上的实际夹具、晶体和接口有真实局部位置与姿态。
- 示意图、折叠模型图和注释的排版位置只用于查看，不额外决定物理损耗。
- EDA/封装工具从实际装配及选定制造模板取得结构，提供“装到这张板/这个槽位”的预览。
- 真实线路按其路径结算；不能同时对示意图距离和同一条实体线重复扣成本。
- 默认只有明确连接或登记的邻近耦合规则产生信号作用；不会因为两个图元靠近就偷偷串联。

从示意视图切换到物理装配时，要生成或选择实际结构和路径，不能通过切换视图绕过占地/连通约束。

## 4. 端口怎样适配到下一层

端口的候选数据按玩家能理解的含义分组，不先冻结接口字段：

| 分组 | 必须说明的内容 |
| --- | --- |
| 物理接口 | 所属对象、局部位置/外法线、连接头/接触形式、键位与接线空间 |
| 载体与职责 | 电、光、共振等载体；供能、控制、数据、参考等用途 |
| 信号表示 | 电平/样本、光强、相干场、已编码数据包等 |
| 方向与兼容性 | 输入/输出/双向、协议、选定频带、允许的数据类型或shape |
| 运行条件 | 吞吐/采样窗口、所需供给、参考、温度与有效精度范围 |

“可以直接相连”至少要满足位置/对接关系、流向、载体、信号表示、选定通道及工作条件。适配器可以建立一段新路径；没有适配器时，不能拿一个较低的质量系数代替实际缺失的连接。

### 4.1 五种适配不能互相替代

| 适配 | 实际完成的事情 | 实体与代价 |
| --- | --- | --- |
| 机械转接 | 适应封装尺寸、键位与固定方式 | 转接座/托盘，占体积和安装空间 |
| 方向/线路转接 | 把一个位置的端口引到另一位置 | 实际互连、弯折/接头、背板路径与相应损耗/容量 |
| 载体转换 | 电样本编码成光信号，或光信号读出 | 调制、探测、读出/恢复结构及供给，必要时有参考与校准 |
| 时序/协议适配 | 缓存、重定时、组包/解包或服务转换 | 有实际容量和处理能力的接口模块 |
| 环境适配 | 把不同工作要求放在可维持的区域 | 热界面、隔离、稳定供给、必要的温控/参考设施 |

重命名端口只改变逻辑名称，不移动接头；改变公开端口绑定必须检查真实路径。机械上能插入，也不代表协议和信号表示能够通用。

### 4.2 逐级引出保持一条可追溯的连接

```text
器件输出口
→ 封装内部互连或已安装桥接
→ 封装外部端口
→ 主板socket/线路
→ 主板边缘接口
→ 托盘转接/机柜背板
→ 机柜面板
→ 世界线缆/交换设备
→ 目标节点对应路径
```

每一段都能定位具体对象。板的一个口没有引出，就不能因为机柜面板还剩空孔而被视为已联网；面板端口数量也不增加芯片实际可提供的通道数。

## 5. 光电组合按实际信号与结构设计

### 5.1 都是“光口”，也可能不能直接互换

| 路径 | 承载内容 | 必要适配与注意点 |
| --- | --- | --- |
| 电控制/数字数据 | 门控、参数、命令、数字样本 | 与FE供能分开；数字样本不是未经编码的光场 |
| 光强通道 | 规定编码下的强度/模拟量 | 量程、噪声、读出与采样条件 |
| 相干光路 | 相对于参考的幅度/相位关系 | 匹配的源、路径、模式/波段与校准范围；普通光强调节不等于完整相位控制 |
| 光纤包链路 | 经收发器编码的数据包 | 实际收发、协议与带宽；包接收再编码不承诺保留原模拟光场的相位 |

量子态与其测量接口留在后期独立定义，不能因载体也叫光就接入普通复制/广播网络。

一个具体混合计算路径：

```text
电域输入/参数
→ 驱动与编码结构
→ 晶体光学阵列
→ 对应探测/读出结构
→ 电域的判断、状态或下一段运算
```

若任务使用相位编码，编码端需对应参考与调制能力；要读出相位信息，读出端也需相应参考/测量结构。普通强度探测不能被标成任意相位读取器。脚本、模型端口的类型声明不能补足这些硬件。

### 5.2 三个组合尺度

| 尺度 | 开放的设计 | 约束 |
| --- | --- | --- |
| 实验结构/模块 | 在同一台上连接实际电门控、光路径、读出、参考和状态模块 | 各模块独立成立，显式跨域与供给；作为最初混合设计入口 |
| 混合封装/主板 | 把已测模块或裸片装到共同载板，缩短已知路径 | 机械占用、接口、支持的桥接、温控/供给区域与维护 |
| 更高集成制造 | 已研究模板将某些电光结构集成制造 | 使用具体工艺兼容组合；不能因勾选“混合芯片”就越过所有制程要求 |

旧稿按单一die_domain硬性拆分、同时又放入storage/bridge角色的枚举不再作为统一判断。制造族、功能角色、工作环境分轴记录。某些工艺支持一体制造，某些需要分片封装，是否允许由实际模板/结构与条件决定。

普通经典光器件也不统一要求低温或大隔离槽。只有对应器件明确提出环境要求时，才需要相关空间和设施；高发热电区是否影响邻近光路，由实际热路径与漂移模型判断。

### 5.3 参数、参考和数据可以走不同路径

光阵列的参数写入、日常输入数据、相位参考和供能不是一根万能光线。早期可用明确的多口模块把它们组织起来；后期支持复用时，须有实际复用/分离及调度能力。

组件封装若已经包含编码/读出，其材料、成本和能力在该边界计入；主板只补外部缺项。更换外部参考或输入编码，需检查已有封装是否兼容。

## 6. 物理方位怎样影响机柜和集群

| 设计选择 | 局部影响 | 向后传递的结果 |
| --- | --- | --- |
| 光口朝后，外部数据面板在前 | 是否有实际引出路径；与局部参考源的相对位置 | 转接件、路径长度、可用端口与维护空间 |
| 板卡旋转/换托盘 | 插槽键位、边缘口位置、冷热接口与供给方向变化 | 重新检查背板连接及受影响回路；不能只复制原资源摘要 |
| 光路径靠近发热区 | 条件变化后响应/校准可能漂移 | 任务暂停、校准开销或降载，仍需追到该器件和热源 |
| 多板共享一条背板/上联 | 流量竞争同一实体段 | 总能力不能当成每块板都能同时独占的能力 |
| 旋转整座机柜 | 外部端口、管线、检修面和环境关系变化 | 实体网络重验；内部相对结构不自动重制 |
| 搬到另一个场地 | 世界链路长度、供给、散热、无线覆盖等变化 | 根据新路径/条件重新调度，芯片数学功能与原料身份保持 |

集群使用稳定的对象/端口身份和实际连接图；地址不是一个只能对应旧坐标的字符串。位置变化可能使连接失效，但不能让任务悄悄连到碰巧占据原坐标的另一个设备。

普通包网络关心实际链路、协议、队列和到达时间，不要求全网维持模拟光学相位。相干光学实验/阵列的参考关系只对它真实依赖的物理子网生效。包网络上的一个长数据跳转，不直接计为芯片内部的相位路径差。

主板的多个本地存储仍分别属于实际控制与地址空间；机柜或集群汇总容量不把未连接的内存合成一块可直接寻址内存。

## 7. 一块混合卡怎样逐步上架

这个例子沿用现有主板/机柜内容，不冻结R2.1小柜的尺寸与全部槽位。光电模块、载板、接头与背板均需实际制造。

### 7.1 实验与封装阶段

在实验台上验证“电样本→编码→小光学阵列→读出→电门控/状态”。先标记三个不同接口：

- 数字数据/控制接口：来自本地板或收发器。
- 光学参考接口：连接所选映射需要的参考结构。
- 供给接口：供能与散热/稳定条件。

封装预览显示它们位于哪一面、占多少空间、哪些允许转接。内部源/读出已集成的封装不再次要求外部购买相同部分；未集成则明确列为装机条件。

### 7.2 主板阶段

玩家将封装放入兼容槽，选允许的朝向，并连接实际存储、控制和外部网络接口。视图叠加数据、参考/光路、供能/散热三组路径；它们是同一实际板的查看层，不是三份需要重复设计的独立图。

若光参考口靠近柜内参考源，参考路径可能更容易维持；若网络口因此背向面板，则要实际引出数据。玩家可以旋转模块、改板口布置，或使用有容量限制的转接模块，比较对应代价。

### 7.3 机柜阶段

把板装入托盘，依次检查机械姿态→接口对接→供给→实际通信与工作窗。板口与背板相向但错位，或同位却接头/信号不同，都不能直接连通。

作为示例：一个方向转接路径只支持16 B/tick，而两端各支持64 B/tick，最终该串联数据路径上限仍为16。转接恢复了连通，不保证保留两端峰值。具体数值是讨论假设，不是所有转接件的固定规格。

可供玩家比较的方案是直接对接、加转接、改板图或换托盘位置。第一项只需可用；后续批量任务才推动更好的空间与路径安排。

### 7.4 集群阶段

第二张卡上架后，先确认各自本地任务，再比较同时执行。若两份各64 B数据共用64 B/tick上联，忽略其他阶段也至少需要2 tick传输；端口摘要不能给每张卡都单独预留整条链路。

任务时间线能从等待回溯到共享上联、面板、背板、板口及具体转换模块。玩家按诊断改正确的层，不必因为网络慢就重新加工晶体。

## 8. 因子如何结算且不重复

### 8.1 测试报告要声明覆盖边界

例如，封装输入到输出的报告已包含编码器、阵列和读出。如果上层采用这个报告，就只追加封装外部的贡献；若展开内部模型，则改用对应内部路径，不再同时叠加整块封装报告。

另取一个同载体的全光被动强度传输例子：内部包含输入耦合、选频区域与输出耦合，不含有源编码或光电读出。固定频率/工况下：

```text
展开：0.9 × 0.8 × 0.9 × 外部0.95 = 0.6156
封装报告：已含内部三项的0.648 × 外部0.95 = 0.6156
```

再次乘内部0.9属于重复计入，应被拒绝。该示例仅为不含相干分支的无源强度路径；相干合并用相应响应模型，有源光电转换以编码/读出和供给模型结算，不能盲乘这些数值。

### 8.2 条件改变后重求适用贡献

原报告在旧环境下有效，温度/加载改变时，应检查模型是否支持在新条件下推算或需要复测。不能把新的完整损耗再乘到已经包含旧损耗的报告上。外部热模型提供实际温度，器件模型据此更新响应；主板再扣一遍“光路过热分”会重复惩罚同一原因。

校准只对其绑定的器件、映射、参考与工作条件有效。只改显示名称不让校准失效；整体刚体旋转而相关相对条件未变，也不无条件丢弃全部内部校准。实际光路、相对方向、接触或相关环境变了，才按影响范围处理。

### 8.3 不同量各用自己的规则

- 串联传输率受瓶颈限制，多个任务按共享资源预约；不把“每端口上限”求和当每条任务的独享带宽。
- 串行必经延迟可累加；并行执行要看依赖/等待与共享资源，不把所有数都相加或全部取最小。
- 功率与热负载来自正在运行的实际部件/任务，分配到真实回路。
- 误差由具体变换传播；线性阶段可用声明的增益与误差界，只有确知独立时才采用独立噪声假设。
- 硬失败优先排除路径或执行域，不允许高散热或高算力补偿未连接的端口。

## 9. EDA保留什么工作

本轮中的EDA是实验结构到制造/装机的辅助工具，主要提供：

1. 记录实际组合、相对姿态与端口关系，折叠/展开查看同一结构。
2. 选择已掌握的封装/制造映射，展示实际外形、接口与所需材料。
3. 在目标主板/机柜投影里试装，标出姿态、空间、对接和环境冲突。
4. 生成或调整有限的实际引出路径，并显示需要的转接件和代价。
5. 保存可复用模板；制造与装机后以真实对象复测，版本差异可追溯。

玩家的主要动作保持为放、转、接、调、测。坐标变换、范围检查与贡献追踪由系统完成；复杂性体现为可观察的构筑选择，不重新要求手工录入矩阵、逐引脚抄表或通用微结构设计才能开局。

## 10. 本轮校验与下一步

[有限适配检查](R3_HARDWARE_ADAPTATION_PROBE.md)给出21项指定例子：层级坐标、旋转与流向、端口条件、光电转换、参考需求、贡献覆盖和共享路径等。它没有实现碰撞寻路、完整热耦合、光电数值转换或Minecraft执行；也没有证明任意装配都会可运行。

本轮把数据模型的边界与传递关系具体化，并补上器件→封装→板→柜→集群的空间和接口链。R3.3继续展开同一条混合卡任务的环境诊断、理线与持续运行；具体尺寸、端口模板和逐项配方数量仍待局部设计，不因新增工程关系而视为已经冻结。
