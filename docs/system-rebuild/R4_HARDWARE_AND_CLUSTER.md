# R4：芯片制造、硬件装配、机柜与集群

2026-09-07，当前阶段候选。入口：[总案](R4_STAGE_DESIGN.md)；全部候选投入/产出见[材料机器目录](R4_MATERIALS_MACHINES.md)。型号是设计模板，不是已注册方块ID。

## 1. 一条主线，两种制造路线

第一次用已测晶体器件在实验台拼接，固定功能后封装。电控制芯片、矩阵模块、页载片均先用粗接触模板和模块装配取得。它们再为精密图案、组成注入、层对位与诊断提供控制，形成“研究工具改进制造，制造改善研究工具”的反馈。

| 环节 | 玩家选择 | 产物的实际变化 | 下一环节用什么验收 |
| --- | --- | --- | --- |
| 选片/特化 | 母批、取向、组成处理、应力/退火顺序 | 材料状态与响应窗口 | 参考对照、输入扫描、留样 |
| 器件试装 | 接触、反馈、路径、供给与读出 | 有输入输出及状态的功能结构 | 真值/曲线、保持/复位、扰动测试 |
| 模块封装 | 壳体、端口映射、热界面、外置设备 | 实际内件成为封装子件 | 封装后复测与安装检查 |
| 精密复制 | 工艺模板、层掩膜、对位、剂量/温程 | 未封装片按同一目标功能制造 | 工艺试片、逐裸片分档、功能回归 |
| 装板 | 插槽/内核/页载片、实际供给与总线 | 本地地址空间与算子资源 | 上电、自检、内存与通路测试 |
| 装柜 | 托盘、背板、面板、风路、支撑、走线 | 供给/环境/维护共同约束实际板 | 负载、余热、验通、维护测试 |
| 联网 | 节点、实际链路、数据位置、任务放置 | 可执行的跨节点计划 | 输出一致、断链/恢复、资源核算 |

模块装配消耗已存在的内件、壳体和连接材料；整片制造消耗晶片、处理剂、掩膜工装服务和工艺能量，产裸片后只收封装缺项。设计模板本身不产出硬件。两路线都保存母批、实际结构和工艺报告，可按同一功能协议替换，密度、功耗、环境窗必须分别测试。

## 2. 工序卡、半成品与批量制造

每张工序卡保存输入状态要求、实际工位、装夹方向、处理参数、持续条件、物料/废物流向、测试和下一状态。模板操作折叠为“接触图案→区域处理→恢复/稳定化→接触/互连→测试”；展开可编辑适用步骤。精密路线增加层对位和逐层图案，不能对热预算不兼容的已接触件统一最后高温退火。

首次保守模板保证可获得一套低档器件，玩家改善配比、温程、取向和环境以扩大工作窗。生产首版不强迫解出作者全部方程。工位以实际时间/供给推进：断电保存当前状态和继续冷却的历史；重新上电不会从“理想中断点”无损续跑。

状态依次为待料、已预留、加工中、待检、合格/降档/待返工/报废。输出/废物流位置满时在可安全暂停处停机；需要连续处理的工序必须先保证输出容量。材料受不可逆处理后不能撤销回原料。

分档按功能窗口命名，如“稳谱片·窄温窗”“页载片·可用1536 B”“控制芯片·低节拍”；不设一个同时提升所有属性的品质等级。返工先判断可恢复机制：重新装夹/校准不改组成，清洗不补回过蚀材料，退火会改变应力历史。拆封保留能取出的内件，连接耗材与受损状态另记。

阵列配方必须选[具体阵列模板](R4_MODELS_AND_FACTORS.md)，由工位执行模板内部重复加工，玩家不逐位摆8192个保持胞。模板中的加工、单位数、布线和验证可展开查看，自动复制不是忽略结构和成本。

## 3. B01：第一块可工作计算板

5×5板格沿用旧稿教学布局；一板格为该模板的物理尺寸0.1方块，器件的更细内部尺寸由其封装模型确定。下图是层叠宏槽轮廓，d/t/p对应布线/热收集/供给区域，不能相邻即通。

```text
板后侧（北，+v）
I  d  R  d  M
d  C  d  A  d
K  d  P  d  M
t  t  t  t  t
p  p  p  p  p
板前侧（南，-v）
```

八个实体插槽：I铜包接口、R持久片、M×2工作页、C控制芯片、A电矩阵模块、K晶振、P存储/总线控制。2片工作页各2048 B，形成同一受P管理的4096 B地址空间；系统固定预留512 B，任务可用3584 B。R为16384 B持久容量，其中首版运行程序/诊断目录占4096 B，用户可用12288 B。逻辑页分配不创造新容量。

装配单：板坯1、插座8、上述八件、导线12、热界面4。铜线库存按长度和端头工艺转换为实际板线路，余料保留；固定教学模板的12份包括其供给/返回与数据走线，不能再为同一内部线收世界线缆。自由布局重新按路径展开用量，模板配方不是任意布局无限接线许可。

| 资源 | 初版能力/预算 | 约束 |
| --- | --- | --- |
| 控制/标量 | 8个标量步骤/调度步 | 固定管理服务优先；复杂内核按展开操作计费 |
| 电矩阵模块 | 16个乘加/调度步 | 只对登记内核与格式有效，等待数据时不满算 |
| 本地总线P | 总计128 B/步 | 存储读写、DMA等共享仲裁，不能各自拿满128 |
| NIC | 单向最多64 B/步；同一物理出口按其双工规格 | 实际数据路径、队列和编码开销另计 |
| 工作内存 | 4096 B总，3584 B任务可用 | 不能借另一柜RAM绕过本地工作集 |
| 持久介质 | 16384 B总，12288 B初始用户可用 | 容量和实际读写服务分开 |
| 供能 | 整板空载8、指定峰值36 E/s | 数字是首版游戏预算，并非现实硬件性能 |

供能峰值展开：控制6、矩阵16、NIC4、P3、两RAM合计2、R2、K1、板级转换/分配2，共36。空载分别2、1、0.5、0.5、1、0.5、0.5、2，共8。负载之间按实际活跃量及供给图更新，不能把“36峰值”又加一次在内件之上。

首次可以留空A由控制芯片低速运行小算术，少装一片RAM则实际少2048 B。完整B01配方用于可复算示范，非唯一合法配置。没有独立激活片时ReLU/Bias由控制芯片执行；追加激活模块必须腾槽或加真实载板，不能在八槽外隐形加装。

## 4. B02与光电组合

B02在B01旁加一块实际载板、支撑框、一个光算子插座、2×2光模块、粗稳谱光源、两段外部光线和热界面。物理轮廓扩大为8×5板格，原板保持5×5。扩展宽度用于光算子/源/引出，端口外的维护空间另外检查。

光模块配方已含MZI、两个强度编码和两个读出；不再向外重复要同一套桥接。外部光源是实际驱动来源。其已验证功能是[受限2×2强度映射](R4_MODELS_AND_FACTORS.md)，M01有符号矩阵默认继续用电后端。学习到的新权重不能仅凭校准强塞进不支持的光映射。

B02示例额外峰值为光模块6、源8 E/s，整板50。标准R04空柜峰值20，因此标准64 E/s供给不能同时保证B02全峰值与全部柜设施全峰值。默认规划限制板至44 E/s，必要时错峰或换有明确空间/额定值的更大供能柜；不能只插第二个发电机就让额定64的背板变128。

独立参考/泵浦架服务多块板时保存每条回路、参考域、光功率和返回状态。集中服务提高维护便利，也扩大共用故障的范围。光链路避免某类电传输问题，仍受光源供给、温漂、相对位移、转换与读出影响。

## 5. R04：两托盘小机柜

采用2宽×2深×3高，共12个内部功能位置与12份结构框。为容纳背板、风路及检修，**明确替换R2.1同外形四托盘提案**。标准柜有两个前维护托盘，背部不再塞额外两块计算板。

坐标：x向右，y从前向后，z向上；每位置1方块。前面y=0，后面y=2。下面按从顶到底列出四个位置：

| 高度 | 前左x0/y0 | 前右x1/y0 | 后左x0/y1 | 后右x1/y1 |
| --- | --- | --- | --- | --- |
| z2 顶层 | 监测/控制模块 | 数据/参考端口面板 | 风冷模块 | 导风件 |
| z1 中层 | 托盘A | 托盘B | 数据背板 | 导风件 |
| z0 底层 | 供给模块 | 检修/支撑内件 | 供能背板 | 检修/支撑内件 |

内部电/数据背板以其模型中的分支延伸到两个托盘的盲插接口；分支已计入该背板结构/材料，不能把整个背板当无方向的邻接方块。托盘实际容纳8×6板格，板格0.1方块；B01与B02均可装，余量用于固定及端口引出，不等于能随意堆第二块板。

| 接口/空间 | 标准位置/方向 | 实际要求 |
| --- | --- | --- |
| 柜前维护 | 两托盘沿-y抽出 | 前方至少1方块深的抽出包络，不允许永久线管阻塞 |
| 柜外包数据 | 顶层面板前侧 `(1.5,0,2.5)`，法线-y | 端口引出后沿柜侧槽走线，不能横跨中层抽出区 |
| 普通供给 | 底层供给模块前侧 `(0.5,0,0.5)`，法线-y | 含供给/返回的接头与实际额定值 |
| 冷空气入口 | 中层两个托盘前侧 | 安装线缆不能封满入口，后部导风区连通 |
| 热空气出口 | 顶层后风扇 `(0.5,2,2.5)`，法线+y | 后方默认保留1方块交换空间；封口/近墙会改变阻力/回流 |
| 可选光参考 | 顶层面板的独立光插口 | 面板须装光接头及实际内部光线，不借铜包口代替 |

外壳模型有透空风口、接口锚点与托盘动画，不是12块不透气实心石砖。子对象变换从柜→位置→托盘→板→封装→器件依次组合；晶轴和接口法线随物理姿态变，端口输入输出语义不随左右翻转。

`rack_shell`配方不含计算板；`rack_node`额外装一块B01到托盘A，并用两份实际数据线完成板到背板/面板的指定缺项连接，B托盘为空。第二块板仍须真实制作、安装与布线。

空柜峰值20 E/s：监测2、数据背板8、风扇8、柜级供给转换/损耗2；空载为2+3+2+2=9。单B01柜峰值56≤64。双B01柜峰值92>64，额定供给不变时可给两板各22并限载，或采用新柜供给模板；托盘空间足够与持续能源足够是两件事。

R04背板内部已有真实交换/缓存模块，1280 B管理/队列预算来自其2 KiB页，其余768 B作为实现/维护预留；所有端口共享64 B/步柜外出口。每条板到背板链路的能力不能加成两个64的外部出口。超队列上限采用背压，采样端按记录策略丢样并标缺口，禁止无限缓存。

## 6. 从自建环境到机房

最初裸板接风冷模块，先学温升和停机余热；装柜后看到入口、出口、空槽漏风、背板和线材的位置影响。加第二块板后比较共享供给、回流和排队。精密光板再提出振动/参考/供给噪声问题。这样八类因素随任务逐步露出，不在首次装柜时强迫玩家同时调所有参数。

支持支线：隔振底座、局部供给滤波、屏蔽/返回套件、柜侧线槽、冷板/管/泵/换热器。液冷升级须在新内装方案或柜外设施上分配空间，原12个位置不无限叠件。冷板带走芯片热量，背板与电源仍可能需要空气冷却。泵、风扇、相邻生产机械都作为可追溯振源。

物理渲染与玩法反馈对应：风口方向箭头、温度的测量覆盖、线管真实曲线、模块接触点、抽出包络、供给/参考回路。没有探头覆盖的温度只能显示模型估计。发现问题后给出“改变一个原因→再次对照”的操作，不以刷最高档零件作为唯一解。

## 7. 首个集群与后续规模

两座R04各装一块B01，各接自己的64 E/s供能机；用铜包线经真实面板直连。节点固定管理服务在512 B系统预留内登记节点、状态与有限任务；选一个节点作为本次调度者，不需要先做独立集群核心。独立编排/交换/存储节点随后增加服务规模，也消耗自己的板和资源。

部署前列出：每个算子的可用内核、实际格式/误差、输入/参数位置、本地工作集、搬运路径、队列、供给和校准窗。拓扑发现只发现真实端口和在线节点；把两柜放一起不会自动连接。

默认先采用数据并行或独立实验任务并行。M01在单板已可推理/训练，集群不是人为通关门槛。两柜可各处理一半样本；训练需要版本一致的梯度合并与实际传输，之后原子发布新参数。若做算子流水切分，则中间激活必须经过实际网络：B=32的8维f32隐藏层为1024 B，仅64 B/步的共享出口其载荷下界就是16步，协议、排队及其他流量会增加时间。

同任务内按真实算子依赖与链路仲裁推进；用计算时间、传输时间、排队时间的执行时间线解释瓶颈，不能普遍取它们总和或最大值就声称模拟重叠。容量来自本地地址空间；远端页先通过显式传输/远程服务才能访问，故障语义与成本另计。

## 8. 故障、检修与验收

| 触发 | 立即行为 | 可恢复路径 |
| --- | --- | --- |
| 超供给或温度窗口 | 按计划降载/暂停，继续热演化 | 改负载/风路，回到窗口并复验 |
| 时序/参考超窗口 | 标记相关输入或内核结果无效 | 参考/供给/安装修复，重新校准 |
| 内存不足 | 部署前拒绝或提出可执行的小批量 | 真正重新编译工作集；不只改显示批数 |
| 柜间断链 | 仅关联传输/分布式任务等待或失败 | 重连并核验序号/版本；有效检查点恢复 |
| 拔托盘/替换器件 | 排空任务、断相关供给、撤销能力登记 | 按新物体ID复验及重建映射 |
| 区块卸载/离线 | 首版暂停研究/制造进度，保存状态；按有界模型处理余热 | 重新加载后重建连接/状态，不补送无限离线算力 |

阶段硬件验收为：裸板自检→单柜负载/余热→两个托盘的空间与供给反例→两柜实际路径与断链→光板单输入/双输入校准→至少一次来自热或振源的对照修复。任意更复杂柜型可以开放，但须登记自己的占地、端口、背板与环境连接图，不能沿用标准柜摘要遮掉新增结构。

## 9. 辅助实体的装配边界

| 实体 | 真实内装/连接 | 空间与资源定位 |
| --- | --- | --- |
| 传感汇聚节点 | 控制、RAM、NIC各一槽，板坯/供给/互连，两个探头口 | 独立1×1×1机箱；2048 B工作页中512 B管理，剩余1536 B作有限记录/转发缓存 |
| 记录节点 | B01旁加实际板坯、4插座/记录片、总线控制和连接件 | 独立2×1×1机箱；不能塞进R04单托盘。载板接P的声明扩展口，仍共享其总线/供给预算 |
| 集群编排节点 | B01与管理面板，另带1片可替换检查点介质 | 独立1×1×1机箱；额外介质为备用，未插入时不增加在线存储容量 |
| 交换节点 | 实际数据背板、两面板、供给与框架 | 独立1×1×1；背板共享转发/队列预算不因两个面板翻倍 |
| 同步/参考背板 | 晶振、驱动/门控、实际参考分支 | 可替换适配机架的指定服务位或装柜外；R04没有无限额外内位 |
| 无线前端与天线 | 前端含接口、时序、门/保持、供给，天线另装 | 柜外附属模块或专用服务位；需要真实馈线、供给、参考和方向，不自动装进每个NIC |
