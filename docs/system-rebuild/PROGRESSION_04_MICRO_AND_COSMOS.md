## 1. 先有两种不够用的解释

L2的起点是玩家希望让工坊配合得更好、做出新组合、把复杂作用装进工具，并在更多环境中使用。组成、方向、应力和制程构成共同材料基础；更细的结构和更大范围的用途逐步提出新的问题。低温/外场异常与天区谱线只是其中可展开的两类研究线索。

本段不是先完成微观再解锁宇宙。基础巡天已经可用；低温和量子实验也不要求先完成天空谱图。二者在材料谱尺、背景归因、边界模型三次交汇，最后才共同进入模组的边界耦合公设。

## 2. 微观第一步：低温、相变与可工作的材料

**旧稿依据**：[阶段表§8](../Kamaen_Info_Stage_Content_Line.md)、[GDD§5.8](../Kamaen_Info_GDD.md)。保留低温凝聚腔、准粒子晶格、超导环、拓扑晶体、相变记忆与III型雏形。

```text
普通冷却/密封/传感 → 分级低温试验腔
实际晶体基材 + 组分/温度/场扫描 → 相图与工作窗口
→ 经测试的超导环、相变记忆、滤波材料
→ 更低噪读出、更稳定控制与精密观测
```

首套冷却不需要超导环或视界冷却塔；III型雏形是组合已可独立工作的低温、场与测量模块，不是人造视界。制冷需要输入功和散热能力，低温不会自动等同于高相干。

**初步材料模型**：为不同登记材料分别给温度/场阈值与滞回窗口，先用连续过渡曲线或有状态分段函数。超导用途至少测电响应、场/电流容限和失稳；相变记忆至少测写入能量、状态保持、循环寿命；拓扑用途另有边界/缺陷对照，不能用一个“低电阻”同时证明三种材料。

**实验**：同样品降温/升温并改变小外场，拟合转变窗口；用普通样品作对照；超过工作域时器件退回普通/受损状态，有独立降载与复热。玩家不是看见一次零读数就完成定论，仪器下限和接触误差仍须记录。低温物性研究的历史入口见[昂内斯诺贝尔演讲](https://www.nobelprize.org/uploads/2018/06/onnes-lecture.pdf)。

**材料与数据分开**：`propagator_plate`和`feynman_vertex_plate`是模型/响应记录；`cooper_pair_seed`保留名称，解释为可维持登记配对态的实体预制件，需真实基材和环境。两张电子记录不能凭空合成物质。样本指导工艺，准粒子捕获器读出响应而不是把抽象传播子当粒子装袋。

**收益**：超导环改善特定控制链，记忆晶体增加持久存储选择，滤波器减少特定背景。旧电路、光路和数据设施继续得到升级。

> “有些变化不是原有曲线再延长一点。材料跨过了一个边界，而边界的位置也能被测量。”

## 3. 宇观第一步：谱尺、红移与背景图

**旧稿提炼**：世界信息场是研究对象；此前候选的星录、谱尺、背景图保留功能，重写为玩家实际观测成果，不沿用《接界计划》的文明留言前提。

先在实验室用可重复光源与物质样本建立谱线参考，再拿同一参考解释天区谱图。特殊名称“巴耳末谱尺”表示校准件/谱线档案的显示名，科学命名只是致意，游戏谱线参数属于登记模型。

**初步观测模型**：对已标识同源谱线，`z=(λ_obs−λ_ref)/λ_ref`；同一天区多条谱线应相容。仪器波长偏置与目标红移分开拟合。真实宇宙学红移的背景见[NASA](https://science.nasa.gov/mission/hubble/science/science-behind-the-discoveries/hubble-cosmological-redshift/)，游戏不由红移一个数反推出所有距离、年龄与物质性质。

**实验**：先用已知校准源校正谱轴，再匹配未知目录目标的多条线，留一条做检验。改变曝光/增益可改善信噪，但不能改变隐藏目录真值。观察到不同谱线比例也可能来自目标组成，不能强迫所有差异都解释成红移。

随后制造对应波段的背景接收头，测天区分布，拟合平均项、前景与残余。初模使用有限球面/网格基函数与非负辐射预算，不需要真实全天宇宙模拟。COBE测得背景的黑体形态与各向异性提供研究启发，见[2006年诺贝尔奖说明](https://www.nobelprize.org/prizes/physics/2006/press-release/)。本游戏“余辉星图”不宣称是现实CMB，也不是白噪晶种属性平均的直接物理来源。

**玩法**：换观测地点和朝向，比较本地热源/机器前景与天区共同结构；回放可重分析，但不能冒充新的独立样本。无需强迫等待现实数小时，提供短游戏观测窗口和固定校准对象。

**收益**：实验室谱尺解开天区谱图，天区参考反过来检验仪器长期漂移；背景档案提供以后辨认世界边界的独立基线。

> “那条在小小晶片上辨认出的谱线，也能帮助我读懂远处的光。相似的是测量的方法，不是已经知道了所有答案。”

## 4. 量子实验先于量子求解

**旧稿依据**：[光计算设计§13–14](../Kamaen_Info_Optical_Computing_Design.md)、[阶段表§8–9](../Kamaen_Info_Stage_Content_Line.md)。保留非线性介质、单光子源、SNSPD、时间计数与量子光学路线，去掉“经典光升级标签就变成量子态”的捷径。

基础路径：现有非线性材料/泵浦→关联对源与预告配置；现有半导体结工艺→初级单光子计数头与时间标签。SNSPD在低温与超导材料之后升级，不锁首次量子观察。初版探测器性能必须足以完成保守实验，量子点源提供另一种制备模块。

### 4.1 计数与两光子干涉

先做遮光暗计数、单路计数与符合窗口扫描，再做HOM延迟扫描。真实实验参照[Hong、Ou、Mandel原论文](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.59.2044)。

**玩具概率模型**：在登记的输入态、分束器与检测条件下，`p_coinc(τ)=b+a*(1−V*exp(−(τ/σ)^2))/2`，a,b≥0、σ>0、0≤V≤1且b+a/2≤1。按试次数生成计数，保留单路效率、漏检与偶然符合。不是所有源/实验都满足这条曲线。

**实验**：保持总触发与源亮度，改变延迟和一个可区分性条件；验证曲线凹陷与背景变化能否区分。符合率低可能是漏检，不能通过关掉探测器获得“完美量子态”。HOM凹陷不单独证明纠缠。

### 4.2 纠缠与统计证据

明确的态制备模板和多组测量设置就绪后，再开放贝尔/CHSH教学实验。保留全部有效触发、单路/双路数据、设置选择和被拒事件；报告采用了哪些采样假设，不把带后选择的教学模板称作无漏洞验证。真实实验启发见[2022年诺贝尔奖](https://www.nobelprize.org/prizes/physics/2022/press-release/)。

**初步任务**：用登记态与测量概率生成±1结果，估计各设置相关及其统计不确定度；玩家比较经典相关模板与指定量子模板，改变噪声/损耗检验结论能维持的范围。概率必须归一，不按希望得到的结论临时改变采样。

**收益**：通过量子制备/读出资格测试，获得有条件的校准报告，改进下一阶段测量。纠缠不用于无延迟跨维度传信；大量经典记录不等于复制未知量子态。

> “一次结果仍像偶然。换一种提问方式，再把许多结果放在一起，相关的结构才逐渐出现。”

## 5. 有效模型、费曼蓝图与混合量子求解

**旧稿提炼**：保留外线、传播子、顶点、闭环、约束、合成参数曲线和中观调度；把三类不同图分清：制造工艺图、信息计算图、物理模型图。

玩家先对已测低温响应选择有限自由度和耦合。费曼过程编辑器只允许登记模型中的顶点与边：检查电荷、允许频率关系、晶格/模式条件等各模型适用约束；“频率/拓扑数永远各自守恒”不作为普适规则。连通与守恒合法不代表工艺一定发生，必须求值并与实测对比。

```text
材料与响应档案 → 有效模型/过程图
→ 小规模经典基准求值 → 未见工况预测
→ 量子任务需要的制备/测量能力声明
→ 经典优化 + 量子统计估计 → 候选参数曲线
→ 实际框架试制 → 验收、封装中观协议
```

**首个混合模型**：`H=Σ c_k P_k`，使用有限两自由度的登记算符；`E(θ)=Σ c_k <P_k>θ`。系数来自材料模型标定，制备与测量模板必须支持所需状态和算符。量子设备提供统计估计，经典控制更新θ，实际材料验证仍是最后一关。现实参考为[光子处理器上的变分求解实验](https://doi.org/10.1038/ncomms5213)，游戏不承诺量子优势。

旧玻色采样作为独立的多光子分布/匹配挑战保留，不能作为VQE的通用后端。若某协处理器仅支持固定线性光路采样，其能力表拒绝不支持的任务；制备/测量扩展模块另行制作。主要参数曲线始终可以由有限经典基准产生，量子交叉实验和先进量子优化按实际作品需要深入，不充当全部后期的必修前置。

`wavefunction_cache_page`保存制备指令、任务引用与已测摘要；只有专门的实际量子缓存设备才维护有限寿命量子状态，物品搬动不能无损复制未知态。`wavefunction_sampler`输出登记可测统计与由校准推得的风险估计，不直接暴露任意完整波函数。

误差校验片/阵列先提供校准、重复测量与差错诊断。真正逻辑纠错须登记编码、综合征测量和译码能力，不能只堆方块就宣称任意码距、普遍降低逻辑错误；保留为进阶任务，并明确实际物理资源开销。

**实验**：同一小任务比较经典精确值、有限测量估计、噪声偏置与资源成本；再用输出曲线制作留出样品。训练/求解成功但试制失败，回到材料模型或设备校准定位，而不是自动发成品。

> “蓝图画出了我允许哪些过程发生。实验则决定，这种允许是否足以解释材料真正走过的路。”

## 6. 第二次交汇：微观边界与宇观几何

微观支线利用精密表面、间距与低噪读出制作**卡西米尔间隙腔**，比较距离/表面条件下的力学响应，先校正电偏置、热漂移和支撑结构。真实实验强调几何与材料条件，见[NIST相关实验说明](https://www.nist.gov/news-events/news/2013/10/reins-casimir-engineered-nanostructures-could-offer-way-control-quantum)。游戏采用有最小间距、有限响应上限的登记力曲线，不把简单幂律用到零间距，也不从真空力推出无限供能。

宇观支线用既有天区目录与成像模块测同源多像/形变，拟合有限透镜模板；档案称**测地卷**。真实透镜启发见[NASA](https://science.nasa.gov/mission/hubble/science/universe-uncovered/hubbles-gravitational-lenses/)。多组参数可能解释相似图像，因此加入另一源位置或波段检验，允许保留候选区间，不宣称完整重建宇宙时空。

**联合实验**：在多个本地边界位置重复间隙/晶体响应，同时保留独立天区及底噪档案，拟合一个只属于本模组的共同边界项β。比较“纯局部材料误差”“纯仪器漂移”“登记边界项”三类解释；使用新地点和未用于拟合的观测检验。

这是**科幻公设的显式入口**：世界具有有限可测边界模式，特化卡玛恩晶体能与其中一部分耦合。现实卡西米尔效应、量子计算与引力透镜都不证明这条公设；它由模组世界规则提供可复现预测。没有观察能力之前该项也存在，只是早期设备无法分辨。

**成果**：将实际低温/边界材料制成可重复使用的**接界棱镜**，用“互证谱册”记录来自材料、底噪和天空的联合标定。谱册是知识，棱镜是设备模块；数据不作为消耗性奇异质量。这个名字保留0.3候选中有用的功能含义，不意味着恢复其背景故事。

> “向内测量时，我遇到材料的边界；向外观测时，我遇到信息的边界。现在，两份记录开始约束同一个未知量。”

## 7. 本段归纳

此前按共同谱尺、噪声/统计与独立基线、联合边界模型组织三次研究交汇；L2将材料、工具、原版应用和探索中的持续交换作为主骨架，这三组内容在用途需要时展开。微观制备改善实际执行与读出，世界参照和环境关系提出新的组合目标，工坊与计算集群持续参与。

所有名人命名附对应的实际实验，不作为“高级科学锭”堆叠。合成材料仍需要物料与工作窗口，模型图只提供可检验的工艺依据。后续进入戈古尔斯弦与视界时，游戏公设沿同一套预测、测量、反馈和成本约束继续展开。
