## 1. 一套实验怎样从中期设备开始

最小研究站是已有实验台、可用样品/工装、该实验所需的源和读出、一块能执行相应小任务的B01及实际记录载体。光谱任务另装实际光路；纯电响应任务可先进行。B02、机柜、集群、多点网络、无人机按任务需要接入，不统一作为首次实验的门票。

实验项目共用一个入口：**问题 → 实物与连接 → 测量顺序 → 观察 → 候选解释 → 下一次试验/工艺**。默认模板预填保守范围和一个对照，玩家亲自装样、选择变化项并比较两组曲线；完整公式、残差和资源再展开。正确识别“证据不足，需要补一项对照”也是有用的结果。

### 1.2 真实端口与工程因素怎样延续

每个模块继续登记局部姿态、端口面、方向、载体与量程。样品内侧测压端不能被自动布线合并到外侧大电流端；供电/信号返回、光路参考、冷却回路分别存在。自动搭线生成的路径同时用于材料、损耗、热耦合与渲染，沿用[R4规则](R4_UNIFIED_WORKBENCH.md)。

环境因素归到实际来源：压缩/转动件产生振动，样品/导线/读出产生热，线圈和供电路径贡献场，支架/外壳与距离决定传播。各项先改变本地温度、接触、路径相位或探测输入，再生成读数；不得在数据分析末尾再叠一个“实验品质惩罚”重复计算。

制冷使用独立能量账。候选局部式：

```text
C_cold * dT_cold/dt = Q_leak + P_sample + Q_other_in - Q_cool
COP = eta * T_cold/(T_hot-T_cold)       仅在设备允许的温区、T_hot>T_cold>0内
Q_cool <= min(Q_capacity, COP * P_drive)
Q_hot_out = Q_cool + P_drive
```

`eta`和容量曲线由设备型号/实测决定；接近零温差时仍受容量上限限制，超出登记范围停止用此式。热端实际散热不足就积热并降载，不能继续把它固定在假定温度。样品温度与冷板温度有各自热容/热接触，控制器设定值不代替任一实测值。

有限例：在允许工况中，冷端280 K、热端320 K、eta=0.2、驱动10 E/s时，COP=1.4；容量允许则可搬运14 E/s，并需排出24 E/s。冷端负载12 E/s可压低温度，但热端只有20 E/s散热时该工况不能稳态维持。这是独立制冷组件示例，B01、测头与线圈的供给和热仍另按实际安装计入。

### 2.1 随机实验的首个生成框架

第一轮先把随机性分成四种：真实样品的批次差异、由已存在机器/环境产生的相关干扰、仪器缓慢漂移、读出重复散布。它们不能共用一个“随机误差百分比”。样品差异随实体保留；过程扰动可能改变样品；读出噪声只改变观察。

对固定测头、固定带宽和弱信号积分窗口，先登记一个可替换的读出候选：

```text
y_j = predicted_readout_j + b_cal + b_drift(t_j) + n_j
n_j ~ Normal(0, v_b(T))
v_b(T) = kappa_b*T + sigma_read_b^2
b_drift(t+dt) = rho*b_drift(t) + sigma_drift*sqrt(1-rho^2)*Z
rho = exp(-dt/tau_drift), Z ~ Normal(0,1)
```

此处T是影响该通道噪声的实际部件温度；kappa_b、sigma为非负仪器参数，tau_drift必须大于0。温度与涨落统计之间的联系借鉴[NIST噪声测温](https://www.nist.gov/publications/johnson-noise-thermometry)，该线性方差式是本游戏有限近似，不等于完整Johnson噪声定律。改变带宽/增益/输入阻抗后须更新模型，低计数事件另用相应计数分布，不能继续套同一高斯近似。

`b_cal`表示同一次校准在分析中尚未确定的共同偏置；实际世界中的仪器偏置只在观测链计一次，分析层用估计不确定度表示认识不足，不能再次把这项随机噪声叠到原读数。AR(1)只描述一种仪器漂移候选，本地同频机器干扰仍从真实作用路径进入。

一个简单后果：若记录共享校准标准差sigma_cal，另有独立读出标准差sigma_rand，均值不确定度为`sqrt(sigma_cal^2+sigma_rand^2/N)`。例sigma_cal=0.02、sigma_rand=0.1、N=100，约0.02236，不能按全部误差独立而报告约0.01020；再多重复也不能消除这一共同校准项。

实验模板把新样品、空载/参考、顺序对照与留出条件安排成有限区组；不能为了随机化而打乱本来要研究的温程历史。比较两种工艺可交换批次/运行顺序，研究滞回则完整保留各自轨迹。玩家可以重复、扩展或换假设，但验收条件预先固定，不在反复试到满意结果时自动挑选最漂亮的一组。

## 3. L1-01《把噪声放到一边》：从测一个数，到测一条响应

**需求。** 工坊扩建后，原来的晶体测头开始随驱动与安装条件波动。玩家需要分清信号变弱、相位变化、失谐和本地干扰，先改进一个确实在用的测头。

**搭建。** 旧实验台装同批参考片/待测片；同一振荡参考分到弱激励和同步读出，粗测头的电输出进入X/Y通道。晶体的机械、电气或光学敏感方向按实际载台选一种，不要求首台同时支持所有域。光学场景可以调制光强、读取电响应，显示的调制频率不冒充光载波频率。

**观察模型。** 在一种登记的弱激励、线性、近稳态窗口内，候选有效响应为：

```text
x(t) = U*cos(2*pi*f*t)
H(f) = K / (1-(f/f0)^2 + i*2*zeta*f/f0)
y(t) = Re[H(f)*U*exp(i*2*pi*f*t)] + local_interference(t) + readout_noise(t)
X = (2/N) * sum(y_n*cos(2*pi*f*t_n))
Y = -(2/N) * sum(y_n*sin(2*pi*f*t_n))
H_est = (X+i*Y)/U
```

这里K、f0、zeta与指定域/几何/温度有关，zeta>0；符号约定是余弦输入、复数表示。仪器增益/相位另经参考校正。该式不取代前期强冲击、破碎、结晶或全部电光物性；参数只由观测拟合，不能从样品隐藏字段直接显示。

与原晶体模型的具体接点：在选定材料与安装模板内，可让固有频率尺度沿用E1的方向响应关系，`f0=f_base(c)+k_A*u_local^T*A*u_local+k_S*u_local^T*S*u_local+k_T*(T-T_ref)`；已知参数范围须保证f0>0。缺陷可改变相应损耗项，装夹/传递路径另有自己的贡献。以后若证据支持新增内部状态m，再增加相应关系并检验，不能一进入后期就清空c/A/S和原工艺历史。这里的f0是单模方程参数，不把它与有限阻尼下的实际幅值最大点严格等同。

离散式用于等间隔、整周期且未混叠的示例。实际前端必须有相应通带、参考同步、抗混叠与积分时间；高于板上采样能力的载波由实际模拟/光电前端转换为包络，再按有限仪器模型结算，不在每tick里白送任意高频采样。

**操作与反馈。**

1. 用公开测试信号检查X/Y，换相位看矢量转动，确认读出没有把相位变化误判成振幅消失。
2. 固定样品与小激励，测8个频点；仪器逐点等待稳定，显示幅值/相位曲线和未完成区。
3. 比较“常数响应”“单峰响应”两种解释，预留一个频点或新的扫描顺序做验证。只有幅值数据时，部分模型仍可能难以区分。
4. 开关附近驱动、调整方向或换参考片。出现同频干扰时，界面同时保留原始通道与参考对照，不能承诺一键去掉全部噪声。
5. 用新响应档案调整实际驱动频率、安装朝向或支撑。重复原生产/检测任务，再决定是否封装“同调针”。

**有限演示。** 输入读出含`0.03*cos(wt)+0.04*sin(wt)`，叠加0.2的三次谐波和0.1的直流偏置。指定64点整周期例得到X=0.03、Y=-0.04、幅值0.05；再加0.02的同频余弦干扰，X变成0.05、幅值约0.06403。同步检波能隔离本例的离频成分，但同频污染会留下。这是对[SRS方法](https://www.thinksrs.com/downloads/pdfs/applicationnotes/Lock-In%20Basics.pdf)的有限教学化使用。

**收益。** 新频窗可改进旧分离工位的测量稳定性，也可选择更合适的滤波片/安装方式。强迫制造新晶体不是唯一解；调源、改路、改支撑能解决时也允许。滤波不能滤掉任务本身需要的变化，迟滞和延迟仍计入控制回路。

## 4. L1-02《回来时的另一条路》：温程、接触与真正的新状态

**需求。** 一块晶片降温和复温时似乎走不同的曲线。玩家先调查测量链和实际样品条件，再决定是否需要给材料模型增加状态。

**搭建。** 同批两试片、C0温控样品盒、样品侧温度头、四端载台、可反向的小电流源和电压读出。小线圈是第二组可选外场实验；C1/超导材料不是首次对照的前置。先用参考电阻或已知响应试片验证载台，再换未知样品。

**第一层模型：热滞后造成的假回线。**

```text
T_sample(t+dt) = T_plate + (T_sample(t)-T_plate)*exp(-dt/tau)
R_sample = 2 + 0.04*(T_sample-290)      仅作285–310 K附近的示例
```

第一式只用于冷板在该步近似稳定、弱测量自热的有限窗口；真实加热/换热仍按热账演化。冷板同为290 K时，降温路径的样品若仍是295 K，R=2.2；复温路径样品若为285 K，R=1.8。它们可以来自同一条无记忆的R(T_sample)。若只把设定值画在横轴上，就会误称材料出现滞回。

**第二层模型：电接触和偏置。** 理想高输入阻抗测压、正反电流等幅且短时间内偏置稳定时：

```text
V_plus  = I*R_sample + V_offset
V_minus = -I*R_sample + V_offset
R_est = (V_plus-V_minus)/(2*I)
```

采用[四端与反向电流测量](https://www.tek.com/en/documents/product-article/keithley-low-level-measurements-handbook---7th-edition)启发。四端布局减少供电引线压降进入测压结果，不能消除一切接触非线性；反向间隔内的温漂仍会造成偏差。

有限例：R_sample=2 Ω，I=0.1 A，V_offset=0.03 V；四端正/反读数0.23/-0.17 V，得到2 Ω。若两线另计总接触/引线0.5 Ω，单次正向读数0.28 V会给出2.8 Ω。若反向时偏置升到0.04 V，得到1.95 Ω，提醒玩家缩短间隔或先稳定热状态，而非把小数当真值。

**操作与反馈。**

1. 保持同一装夹，执行降温/复温两条序列，同时记录设定、冷板与样品温度；缺样品测温时明确标为“热状态未确认”。
2. 在相同样品温度区间比较，改扫描速率和等待时间。先解释可由热滞后预测的差异。
3. 小电流正反成对测量，再换测流幅度检验自热/非线性；对照参考片和重复装夹，记录接触变化。
4. 若新工况仍有可重复差异，比较原模型与“带有限内部状态的模型”；在未用于拟合的温程、新试片或小外场下预测并复测。
5. 把结论写入“复温回线册”，导出对已有工艺有效的等待条件、温程或工作窗，实际做一次留样试制。

后续材料候选可采用`dm/dt=(m_eq(T,B,...)-m)/tau_m`或有进入/退出阈值的有限状态规则；两者都需要明确适用材料、动力学、转变能与恢复条件。此轮没有为所有晶体强加同一相变函数。原模型足够解释数据的普通样品也必须存在。

**进入更深微观。** 出现低电阻只产生“低于本量程分辨能力”的记录；继续制作低温/磁响应工装，测温度、场、电流的工作域及磁响应后，才登记相应超导候选用途。相变存储另做写入、读回、保持与循环实验；拓扑材料另做边界、体区和扰动对照。三者不能共用一张“低电阻通过”凭证。

**收益。** 第一轮即可改进温程时间和接触可靠性，减少无效返工；以后才把证据充分的材料封装成低损耗回路、存储单元或探测升级。不会强制每份温程数据都拟合出一种高级材料。

## 5. L1-03《把工坊的刻度带向天空》：谱尺先于答案

**需求。** 中期已有粗星录和分光镜，但目标谱线位置与仪器本身的刻度一起变化。玩家先造可信谱尺，再用它检验天区谱移。

**搭建。** 旧光源/分光工装增加参考入口、狭缝、色散与遮光；单通道强度头随扫描机构读出即可。切换到定向支架输入时保留同一分光与读出部分。改装光路、狭缝或探测器之后重新校准。

已知参考样品提供两条约定谱线，未知样品和天区只提供实际光输入。普通强度读出并不需要单光子计数资格；灵敏度和分辨率是否足够，由真实仪器参数与试测决定。

**观察模型。** 光谱不是把隐藏谱线列表直接绘到屏幕上。每个读出通道先对入射谱积分：

```text
raw[k] = QuantizeAndSaturate(
    exposure * gain[k] * integral(response[k,lambda] * spectrum[lambda], d_lambda)
    + dark[k,exposure] + readout_error[k])
```

响应含实际通带、狭缝/色散/线展宽和光路传递；入射辐射非负。吸收线可由正连续谱乘透过率生成，不能任意相减得到负光强。光子散粒统计可在观测模型中生成，但初级强度头只输出其支持的积分电读数。

拟合出的峰心坐标为u，初步谱轴模型：

```text
u = a*lambda + b
reference: u_ref[j] = a*lambda_ref[j] + b
target:    u_target[j] = a*(1+z)*lambda_rest[j] + b
```

仅在本次校准的范围、精度和稳定窗口内采用仿射近似；不同目标的谱线身份先由候选目录匹配。模型更复杂时需要更多参考线。特别是未知刻度倍率a与目标谱移(1+z)相乘，**再多目标谱线也不能单独分开这两个倍率**；须增加独立参考。

**操作与数值演示。**

1. 先遮光测暗读数，再测参考源。示例的约定参考波长λ*=4、7，对应u=4.28、7.34，得到a=1.02、b=0.2；这不是现实氢谱数值。
2. 测一个有限天区目录目标，候选静止谱线λ*=4、5、6；实际峰心u=4.688、5.810、6.932，均在本例校准输出范围内。
3. 若错把u直接当λ，三条线给出约0.172、0.162、0.15533的谱移，互不相容。校准后分别得到4.4、5.5、6.6，支持z=0.1。
4. 用前两条目标线选模型，预留第三条预测；再次测参考源检查此期间漂移。参考校准造成的共同误差不按三条线各自独立处理。
5. 如果另一组线身份也解释得通，保留候选，扩展波段或提高实际分辨率；增加算力不能找回仪器根本没收到的谱线。

现实[NASA谱学说明](https://science.nasa.gov/mission/webb/science-overview/science-explainers/spectroscopy-101-beyond-temperature-and-composition/)提供实验室与天区比较的思想。这里首先输出谱移和模型候选，不直接输出目标距离/年龄；后续才加入另有观测约束的几何与宇观模型。

**收益与制程反馈。** 同一分光能力可以检查材料透过/吸收变化、选择适合的探测波段、分档滤波片和监控光源漂移。天区中经长期验证的参考对象再帮助检查仪器稳定性；未知对象不能反过来无条件校准自己。

## 6. L1-04《离站以后，仍有回声》：从背景图到成分模型

**需求。** 近远、开关机的旧环境记录已能找到部分工坊影响；玩家希望知道还有哪些变化属于接收头、当地环境，哪些可能随天区方向重复。

**搭建。** 定向支架装登记R波段接收头、参考负载/切换件、温度与工作状态记录。R1/R2/R3是游戏内明确登记的三个接收频带；可见光V分光头不能仅换界面就读取它们。首轮也可只在一个已支持波段做差分图，再逐个制造通道。

首模板：参考A→天空方向p→参考A，另一组使用第二已标定参考B检查增益；在近工坊与远测点、开机与关机、至少两个方向重复。可手动搬运或用已有移动应用，移动期间的数据不当作固定点稳态测量。实际方向、视场、遮挡、当地热源与接收头温度都入档。

来自[COBE/FIRAS](https://lambda.gsfc.nasa.gov/product/cobe/about_firas.html)的启发是差分和参考校准。第一套装置给有限游戏背景图，不声称达到现实CMB测量条件。仅有差分数据时，未知共同零点不能自动变成绝对背景温度。

**初步模型。** 在完成对应通道校准、固定视场、有限模板适用时，可比较：

```text
y[s,p,t,b] = G[b,t] * (a[b]*B[p] + c[b]*F[p] + local[s,p,t,b])
             + offset[b,t] + error[s,p,t,b]
```

B与F是两个候选天空分量，a/c是候选频谱形状；local来自当地可测因素的模型，不是传感器直接读出的隐藏真值。原始总辐射保持非负，差分读数允许有正负。视场较宽时实际先卷积角响应，不能把它当无限小方向上的精确值。

**操作与反馈。**

1. 先检查参考前后是否漂移。漂移过大就保留记录并降低本段可用性，安排稳定温度/缩短切换间隔等修复。
2. 用近远和开关机比较建立局部候选，再旋转支架/变更地点检验。有限两地点不足以排除所有环境来源，结论只覆盖已试条件。
3. 单波段地图显示“合计响应/差分”，未测格留空。目标目录和背景场可由有限规则生成，无需加载虚构星体所在区块；观测站仍须处于实际可运行范围。
4. 增加第二波段后，比较能否分开两个候选成分；条件不好就显示“这些模板现在分不开”，并建议新波段或新的对照。
5. 留一个新波段或新地点验证，才把这一轮结果加入“离站背景图”。多波段、稳定性和前景解释进一步通过后再形成“余辉星图”。

**有限演示。** 假设已经校准并扣除有依据的局部项，两个候选模板的频带响应是a=(1,1)、c=(1,2)。观测y=(5,7)支持B=3、F=2；第三波段若候选a3=1、c3=3，预测应为9，再实际观测检验。若两个模板同为(1,1)，只能得到B+F，重复观测或增加算力也不能唯一分开。模板形状本身还未确定时，须计入这一额外未知，不能套两元方程直接宣称分解完成。

多频共同约束前景的思想参照[ESA Planck资料](https://www.esa.int/Science_Exploration/Space_Science/Planck/Planck_and_the_cosmic_microwave_background)。游戏后续再增加温度谱形、空间基函数与非负约束；第一张地图不直接解锁宇宙年龄、起源或晶种平均性的真因。

**收益。** 可以为观测站与精密机柜选位置、调整屏蔽/朝向/频带、改进背景扣除；微观新材料将来再提高接收性能。若数据只证明“此处机器影响较小”，这也已经是可用工程成果。

## 7. 计算与数据规模怎样自然上升

首批使用能解释的基线：响应曲线、温度滞后、线性校准、小型混合模型。玩家可以手动比较或调用已安装节点的有限算子；没有强制神经网络架构。同步读出前端的成本算在实体模块内，若改由B01执行，则实际采样和算子预算转移到B01，不能两边都免费。

一份B01入门处理计划可先按如下有限工作集分配：8条32 B摘要记录页256 B、两个128 B输入/输出缓冲256 B、程序与求值工作区512 B、16个f32参数64 B，合计1088 B，小于R4的3584 B可用任务内存。512 B工作区仅容纳选定的小型程序/累加状态；新模型必须重新估算。此例不是任意FFT、非线性优化器或完整仪器固件都能塞进去的承诺。

32 B摘要的一种布局是频点、X、Y、样品温度、激励幅度五个f32，加条件索引、有效性、序号三个u32。条件索引所指的对象/校准/时间元数据另存档，占真实载体容量；单条摘要不能替代完整来源。原始长波形、图像或更多频点需分页并占额外存储，读满后暂停或按预先选择的策略减采样，不能静默丢点再宣称完整。

程序由已支持的实数算子表达；复数可以拆为两个实分量，但带符号求和、非线性拟合与FFT均须各自有可执行算子和资源预算。B02初始非负2×2光算子不能被自动认作通用复矩阵求解器。

| 研究扩展 | 先增长的实际需求 | 对硬件的自然牵引 |
| --- | --- | --- |
| 同片8点→多样品、多温度、多方向 | 工装换样、等待、元数据与样品供给 | 流水线/多工位、可靠校准；未必先缺算力 |
| 一条谱线→宽带光谱与图像 | 探测通道、读出吞吐、存储与校准模型 | 更好测头、采样板与实际网络；光学和电气各承担适合的部分 |
| 两个模型→多假设、多参数 | 真正的求值/搜索与留出数据 | 更大本地工作集或可分块并行任务，按端到端成本选择集群 |
| 单站→多点长时间观察 | 位置/时间对齐、共同偏差与缺测 | 远程站、通信与调度；断网仍保存本地可容纳的有效记录 |
| 连续强度→单光子统计 | 触发、时间标签、事件计数与源资格 | P18计数前端和态制备，再由经典节点组织统计 |

批量研究允许在真实能力内连续执行并异步归档；不靠现实数小时等待制造门槛。默认模板可分段停止/恢复，样品热史继续演化，恢复时先复测实际条件。区块卸载和服务器预算沿既有运行边界处理，不能无限后台试验。

## 8. 从实验成果回到制造，再进入后续设计

同调针不是凭一张通过报告生成：先选择真实敏感片、封装/参考路径、制造并复测。复温回线册给温程建议，实际样品必须经历它；谱尺和滤波器一样需要真实源/光学件；背景图可以给选址和屏蔽方案，却不能凭坐标自动建好观测站。

已测同一材料可能有多种工程解：改结构、改工作频率、缩小带宽、改善热路径、分批执行或采用更合适的模型。各方案比较有效输出、占用、制造成本与维护，不合成一个统一“科学品质值”。

下一轮四个实物闭环按需求深化：

1. **结构记忆件**：加工/写入→电或光读回→保持/漂移→循环→封装，反馈存储与可调滤波。
2. **低损耗与低噪材料件**：更低温/外场→输运与磁响应→工作域→实际回路，反馈控制和计数探测。
3. **内部结构观察**：对应波段的散射/衍射源、探测与制程→候选模式/结构→新样品验证；细化旧“准粒子捕获器/传播子片”的真实输入输出。
4. **量子实验件**：制备→暗计数/效率/符合→HOM等指定任务→支持的状态/测量能力，再讨论协处理任务。

本轮有限示例的复算见[L1局部验算](LATE_L1_MODEL_PROBE.md)。它检查指定例子中的混淆、不可辨识和资源/热边界，不是实验真实性、完整材料配方、GUI或模组运行的验证。
