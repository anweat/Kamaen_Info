# L3：谱纹、制造与空间作用模型

2026-09-09，配合[完整玩法](LATE_L3_COMPLETE_GAMEPLAY.md)。本文件定义可实现的有限游戏规则、首次制造与样机装配份额；不是现实晶体常数或全场物理仿真。对象逐项目录见[内容表](LATE_L3_CONTENT.md)。

## 1. 材料怎样贯穿始终

每个实体继承E1的母批、组成c、结构A、方向Q、残余应力S、缺陷d、结晶比例ξ、几何、内能与工序历史。L3增加的是区域分配和已制造的耦合，不生成独立的“后期品质等级”。区域是制造/响应分区，不等于R4的逻辑位；面积、允许通道和可分辨范围来自实际模板。

谱纹方案记录目标区域和作用关系；制造实例记录实际区域状态；运行实例记录当前写入状态、供给和输入。保存方案不生产材料，拟合系数不覆盖世界响应。拆封仍能追溯区域与端口，换机柜也不重抽性质。

首版使用三个互不混用的层次：

| 层次 | 状态与变化 | 初始用途 |
| --- | --- | --- |
| 持久结构 | 区域方向、组成、界面、锁定结构；实际工艺改变 | 梯度片、约束片、作用路径 |
| 运行状态 | 支持的写入/保持/复位状态；由对应器件与维持条件更新 | 双态响应片、选择动作 |
| 观测结果 | 经源、传输和读出得到的幅值、时间、统计与估计 | 识别工况、模型比较、过程蓝图 |

忆形晶片初版是双态响应组件，不自动获得非易失存储或机械自由变形。后续相变记忆晶体通过独立写入工艺保留材料状态，不能将短时光RAM改名就取得同样能力。

## 2. 双区域谱纹的首条制造线

```text
现有区域晶片/同批分片
→ 夹持和确定可加工区域
→ 局部定向/特化
→ 相容的稳定化与区域锁定
→ 形成接触或导波耦合
→ 安装写读与供给接口
→ 裸片用途测试 → 封装 → 装机复测
```

首次可用两片拼接版：已有分片分别处理，再以真实接触/导波件连接。单片版用粗模板和可定位作用头逐区处理。由这一保守路径制得的稳定片再改善织构头，避免首台工具依赖自身高级产物。

三类工艺结果沿实际历程产生：定向后锁定得到稳定方向；锁定前后顺序不当会留下普通处理片；局部覆盖不足会得到混合区域。剩余片可重加工或回收，不以随机“失败销毁”替代过程。

### 2.1 一个可复算的教学工艺

对每个粗分区保存定向量a、锁定量l和锁定时的方向标签；它们是A/S/界面变化的有限教学投影，不作为额外品质重复扣分。定向动作只在未锁定区内增加a，锁定动作只在a达到窗口且方向已确认时增加l。

```text
定向事件：a_new = min(1, a + D_A / 4)，只作用于未锁定区
锁定事件：若 a >= 0.8，则 l_new = min(1, l + D_B / 3)
             否则本次不形成目标锁定结构
l达到1时保存本次结构方向；改变它需要先执行已定义的解锁/退火工序
```

D是该工序在有效窗口内的剂量统计，**不是可再次提取的能量库**。输入能量仍进入真实内能、机械功、逸出与排热；不形成目标结构的能量也有去向。教学例固定温窗与充分散热，完整实现必须先根据温程/接触等判断有效剂量，不能只累计通电时长。

在初态a=l=0时，A剂量4后B剂量3得到a=l=1；B3后A4只得到a=1、l=0。双区域分别写方向x、y再锁定会形成不同用途；如果两条作用路径都覆盖两区，就无法凭方案名称得到分区结果。

持续工序按真实时间积分。拆成多个求解步不能多送脉冲；每个动作有一次性事件身份。区域超过当前模型范围时按对应物理规则演化，报告该工艺不保证目标结果，不因为玩家没解锁知识就冻结物质。

## 3. 空间作用如何计算与显示

每个作用头有实体位置、局部坐标、端口方向、作用种类、可用频段、功率和几何核。功能锚提供定位、引导或读出，不因连成多边形就自动获得任意填充场。初版按工件区域/载具位置计算，不遍历整个世界体素。

非相干能量传输的首个有限分配模板：

```text
E_emit_i = P_i * dt
w_ij >= 0：源i到已声明路径/出口j的几何权重
f_ij = w_ij / (w_loss_i + sum_j w_ij)
E_delivered_j = sum_i E_emit_i * eta_i * f_ij
E_loss = sum_i E_emit_i - sum_j E_delivered_j
```

分母为0时全部计入源端/终端损耗。η在0到1内。出口集合先由实际结构定义，空出口也存在；不能只枚举当前工件然后把一个离开对象的份额自动送给其他工件。没有进入目标的能量沿声明终端、介质或源损耗结算，图上显示其去向。

该模板是有界游戏传输，具体距离、遮挡与方向由对应作用头给出。机械头还要把冲量、反作用和接触送回E1.1力学模型；热头更新热状态；写入头通过材料过程更新区域。不同类型不合成一个万能“场强”。

相干光学可使用已有双端模板`P±=Pin·η·(1±V cosΔφ)/2`，两个端口共同结算，随后分别沿实际路径分配。非相干源不能凭同频就合并振幅；随机组合空间的复数可视化也不是实际场。

预览使用玩家已标定的传输模型，实测层使用真实读出，二者分色。移动源、锚或工件改变几何；拖动算子图只是排版。自动布线要经过R4的真实端口、方向、占位、物料和施工流程，不能为更漂亮的场图暗中生成线缆。

### 3.1 三种布局的具体差异

| 布局 | 剂量/时序怎样到达 | 能做什么 | 一个可诊断反例 |
| --- | --- | --- | --- |
| 串行走廊 | 工件先收到A，再收到B；位移与驻留来自载具 | 稳定锁定片批量制造 | 载具太快导致A不足，后段B无法补出先前定向 |
| 交叉写入 | 几何使两区接收不同方向/时段，最后分区锁定 | 双区域方向片、梯度作用头 | 旋转锚后串扰使两区同时定向，不能保留设计中的独立性 |
| 并列处理 | 同一源的出口份额分到不同工作位 | 试制多个方案或并行交付 | 多放工件却不调整真实出口/供给，单件剂量会不足 |

相邻区域影响作为传输和实际材料变化的一部分只计算一次；封装应力、机柜振动和读出误差各自从原有模型进入，不再另加“谱纹复杂度失败率”。

## 4. 制造平台与新增实体控制在少量家族内

| 家族 | 实体内容 | 首次来源 | 可扩展用途 |
| --- | --- | --- | --- |

| 功能锚与场控制 | 源端锚、引导/读出锚、实际连接 | 稳定谱纹件、线圈/光路、控制与壳体 | 织相工场、切片、后续边界接口 |

| 模式/量子模块 | 实际源、路径、控制、计数和校验 | 已知非线性/发光区，后续低温薄膜与模式材料 | 特定状态过程、量子协处理 |

普通支撑、围护和冷却布置不要求全部换成专属装饰方块。需要特定密封、热或场性质的地方检查实际结构；装饰不计功能等级。服务如过程编译、曲线调度和页索引优先装入已有计算节点，只有专用端口或吞吐需求出现时才做独立实体。

## 5. 从普通制冷取得后期材料

### 5.1 首套制冷和工质

第一套密封循环由普通金属换热件、驱动/压缩件、绝缘密封、现有控制与普通供能组装。工质候选为模组“封装冷媒”：普通有机馏分、净水与已能制造的晶体触媒在原有分离/反应工位中制得；触媒留在工装位，装罐后有真实库存。它是游戏工质，不声称这套混合物有现实低温性能。

C0沿用早期温控；C1首个样机以120K冷端作为有限设计目标，材料家族的首个低温保持窗定义在100—130K。首套不需要超导环。后续C2由更好的换热/约束和C1产物扩展更低温工作窗，量子和高级材料按各自需求使用，避免所有后期材料共用一个温度门槛。

有限制冷模型继续使用`Qc <= min(Qcapacity, η Tc/(Th-Tc)·P)`，条件为0<Tc<Th；热端排出`Qc+P`，达到容量上限的多余输入不能消失，控制应降低输入或按实际损耗排热。例：Tc=120、Th=300、η=0.2，Qc=6至少需P=45，热端需排51。机器适配定义FE和热模型的固定换算，不把FE数直接宣称为焦耳。

## 6. 样机物料的计量边界

[内容表](LATE_L3_CONTENT.md)给每个实体的首次投入、过程与用途。基底计量采用工程份：区域晶片、金属结构件、相容光路件、控制模块、读出组件、散热组件、密封件、储备和末地类基材各为实际可取得构件，而非研究点数。其内部材料由E1/R4已有工艺展开；本轮不声称已经统一折算成开局铁锭总数。

装配输入消耗实物，工位、工具和资料另列为可复用条件。数据记录可复制但占存储，不写入物理原料栏。长期光存储的首次普通基膜与写入头先由既有工艺制作，再升级高密度版本；紧急熄灭器由普通隔离/卸载和储备接口先造，不能先依赖完整视界熵流泵。

## 7. 性能、保存与失效怎样贯通

制造、区域求解和程序执行分时进行。只在实体结构改变时重建对应几何关系，运行时使用有界工作位和路径集合；场尺寸/对象数有配置上限。集群可离线比较布局并给计划，现场最小控制仍应在本地执行。

记录按真实对象、区域、过程事件、参考版本与采样时刻关联；完整谱与地图分块存储。B01承担小规模规则和摘要，复杂搜索/量子/世界预演使用实际支持的算子与工作集；B02首版非负光矩阵不能直接当任意复数过程求解器。

卸载时保存工件、工序阶段和已结算事件；恢复不补造未采集数据、不重复产出。长时离线以暂停为首版默认，持续加载设施再提供实际在线运行。失败优先保留半成品与已经完成的阶段；只有对应物理过程确实造成损伤时才改变材料。

有限例子的复算与依赖检查见[验证记录](LATE_L3_VALIDATION.md)。完整3D寻路、热/场求解、物料平衡和多人运行仍属于实现验证范围。
