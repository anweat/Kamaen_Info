## 1. 从仪器走向可设计的计算系统

**旧稿依据**：[EDA设计§2–8](../Kamaen_Info_Computing_EDA_Design.md)、[硬件设计§12](../Kamaen_Info_Hardware_TechTree_Design.md)、[Runtime MVP](../Kamaen_Runtime_Infrastructure/MVP_Path.md)。恢复其“设计硬件承载任务”的思想，不恢复“电气先统治后被淘汰”的排期。

自动扫测已经产生曲线。玩家的第一个计算需求是：扣除偏置、比较参考、找出候选峰、按用途分档。先给可展开的预设功能图，玩家能改阈值、增加参考输入或缓存，再逐渐进入版图。

```text
已测比较/保持等器件 → 实验台拼接与调谐
→ 输入/输出、实际连接、供给/散热和行为验证
→ 固定模块、封装、端口映射与复测 → 集成板 → 记录与算子任务
→ 用已有控制改进区域图案/精密制造 → 同功能裸片复制与封装复测
```

第一版工程入口由此前记录、固定诊断、机械模板与显示能力支撑；粗接触模板和模块装配能制作入门芯片，不依赖待设计的计算机编译自己。II型框架自动化已有工序，不垄断首批可用器件。

**玩法选择**：先在实际实验结构上验证功能，再在同一项目中调整制造与装配；更细版图按需要展开。电裸片、光裸片与桥接封装分别满足条件。普通玩家使用已验证的保持、I/O、算术及相应光学模板，高阶玩家展开内部。不同封装作为端口密度、可维修性与热预算选择，不逐一强制串成等级。

**初步模型**：首个任务先串行记账，`总耗时=各算子耗时+搬运+转换+校准+等待`；执行前校验峰值内存和端口容量。后续流水并发按任务依赖求关键路径，不继续把并行耗时简单相加。材料的阈值裕量、传输损耗与漂移进入有效速率和错误诊断，不再凭“芯片级别”独立重抽好坏。

**实验**：同功能、同输入，一版布置短连接，一版密集堆放；比较正确率、温升、搬运等待。再换一块真实参数较差的晶片，观察器件画像如何影响结果。诊断指出瓶颈，不能只显示“布局不佳”。

**收益与故事**：同一仪器处理更多样品，模板可复用，坏裸片可降级。

> “我曾把性质写进一枚晶体。现在，连接的方式决定这些性质共同完成什么。”

## 2. 存储、参数空间与运行时：数据为什么不能放在同一个箱子里

**旧稿依据**：[信息系统§3–9](../Kamaen_Info_Information_System_Design.md)、[Runtime完整路径](../Kamaen_Runtime_Infrastructure/Complete_Path.md)。保留四类数据、参数物品、图网络、端口、触发器和运行预算。

```text
低速保持/读写单元 + 物理存储载体 → 内存页与记录柜
单机板 + 页槽 + 任务模板 → 本地数据处理
算子/参数/端口 → 可执行模型图 → 版本化输出
```

记录柜先由空白载体和读写结构制造；数据库是柜上装载的应用，信息中心再组织它们，修复“数据库需要中心、中心需要数据库”的循环。

| 数据类别 | 本段可见用途 | 生命周期与失败表现 |
| --- | --- | --- |
| Input | 此次扫描的原始读数 | 保留出处，可因过期而拒用 |
| Parameter | 校准系数、阈值、后续模型权重 | 可保存、复制版本与回退 |
| State | 扫描位置、积分记忆、任务进度 | 依设备支持检查点或复位 |
| Activation | 中间差值、矩阵临时结果 | 工作内存不够时分批或拒绝运行 |

损失、奖励、梯度、指标是上述数据在任务中的角色，不增加神秘第五类。复制记录消耗载体/传输，不能复制样品、正在运行的唯一设备实例或未知量子态。

参数晶胞→矩阵板→晶体簇→参数库是容量/组织升级。参数空间保留为可返回的可视化编辑场：方块表示索引与连接，编辑提交生成模型版本；进入参数空间不会产出材料，也不要求先能创造真实维度。空间关闭时从正常入口返回，模型持久记录在空间外。

**初步运行模型**：端口声明类型、形状、单位、时效；任务具有输入版本、输出目标与步数/内存/时间预算。基本运行时先执行固定算子图，之后开放有限表达式与有界循环；高级编译只改善预算利用。算术结果必须从输入求得，不能用等待时间换一份与输入无关的“成功模型”。

**实验**：把温度单位或向量形状接错，观察编译诊断；填满工作页再分批处理；暂停恢复后，Parameter保留、临时Activation释放、State按模板恢复。每个故障都有可见原因和回退。

> “记录一件事、记住进行到哪里、保存一种解释，原来是三种不同的工作。”

## 3. 网络、环境采集与初始巡天：把比较扩展到不同地点

**旧稿依据**：[硬件设计的传感器/网络章节](../Kamaen_Info_Hardware_TechTree_Design.md)、[信息系统§7、11、14](../Kamaen_Info_Information_System_Design.md)、[GDD§5.7](../Kamaen_Info_GDD.md)。

起步是两个传感器与一个汇聚器：比较机器旁和远离机器的同型探头，再增加本地记录柜。基本网络先直连地址；服务增多时才引出交换机、多DNS与存储中心。

```text
本地探针/谱仪 → sensor_hub → 时间与校准对齐
→ 频率总线/低速网络 → 数据柜 → 环境档案
集成板 + 网络接口 → 交换/路由 → 机柜与存储中心
```

无线G1–G6保留为范围、并发、延迟、带宽的不同组合：G1控制、G2稀疏记录先开放；G3状态流/G4任务请求随集群开放；G5/G6高并发随中后期材料升级。F1–F5是协议/设备能力族，不能作为同一连续物理频率的万能数值；实际载频、波段、采样率、节拍分别记录。

多DNS按根/区域/本地/缓存解释，预置单域模板可通关；跨域别名与失效切换提供深度。地址解析只定位服务，不能自动授权读写。卸载区块中的端点变为离线，不以升级无线范围隐性强加载世界。

**初步模型**：`排队量_next=max(0,排队量+到达量−服务量)`，队列上限、TTL、拥塞反馈独立。时间对齐允许有限误差，不把同tick不同延迟当成同时观测。

**实验**：制造突发数据、旧地址与离线端点，选择降采样、缓存或重路由。长期档案先保留固定容量摘要与重要原始片段，不鼓励每tick永久存一切。

此时并行开放**初始星录**：普通镜组、已有光学读出和手动指向采集有限天区的强度/粗谱。天空数据由模组固定种子目录生成，不宣称原版模拟了真实宇宙。基础巡天无需量子仪器；微波接收要另造波段对应接收头，不能用可见光镜片通吃。

**收益**：选厂址、诊断干扰、比较不同群系/维度的登记现象，留下宇观基线供后期复核。

> “同一套仪器在不同地方留下了不同余量。我第一次无法只从机器内部寻找原因。”

## 4. 光电矩阵与集群：解释为何需要更多计算

**旧稿提炼**：保留电矩阵/激活瓦片、光GPU、光脉冲、光协处理、光控制核、光RAM与全光网络。修订“只许光计算模型”的限制。

电矩阵由已验证算术阵列扩展；光矩阵由相位/导波网络和明确编码读出扩展。两者分别可以制造，基础光矩阵先用手动标定的小阵列，F4、泵浦塔和自动校准是规模升级。光RAM、光控制核、非线性脉冲器都不作为基础光矩阵的前置。

**共同任务**：同一组有限尺寸输入做线性组合，并检查输出误差。电阵列走有界数值算术；光阵列的真实内部状态先按复振幅传播，读出强度需通过登记的编码/参考方案还原任务数值。带符号权重使用差分通道等明确模板，不能把非负强度直接当任意实数矩阵。

**初步成本模型**：同时比较输入搬运、权重重写、校准、转换、内存与求值。小批量频繁改权重时电阵列可能更适合；大批复用时光阵列可能有收益。候选数值必须让两者各有可测用途，不承诺现实量子/光学加速比。

```text
单机板/光背板 + 电/光算子 + 明确桥接
→ 混合节点 → 两节点任务拆分 → 机柜/集群
→ 批量晶片预测、环境档案处理与实验排程
```

全光五件套在同阶段作为完整专化分支逐件解锁：非线性介质→光逻辑/双稳态→光控制核与短时光RAM；光协处理负责搬运，光GPU负责登记密集算子，脉冲器负责登记非线性/稀疏任务。缺其中一件仍可用电域承担对应角色。后期长期光存储和WDM进一步降低某些搬运成本，电气持续可用。

**实验**：固定算法/精度比较电、光、混合三种后端，再固定硬件比较不同分块。拔掉一节点时任务恢复/重排，副作用执行器用任务号去重；不能因重试而重复投料。

> “更多器件没有自动带来更快的回答。让数据少绕一次路，有时比多造一整排晶体更有效。”

## 5. 模型发现与监督学习：把经验变成能检验的解释

**旧稿依据**：[信息系统§4–6、13–15](../Kamaen_Info_Information_System_Design.md)。模型第一次有用从现在及此前查表就开始，不拖到量子工艺才有收益。

玩家先以二段的掺杂/应力数据拟合一条简单响应关系；比较常数猜测、查表、带交互公式。随后选择小型MLP处理更多输入。线性、卷积、循环、注意力、图模型等全部保留为有任务支撑的模型库扩展，逐次用光谱、时间序列、局部网格、网络拓扑引出；不要求为了通关训练所有架构。

**初步模型**：在有效数据上`L=平均(预测−实测)^2`，单位先规范化；各模型以同样的新母批/新工况验收。添加输入字段不自动获得其真值，缺失与延迟显式编码。训练/校准/验证组按批次和时间块隔离，调参用过的验证集不再称为独立终验。

参数更新是真的有限求值与优化；可用小shape有界步数，不能只靠训练倒计时提升等级。模型物品封装图、参数引用、版本与适用域；权重可回滚，设备替换后重新做所需校准。

**实验**：给一批“浓度越高应力也越大”的生产数据，让两个解释同样拟合；再让玩家选择交叉工况，获得可区分证据。允许回答“目前不能区分”，不强制猜开发者公式。D1离线原型提供这类反例参考，但不替代实际数据界面测试。

**收益**：预测合适晶片用途、少报废、估算机器维护时机；模型更复杂需以误差改善抵偿资源成本。界面显示预测区间、失效域与残差，未知性质继续通过实验取得。

> “公式替我解释了一批晶体。下一批晶体则告诉我，这个解释只到哪里为止。”

## 6. 动态控制、强化学习与生物/物流

**旧稿提炼**：保留环境模拟器、状态/动作/奖励、回放、实体策略、交易对话、物流和反馈路由；固定控制先能生产，学习优化后续规模和复杂实验。

首个动态环境复用退火炉：温度有惯性，传感有延迟，电源有扰动。先比较定时配方、带滞回/PID模板，再引入有限回合策略学习。模型输出动作必须经本地限幅和独立联锁。

**初步环境**：`T_next=T_amb+(T−T_amb)exp(−Δt/τ)+K*u*(1−exp(−Δt/τ))`，τ>0、u∈[0,1]，环境和加热在每步近似恒定；换工况时更新参数。这是稳定的一阶游戏热模型，冷却、耗能和加工质量另算。

**奖励**：合格产量收益减去时间、能耗、超限与报废成本。验收同时要求完成任务、保持安全和预算合格，不以单一累计奖励放行，防止“永远停机”“反复提交旧轨迹”获胜。随机训练与未见测试工况分开；奖励权重由玩家配置，但验收指标固定可见。

**生物链与策略深化**：前期[E1.2应用](EARLY_E12_APPLIED_PROGRESSION.md)已从作物/木材与有机料取得纤维、树脂和培养前体，开展局部田间观察及基础受控培育。现在扩展多变量预测、跨批验证和相容控制。培养状态/环境/历史按[应用模型](EARLY_E12_APPLICATION_MODELS.md)描述；生长量受实际基质、营养、水和容量限制，不能只靠无物料约束的Logistic曲线产物。原版农场观察与模组受控实例分别更新，收获与留种分账。

**物流与实体链**：库存预测→多机送料策略；路径/碰撞记录→本模组代理执行有限任务；对话/交易用离线有限意图、报价、关系状态，模型可选生成建议。对抗实验在可重置场景回放，不能默认控制任意模组实体或直接修改玩家意志。

**实验**：热处理做未见电源扰动；培养做同批不同环境与空白对照；物流做突发需求、堵塞与断网。策略收益来自相同资源下更稳定完成任务，坏策略回退公开保守方案。

> “预测接下来会发生什么，还不等于知道现在应该做什么。每一次动作都会改变下一次能看到的世界。”

## 7. 主动实验、底噪分层与开放模型接口

**旧稿依据**：[GDD底噪层](../Kamaen_Info_GDD.md)、[信息系统数据质量/外部API](../Kamaen_Info_Information_System_Design.md)。

当晶体、仪器偏差与热漂移已能解释大部分结果，玩家开始追问剩余误差。先用规则选择“候选模型分歧较大且可负担”的下一点，不强制再训练一个RL选点器。

**主动选择候选**：`优先级=预测分歧/(试验成本+ε)`仅在可执行/安全集合内排序；高分不等于发现真相，必须实际取样并更新档案。遇到相同观测下不可辨识的模型时，提示缺少新仪器/干预能力。

**世界底噪初模**：`N_layer(x,t)=区域背景+登记局部源响应+事件项+相关波动`；测量再通过传感器响应、带宽、偏置和自身误差。这里的热噪层是环境现象，白噪晶种的“平均背景属性”是物质基底概念，两者不等同。

固定世界种子/模型版本产生有限空间与时间索引，物理上共享的源供不同仪器观测；仪器误差可独立。同一地点时间重复读取不重抽真实场。缓存键含维度、区域、层、时间窗、模型版本，修复旧“全维度同层共用一个数”的空间信息丢失。

**实验**：近/远探头×源开/关四组对照，固定积分窗；再改积分时间，比较独立与相关样本的有效收益。热噪测温的真实启发见[NIST](https://www.nist.gov/programs-projects/johnson-noise-thermometry)，本模组用有限噪声模型，不把所有底噪都当电子热噪。

九层均保留：热、辐射、量子、区块更新、实体、红石、群系、虚空、弦残留。前六类按已有探头能力逐渐解释；“量子层”数据先存为候选残差，量子测量能力不足时不发权威标签。区块更新计数是游戏活动代理量，不直接称为严格热力学熵；虚空/弦层等待后段边界实验证据。

外部API在这里作为可选任务后端：与本地求值/训练/对话共用Schema、截止期、费用上限、失效回退与结果验收。断网不影响通关。模型建议不能自行授予科技、产出材料或访问未开放状态；游戏内脚本也不是不受约束的外部操作系统。

**收益**：选择稳定厂址、消除可控干扰、规划下一组实验；残差档案连接微观相变与宇观谱图，而不是“噪声值攒满就解锁量子”。

> “我终于能从噪声里划去一部分已知原因。留下来的不再只是误差，而是一组值得继续提问的关系。”

## 8. 本段回看与下一段

回写规则：研究记录从扫测阶段保留母批、时间和校准版本；单机能做小模型，集群服务规模，避免模型自举依赖大型集群；基础巡天与环境调查先行，后期仪器深化它们。网络复杂度和模型架构提供深度，不挤掉材料研究主线。

下一段并行推进：实验室里降低温度、改变场和测量单光子，天空中提高谱分辨率、区分源与背景。两条线反复共享晶体参考、实验方法和计算基础，直到能对边界提出可检验的联合模型。
