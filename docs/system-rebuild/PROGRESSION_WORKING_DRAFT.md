## 1. 推进方式与故事基调

每一段按“旧稿思想→玩家遇到的问题→新操作与产物→初步模型→发现片段→下一段需求”展开。完成一段后，归纳共同概念、检查前后冲突，再同步到相应专题；发现旧公式不够用时调整公式，不为维护公式强改玩法。

主旨：固定物质体系的平均背景以白噪晶种体现，晶体通过组成与内部性质特化，成为玩家作用于、读取和研究物质及现象的媒介。信息与频率贯穿材料、控制、计算以及微观/宇观研究。

故事先沿玩家自己的发现展开：从看似嘈杂的圆石中制备平均基底，发现可写入差异的晶体，再发现这种差异能够辨认并影响其他对象。旁白采用可回看的研究笔记，不预设古代文明、末日或必须完成的宇宙使命。更大的背景等世界底噪段自然显现后再讨论。

笔记记录“我观察到了什么”，不会替玩家提前宣布未知真相。固定教程展示操作方法；研究结论依赖实际对照；失败时写观察结果与待验证解释，不自动发成功台词。

## 2. S1：圆石频谱初炼——从混杂中找到共同基底

### 2.1 初炼：同一块石头里为什么会出现不同产物

**旧稿思想**：圆石是低效宽频基底；筛分/泥浆分离产生基础粉末和频谱滤渣。依据[阶段表§2](../Kamaen_Info_Stage_Content_Line.md)、[早期设计§3、11–12](../Kamaen_Info_Resonance_Crystal_And_Early_Game_Design.md)。

**玩家行为与科技线**：

```text
圆石 → 木质手筛 → 粗频谱碎屑
碎屑 + 水 → 木盆沉降/粗滤 → 少量基础粉末 + 频谱滤渣
铁铜/玻璃 + 机械结构 → 搅拌分馏塔
分馏塔 → 持续处理泥浆，分出既有粉末与滤渣
```

木筛、木盆是修复旧稿“起步筛需要铁”的候选首版；金属筛和工业滤膜属于后续升级。基本金属由累计有效处理量确定性得到，不能靠稀有抽奖才能造第一台机器。开局假设有可再生木材、圆石来源、水和普通燃料；具体空岛配置后续列清。

第一次选择：改变粗滤方式会改变产物比例，连续运行又会积累污染。玩家比较同量圆石的两种处理，不必此时理解完整频谱。

**够用的初步模型**：每种原料有允许产物集合与有限产量预算Y；滤材为各合法产物提供偏向w。`产物份额_j = w_j / Σw`，总输出不超过Y；污染降低可用产量或纯度，水洗消耗时间和水以恢复。分配可有累计余数，避免小批次永远产不出低比例基础粉末。

暂不把每种元素真实含量、全部世界物质坐标引入此段。圆石宽频不意味着任何终局物品都能被调出来；滤渣有实际质量，不是免费的噪声能量。

**可见发现**：玩家确认改变处理方式会改变结果，而非总是投入更多材料。

> “留下来的不只是杂质。换一种筛法，它留下的东西也变了。”

**承接**：粉末建设设备，滤渣留下下一段的问题：它还能怎样被处理？

### 2.2 均值化：把偏向减弱，而不是提炼一种特性

**旧稿思想**：热噪坩埚处理滤渣，获得均值化圆石；初级分光镜观察偏差。结合已确认的“平均背景物质表示”。

```text
基础金属/石质容器 + 炉体 → 热噪坩埚
频谱滤渣 + 登记基材 → 热处理/保持/冷却 → 均值化基底
玻璃 + 基础结构 → 初级分光镜
```

沿用旧ID `whitened_cobblestone`；显示名可先保持“均值化圆石”。配方需要的基材数量尚待后续物料表核算。分光镜不要求卡玛恩晶体自举；它只能显示粗分段响应和重复测量的稳定程度。

玩家用同批滤渣比较未处理、短保持、充分保持三份样品。第一条可以发现的规律：有效工艺窗口内，保持使明显偏向减弱；过热或粗暴冷却却可能增加加工缺陷。

**初步模型**：暂用少量归一化属性偏差δ。有效窗口内`δ_next = (1−α)δ + 批次扰动`，α受保持与稳定度影响；另外记录缺陷D，避免把偏差小与缺陷少混为一谈。参数先用固定可解释范围，世界间变化以后讨论。

初级分光镜只能为“趋近背景”提供部分证据，不能直接宣布已经测到全部属性均值。原型中可以先选两项可观测响应，后续仪器再检验未观测属性。均值基准如何由完整物质注册表定义，保留D1候选，不阻塞这一段玩法。

> “我没有把它变成更像铁或铜的东西。它正在失去对某一类性质的偏向。”

**承接**：均值化基底仍然松散，玩家需要把这个状态保持下来。

### 2.3 初始结晶：白噪晶种为什么值得保留

**旧稿思想**：均值化圆石与频谱滤渣制白噪晶种；晶种是粗晶体起点。

```text
合格均值化基底 + 少量制备滤渣
→ 坩埚的结晶容器中保持/冷却
→ 白噪晶种
```

“少量滤渣作为成核辅助、不会重新引入明显偏向”是需要试验核对的候选解释：可规定其先经同批处理，或后续另分成核组分；本轮不把未经均值化的任意滤渣直接加回并默认仍中性。

操作重点只保留合格基底、安静保持和冷却方式。第一份晶种不要求精密控温、锁相器或全属性分析；公开保守窗口保证产出，精细操作改善后续可控性。

**初步模型**：基底偏差低于容许窗口、保持量达标即可成核；冷却偏离安全区增加D和批次差异。晶种仍是接近平均背景的初始结晶，不在此强制选择导波/稳谱用途。

**验证行为**：把合格晶种放置一段游戏内有效观察时间后复测，看到其参考响应得以保持；结晶失败所得碎料可回到热处理，有损回收。

> “那些原本随处理改变的细纹，在这枚晶种里停留了下来。”

**本阶段成果**：既得到制造能力，也得到可重复的参考样品。后续实验要有共同起点，才能分清加工真正造成的差异。

## 3. S2：结晶与力学合成——向共同基底写入差异

### 3.1 粗晶体：冲击为何不只造成破坏

**旧稿思想**：白噪晶种经模拟爆破成粗卡玛恩晶体；刚体板、缓冲砂、靶座改变冲击画像；早期原型以结构差异产生可解释结果为核心。依据[阶段表§3](../Kamaen_Info_Stage_Content_Line.md)、[玩法计划§3–4](../Kamaen_Info_Core_Gameplay_Development_Plan.md)。

```text
白噪晶种 + 晶体生长基材 → 靶座上的待处理晶坯
待处理晶坯 + 工艺冲击 → 粗卡玛恩晶体
```

晶种引导结构，基材提供生长质量。沿用已注册`kamaen_crystal_raw`；旧表`raw_kamaen_crystal`作为设计别名核对。冲击装置先用机械/工艺爆震方案，TNT是后续可选来源；安全模板无需天然火药才能启动。

玩家只改一个缓冲位置，对比两次输出。冲击太弱不能充分形成可加工晶体，太强造成裂纹；方向和宽度改变内部应力。没有必须制造基地灾难的剧情要求。

**初步模型**：冲击画像保留强度I、方向n、宽度与波形稳定度。有效窗口决定成型，`S_new = S_old + k I nnᵀ`作为首次应力写入候选，另有过载缺陷项。暂不追求真实冲击波求解；多方向处理之后再扩展压缩、剪切与退火模型。

首次冲击可留下应力偏置，但粗晶体不因此自动获得完整的成品专化标签。玩家已经改变了结构，还需测量其用途。

> “力量没有只把晶种打碎。它还改变了晶体随后怎样回应。”

**承接**：同样外形的晶体出现不同响应，需要有目标的调整和对照。

### 3.2 首次特化：三个用途不是三个世界坐标

**旧稿思想**：导波、抗压、稳谱三条专化，应力和取向贯穿后续。保留用途，修正旧表X必导波/Y必抗压/Z必稳谱的绝对坐标解释。

粗晶体先进入基本I型框架：普通压头/结构可以制造首版，偏振晶体与应力传感器用于升级，不反过来卡住基本框架。玩家选择装夹方向、有限加载与退火，观察同一晶体的前后变化。

| 暂定用途 | 用什么短实验发现 | 立刻用于哪里 |
| --- | --- | --- |
| 导波倾向 | 沿不同方向注入/读取同一参考响应 | 首批调谐传递件、探头连接 |
| 稳谱倾向 | 同条件多次读数，比较漂移和峰宽 | 参考晶体、较稳定的测量 |
| 抗压倾向 | 在可恢复的加载范围比较结构/响应变化 | 改善框架和后续加工容错 |

**初步模型**：组成固定时先用`响应 = 基础项 + k·u_localᵀ S u_local`描述方向差异；漂移/缺陷另算。方向旋转改变设备看到的响应，不把世界坐标轴永久绑定功能。保持能力与抗压还需各自的有限指标，不能从同一个分数直接推导全部性能。

本段只教结构特化；粗晶使用固定登记基材与配方，组成已有确定状态，但尚不开放玩家调节。组成/掺杂在后续按工艺进入，避免一次要求玩家辨识所有变量。D1的交叉组成/应力实验留给那时复用。

> “它没有离开共同的起点，只是沿着某些性质走得更远。”

**成果与解密**：玩家能提出并验证“方向改变会改变响应”，做出至少一种有实际收益的专化。三种标准模板均可访问，基础进程不锁随机词条。后续退火可能松弛已写入应力，因此专化记录应附处理历史和测试工况；再次加工后须复测，不视为永久不变的词条。

## 4. S3：共振调谐与信息读取——差异开始辨认和作用于世界

### 4.1 目标样本与选择性共振

**旧稿思想**：目标有固有频谱；晶体、原料、设备与稳定度共同影响资源分离；统一共振平台通过模块扩展。依据[早期设计§5、10–13](../Kamaen_Info_Resonance_Crystal_And_Early_Game_Design.md)。

```text
专化晶体 → 调谐晶片/粗参考件
真实目标样本 + 基础测量 → 可比较的频谱样本
样本 + 晶体 + 粗调谐机构 → 有选择性的共振晶体
共振晶体装入分离平台 → 改善某个合法产物方向
```

旧锁相器配方中的金和高级参考适合作精度升级；首版可先用机械调节/基础电驱动与已有晶片。具体配方后续核对，但不要求先获得只有高效共振才能产出的材料。

第一次任务选已经可获得的铁/铜类样本：同量合法基材，用未调谐与调谐晶体比较产物比例。数据指导晶体调节，不能代替分离所需原料。新收益回到S1既有产线，体现晶体研究有即时用途。

**初步模型**：把目标与晶体的已测粗谱归一化为非负向量p、r，暂用`M=Σ min(p_j,r_j)`表示重叠程度，范围0–1；以`w_target = w_base(1+gM·稳定度)`改变合法产物的分配权重，总产量仍受S1预算约束。M只用于这个初级模板，不是全部物质/频率相互作用的通用公式。发展线二的两路相位实验将明确展示其解释边界；届时新增相位模型，不追溯否定本模板的已有有效结果。

**实验**：匹配样本、换成不同样本、故意失谐三组对照。若只看总产出可能误判，应比较各产物份额、纯度和投入。后续掺杂或非线性设备可暴露粗谱重叠模型的不足。

> “晶体开始对不同的东西作出不同回应。我也开始能选择这种回应。”

### 4.2 从响应到信息，再到第一次反馈

**旧稿思想**：探针读取登记对象，封装InfoSignal，经频率总线、缓存和红石边界输出形成闭环。

先分清两类接口：分析仪通过晶体的物理响应识别性质；状态适配器读取允许公开的红石/机器状态，并用晶体编码传递。后者不声称能从任意对象频谱反推出一切内部字段。两类接口未来可以共同为模型提供数据。

```text
目标状态/响应 → 探针与明确读出规则
→ 带类型/来源/时间的信号 → 频率总线
→ 本地比较/简单缓存 → 执行器改变设备
→ 重新读取结果
```

第一条闭环选本模组分离设备的运行状态：先由手动开关验证探针和传输，再接“污染超过阈值→暂停进料/允许冲洗→恢复”。污染通道是本模组明确开放的设备接口；红石通道可作无需复杂适配器的教学起点。不默认原版熔炉可直接被任意红石输出停机。

**初步模型**：先用阈值和滞回形成可观察控制，附带信号失效时间。晶体失配造成无效/不可靠读数，执行端回到固定安全状态。编码和信息含义分开：选择频段不自动赋予任意数据语义，协议要声明传的是什么。

**实验**：故意延长线路/更换较不稳定晶体或暂停源端，观察旧读数和新状态不同步；加入时效检查或缓存策略后恢复。只变一次因素，不要求此时训练模型。

> “先前我用晶体改变材料。现在，材料的状态能沿着晶体回来，决定下一步操作。”

**S3结束成果**：从平均基底制造有差异的晶体，用它辨认并作用于对象，将信息传回并闭环控制。整个起步段没有离开卡玛恩晶体的线索。

## 5. 故事与后续发展方向：只留承接，不提前定案

| 已产生的需求 | 接下来的发展方向 | 保留的故事问题 |
| --- | --- | --- |
| 应力调节不能实现所有响应 | 组成/掺杂、晶片与精密制造 | 晶体内部还能怎样改变？ |
| 线路与简单控制承载不了复杂信息 | 光电并行的元件、结构、计算与存储 | 如何让多个响应组合成一种功能？ |
| 记录增加，经验判断失效 | 数据模型、预测、学习、策略 | 怎样把观察变成可检验的解释？ |
| 排除设备误差后仍有共同残差 | 世界底噪、多地/多层调查 | 剩下的变化来自世界的什么结构？ |
| 同类现象跨尺度出现，旧解释不足 | 微观与宇观交织研究 | 局部信息与整体边界怎样关联？ |
| 获得可靠的世界信息与作用方法 | 旧稿弦、视界、世界之心和规则编译 | 对世界的理解最终允许我们做什么？ |

“共同残差”先是观察问题，不提前写成文明留言或证明某个终局理论。已有故事和特殊名称等走到相关位置时，依据当时的研究对象挑选和调整。

## 6. 本段回看：已经需要归纳的共性

### 6.1 这次从流程中提炼的五条规则

1. **参考样品先于复杂解释**：均值化和晶种提供可重复起点，初级仪器只能验证部分性质。
2. **材料始终有质量来源**：晶种指导生长，原料供给晶体；信息指导加工，不直接变成物质。
3. **中性、质量、专化是不同指标**：专化远离背景不意味着品质变差。
4. **模型因新需求而扩展**：份额/污染→背景偏差→方向响应→选择性共振→时序反馈，组成与复杂计算留到对应工艺。
5. **每个研究成果回到已有玩法**：滤渣变晶种，晶体改进分离，状态反馈改善维护；不是连续领取无用途的解锁物品。

### 6.2 旧稿处理账

| 旧想法 | 本段处理 | 尚待深化 |
| --- | --- | --- |
| 圆石/分馏/滤渣/均值化/白噪晶种 | 保留 | 分离预算与成核辅助的完整物料表 |
| 起步筛需铁、首个锁相器需金 | 首版与精密版拆开，先保证自举 | 精确部件配方 |
| X导波/Y抗压/Z稳谱 | 保留三用途，改用局部方向与实际响应 | 完整应力/缺陷模型 |
