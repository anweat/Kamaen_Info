# L3：接界、视界与创世的具体任务演示

2026-09-09，[完整玩法稿](LATE_L3_COMPLETE_GAMEPLAY.md)中T08—T12的展开。这里给可落成原型的有限游戏模板，参数用于说明选择如何改变结果，不是已经平衡的配方或真实物理常数。前段操作见[谱纹与空间工艺](LATE_L3_MATERIALS_AND_FIELDS.md)，物件来源见[内容表](LATE_L3_CONTENT.md)。

## 1. 固定回响：让工场中的一条作用路径更好用

### 开始时已经有什么

已有一个能运行的世界切片、两种不同响应的测头、普通供给、接界棱镜、相容晶体载体和初级弦锚。棱镜从拓扑晶体、谱纹件与光路制得；锚的框架、控制与普通储备先造。首次全部通过普通线路连接，没有借用尚未得到的特殊链路。

任务来自一个实际订单：加工位置受到普通线路几何限制，玩家希望把某个已知模式稳定地送到工作位。先在已有局部区域完成耦合，再研究可搬迁载体和成对链路。

### 玩家逐步做什么

1. 在工场保存一条正常工作记录，带同一参考件到回响图上的可达位置。旋转和换测头后，确认差异属于哪类响应。界面同时保留原工场记录，方便比较。
2. 在选定区域摆入棱镜和接收件，接上普通线路。工程视图标出真实方向、选定频段、源端输入及接收端测量；只有标定过的区域显示预测覆盖。
3. 先扫少量频点，再在局部改变方向和相位。可以用模板手工操作，也可让已有计算节点枚举候选。发现较好条件后，留一个未参与选参的位置或工况作复测。
4. 用已有定向、稳定化和锁定工序处理实际载体，将受支持的耦合结构制成弦残迹，再装入锚。知识记录提供工序条件，载体提供实物。
5. 把锚接回工场，完成原来的实际订单。保守首版只稳定某一类局部模式；下一版成对端点才允许受支持的特殊连接。

### 调谐确实改变什么

首个边界通道可以采用如下游戏传输模板：

```text
eta_boundary = eta0 * d² / (1 + (delta_f / gamma)²)
               * (1 + V*cos(delta_phi)) / 2
E_out = E_in * eta_boundary
E_loss = E_in - E_out
```

其中d是两个已声明方向的单位向量点积，gamma>0为本载体的频率窗口，eta0与V在0—1内。路径没有被实际组件支持时不可套用此式。它替代该段的传输模型；不能再把相同的方向、频差或相位损失当成另一层品质惩罚重复扣除。损耗进入该模板声明的终端/热路。

令eta0=0.8、V=1、输入10：

| 实际设置 | 接收能量 | 玩家看到的下一步 |
| --- | --- | --- |
| 同向、频率匹配、相位差0 | 8 | 用这个工作点试制并做留出复测 |
| 同向、频差等于gamma、相位差0 | 4 | 调频可以改变传输；也可接受较低效率先使用 |
| 同向、频率匹配、相位差π/2 | 4 | 改相位或补偿实际路径，而非继续加同款测头 |
| 方向正交 | 0 | 调整实体棱镜/端点方向，移动图表节点无效 |

单个接收值4不能唯一说明是频差还是相位造成。补做扫频或改变相位的对照才能区分；这正是从“选到好参数”继续走向“理解规律”的解密玩法。

随机实验在固定规则下改变来料偏差、读出扰动和可声明的环境扰动。先保留同一载体/同一位置的配对对照，再换载体或地点检验适用范围；重开界面不重抽真实材料。失败留下实测记录和可重加工载体，不能用无关样本数量替代缺失条件。

### 得到特殊链路后继续怎么玩

首个端点模板每控制周期发送4个固定大小的信号帧。现场产生7帧时，4帧进入传输，3帧排队；增添接收器不会复制源端容量。玩家可减少非必要采样、分开控制与档案队列、增加一条真实链路，或者保留普通电/光通道承担大数据。

执行指令带有效期；迟到或离线期间积压的动作不能恢复后全部补做。遥测可延迟归档，控制需要现场基线。物品转移另需装卸与交付服务，一次交付只在确认后记入目标库存。

此任务留下的是一个可用连接方案、实际弦载体与调谐记录。更高带宽、更宽工作窗和跨维度服务成为后续建设目标。

## 2. 视界服务工场：先决定它承担哪一项工作

### 实物与面板

已有III型框架、约束件、弦锚、普通基膜、膜写入头、独立熄灭器和外部供给。专用熵流泵、霍金采样器、页读出或求解接口按选定用途安装。框架是实际模块的组装，围护不要求填满专属外壳。

统一工程入口增加实例页，首屏显示“用途、正在处理的对象、输入与交付、热状态、各约束点、停机储备”。选中异常点直接定位实际部件与线路。模型预估和读数分别显示，不把所有状态压成一个稳定度分数。

首个受控样机可用这些有限约束演示：4个约束点各自上限10；热缓冲容量80；停止接新料阈值64，受控熄灭阈值72；独立储备至少20。热量和储备使用同一配置下的记账单位，实际FE换算由实现固定。

负荷[6,7,12,5]虽然平均只有7.5，第三个约束点仍超限。玩家必须改变接口分配、调整结构或降载。热缓冲初值40，每周期产生16：排18时降至38，排8时升至48。调度不能靠漂亮的均值掩盖局部问题。

阈值是这台样机的控制配置；材料的真实工作窗仍分别检查。未知材料或热路超出模型范围时，界面提示当前预测不保证运行，不替玩家伪造安全读数。

### 三个可独立选择的订单

| 订单 | 玩家操作 | 交付验收 | 值得优化的方向 |
| --- | --- | --- | --- |
| 给织相工场供一批能量 | 装真实料、选择批量、接抽取通道与实际负载，安排冷却和停机储备 | 负载实收量、维护消耗、热和残料账目一致 | 处理速率、约束负荷、排热与批次交接 |
| 保存一份大型回响档案 | 选择已存在的记录、页布局、冗余、读写接口；写后读回，停机再恢复读取 | 实际页确认与读回内容一致；副本不算新增逻辑容量 | 密度、写入热、带宽、恢复时间和跨介质迁移 |
| 为工场找到一个新布局 | 提交有限候选、真实接口约束、工作集与预算，比较当前最佳可行解 | 候选能下发给现有工场试制，实测能与预测比较 | 生成策略、过程模型、求值分工与搜索范围 |

能量订单使用主专题的10份料示例：6份转化，净交付480、热120、剩余4份材料。外部启动另记。存储订单可先在普通盘保存原件，用64物理页演示32逻辑页双副本，索引另配。求解订单可用经典小候选集先核验，再将受支持的更大任务交给视界服务。

首次任务只需选一个有实际需求的订单，并完成停机/恢复。切换用途先停止接单、结清确认、保存中间状态，再更换接口与配置；不能在同一时间把整台容量同时报给三个用途。多台分工和维护窗口给集群调度新的价值。

### 失败仍然能继续建设

料箱空了就等待供料；读出中断保留未确认任务；约束点超载停止新处理并降载；储备不足不能开始下一批。掉线前已经交付的结果不会重试产生第二份。熄灭后的残留按真实剩余量收集，不每次开关机固定掉落一份黑洞残渣。

玩家能因此完成更大的工场、保存长时观测、试制过去枚举不起的组合。高性能计算的回报依旧落实到作品，不只用于打开下一台机器。

## 3. 把世界之心变成一个能使用的新世界

### 一份有来源的世界之心

选择一个已投入使用的谱纹/材料项目、一个区域或切片、一套边界实例及一处远端参照，交给巨型节点框架组织联合记录。其物理连接、采样时间、校准与数据来源都能追踪。集群整理分块数据，已存在的经典、光学和可选量子节点处理自己支持的部分。

同一次观测派生出的材料拟合、图表和摘要仍算同一来源。玩家安排一个未参与拟合的位置/工况，检查模型能否预测。无法辨识的关系以区间保留，先使用确定的规则范围制作世界；更好的模型随后开放更多可组合条件。

### 七组参数每一组都给实际选择

| 组 | 首轮模板选择 | 实际改变与约束 |
| --- | --- | --- |
| 地形 | 平缓陆地、分离浮岛 | 改变建设和运输布局；出生点、返回点及首个工作区必须有可执行通路方案 |
| 群系 | 温和、干燥、湿润的受支持组合 | 对应真实环境与适配对象，水/生物不是拖动图标就进入库存 |
| 物理规则 | 常规；已取得组件支持的局部低载荷区 | 后者需要相应作用结构及维护，不提供任意改写运动或跨界复制能量的接口 |
| 资源频谱 | 四类已登记资源族的相对分布 | 示例比例[0.4,0.3,0.2,0.1]，总和必须为1；实际丰度另受生成与维护模板限制 |
| 实体生成 | 支持的实体集合、容量与可用条件 | 与群系/空间相容，使用登记生成规则，不开放任意实体内部状态编辑 |
| 底噪结构 | 普通背景、某个已识别模式的较静工作域 | 调整对应世界实例的有限背景参数；其他热/机械/事件来源仍独立存在 |
| 维护与漂移 | 运行预算、缓冲储备、允许漂移范围 | 范围受当前结构与实测模型限制；不能用一个滑杆将全部成本置零 |

这些模板首先表达可以使用的差异；数值更细的控制随材料、观测与作用能力展开。资源频谱描述分布，不能兑换无限矿物；新维度仍采用同一组固定物质种类。

### 一次真正会改变决策的预演

为本例配置每周期10个维护供给单位；每个单位对应固定的接口供能，不混入“研究点”。基础世界需要2，静默工作域另需2，浮岛生成模板另需1，局部低载荷另需3。已有工场的运行接口需要5。

- 平缓地形＋静默工作域＋工场：总需求2+2+5=9，可以持续运行，余量1。
- 再加局部低载荷：总需求12，不能继续按10的供给提交。可以增加真实供给、缩小受控区或选择保守模板。
- 浮岛方案即使总需求合格，没有可执行的运输/通路方案仍不可交付；可以补桥梁建设计划、载具与材料，或修改地形。

维护例只是已声明模板的有限工况预算；不能替代实际工场热路、通量与返回储备的单独检查。玩家预演中看到的供给需求会进入建造清单；成功的方案下发后，需要先把工作点实际建起来。

初次原型可从九个区块的生成额度开始，世界边缘显示尚未开放的区域；扩展时再投入实际生成预算和相应维护能力。资源预估按已开放范围计算，调整资源频谱只作用于尚未生成的区域版本。已有地形和库存保留，不能反复改同一区域蓝图刷新矿物。生成新区域属于创世公设的单独有成本过程，工场合成仍遵守自己的实物账目。

### 制造、进入与持续使用

工程终端将蓝图写入真实核心，先预留一个空闲实例槽，在母世界建好独立返回锚与储备。点火环提交创建后绑定该核心；重复操作恢复同一笔未完成创建，不复制第二个世界。实际进入后，建设选定工场/采集点/生态区，完成一次交付，再离开、休眠、恢复并返回。

漂移表现为可观察的工作窗变化和逐级退化，先影响受控区的产出或附加作用；维护设施给复测、补给或降载选择。休眠保存实物与记录，不离线滚动灾难。人在内部时保留应急退出。已有世界改进规则先另存蓝图版本，不覆盖已建地形。

## 4. 贯穿三个工程的故事记录

记录随实际作品出现，不需要收集额外书页解锁：

| 实际成果 | 研究册中的叙事线索 |
| --- | --- |
| 同一母批做出不同谱纹 | “这块晶体留下了我们施加过的差异。工序已经成为它的一部分。” |
| 工场换布局，产物随之改变 | “位置、方向与到达的时刻，也参与了作品。” |
| 同一参考在多地复测 | “均值给了我们共同的起点。沿着差异，我们开始看见材料与世界之间的关系。” |
| 将边界关系固定到载体 | “一种曾经只能追踪的关系，现在能由我们维持和使用。” |
| 新世界中第一批工件完成 | “最初的晶种仍在工坊里。我们把一路认识的条件组织在一起，新的地方开始回应。” |

世界之心收束的是玩家这一路能观察、描述和构造的关系。留下未解释的模式，便能在创世后继续探索；已经掌握的模板则成为建设新作品的可靠基础。
