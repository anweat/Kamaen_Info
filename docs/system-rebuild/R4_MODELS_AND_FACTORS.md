# R4：模型、影响因素与功能规格

2026-09-07，阶段设计候选。入口：[R4总案](R4_STAGE_DESIGN.md)。本稿给出统一规则及可用于首轮实现的游戏模型；现实启发及其适用范围沿用[R3.3调研](R3_RACK_ENGINEERING_RESEARCH.md)，不把虚构晶体常数解释为现实材料参数。

## 1. 把影响因素归为八类

每类只向下游提供有单位、有对象、有适用条件的量。玩家默认只看当前任务相关的三项，展开后可追到原件及测量。

| 类别 | 拥有这些状态的对象 | 主要输出 | 玩家能做的事 | 典型代价 |
| --- | --- | --- | --- | --- |
| 材料与历史 | 晶片/区域/母批 | 组成、晶轴、残余应力、缺陷、响应参数 | 选片、定向、组成处理、退火、复测 | 用料、时间、不可逆变化 |
| 结构与接口 | 器件、封装、支撑、实际线路 | 占地、端口、接触、传播/耦合路径 | 拼接、旋转、对接、换封装、重布线 | 空间、材料、检修难度 |
| 供给与返回 | 发电机、供给模块、导体/储能 | 可用功率、压降/纹波、返回路径、余量 | 分路、缩短大电流回路、滤波、缓存 | 铜、热、共享上游容量 |
| 热与流动 | 芯片、热界面、空气区、管路 | 温度、温差、余热、流量、回流 | 导热、封口、风冷、液冷、错峰 | 风扇/泵功耗、振动、管路空间 |
| 机械与振动 | 底座、支撑、风扇/泵、敏感组件 | 源谱、传递响应、相对位移/加速度 | 换安装点、调支撑、隔振、分离振源 | 体积、支撑刚度、共振窗口 |
| 场与串扰 | 实际导体/回路、邻近源、敏感端 | 耦合扰动、串扰、读出噪声 | 改路径/返回、分区、局部屏蔽 | 线长、占位、材料；无万能屏蔽 |
| 信号与参考 | 源、器件、线路、采样器 | 波段、幅相、带宽、损耗、时序/同步、信噪比 | 选频、调相、改节拍、放置转换器、校准 | 转换与维持能量、延迟、误差 |
| 计算与资源 | 真实板/链路/运行实例 | 内存占用、队列、吞吐、版本、映射误差 | 分批、放置算子、移动数据、排任务 | 驻留内存、通信、排队、检查点 |

热噪属于产生噪声的机制，信号页显示它对读出的影响；不能再在“材料差”“温度高”“信噪比低”三个入口重复扣同一份误差。频率包括激励频率、谱坐标、时钟和机械振动频率，界面必须区分单位和参考域，禁止做一条共用的“频率等级”。

## 2. 每层模型的输入、更新与输出

| 模型 | 输入/自身状态 | 求什么 | 交给下一层 |
| --- | --- | --- | --- |
| 物质与加工 | 母批、组成、方向、工序历史、实际温程 | 新的实际物性状态 | 指定区域的响应及不确定信息视图 |
| 器件 | 物性、几何、接触、驱动、当前输入、内部状态 | 端口输出与下一状态 | 经测试的功能、工作窗、功耗/敏感性 |
| 封装 | 内件、键合/导波、外壳、热界面、映射 | 外部端口及实际中间路径 | 能安装和调用的模块能力 |
| 板/机柜 | 安装清单、背板、供给、支撑、风路 | 各局部条件与共享约束 | 可调度的本地资源、实际路径和测量 |
| 集群 | 在线节点、链路、任务、数据位置 | 放置、传输、排队、失败边界 | 可执行计划及证据，不能改写物性 |
| 玩家模型 | 数据、假设、参数、训练/推理状态 | 对现象的预测、误差与新实验提案 | 有适用范围的解释；不直接覆盖世界真值 |

共同记录使用 `object_id / revision / model_version / units / conditions / source_ids / covered_path / timestamp`。批次、工序记录和当前测量不塞在一组扁平属性里。对象修改使相关报告变为“需要复测”，不会删掉历史记录；与改动无关的证据可继续使用。

因子分为四种：改变状态的输入、传递函数、资源上限、观测证据。只有属于同一量及组合规则的因子才能合成。端口不匹配是硬错误；未测工况是未知；超过已测窗口是风险/降档。三者不合成一个红色品质分。

## 3. 初始晶种与可解密的物质模型

前期状态细化见[E1晶体模型](EARLY_E1_CRYSTAL_MODEL.md)：持久内部结构A与可松弛残余应力S分开，切片/器件延续同一对象来源。下文简写尚未展开A，不应理解为退火消除应力就必然消除全部结构特化。记号也需区别：本节旧`z`表示绝对背景属性，E1的`z`表示相对μ的偏差，即`z_E1 = z_R4 - μ`；两条均值化式在此换元后对应。正式字段与全局参数仍待讨论统一。

世界规则保存有限物质集合及其参考属性向量。晶体局部状态用 `c, O, s, d, h`：组分比例向量、晶轴取向、残余应力、缺陷状态、加工历史。各组分非负且和为1。平均背景参考 `μ = Σ p_k a_k` 的权重由世界规则固定；均值化减少的是相对参考的偏置。它不消除热涨落，也不凭空增加物质种类。

首轮可实现的降阶加工规则：

```text
均值化：z_next = μ + exp(-k_m D_m) (z - μ)
        D_m 为在有效温窗内累积的处理剂量；窗外可能增加缺陷
成核：有效过饱和 S>Scrit，且在允许冷却窗停留达到 D_seed 后形成晶种
应力写入：s_next = s + k_s * effective_load（受塑性窗口与饱和上限约束）
退火：d_next = d_floor + (d-d_floor) exp(-k_d D_a)
      s_next = s exp(-k_r D_a)；过热项另增缺陷，不靠 clamp 隐藏过热
区域处理：c_next = normalize(c + retained_dose * recipe_direction)
```

`z`是当前可平均化的背景属性状态，`c`是实体组分；上述均值化不能作为任意组分转换器。配方限定哪些原料能走这一过程。首次保守模板提供已知可达窗口；精确系数随世界规则固定，母批偏差固定，玩家通过留样对照逐渐拟合。随机性不在打开界面、取出重放时重抽。

成核只交付相对均一的初始参考。少量稳定母批偏差影响后续实验，但不生成无限刷词条的稀有神晶。偏离窗口得到未成核料、偏置料或缺陷晶，可复测、降用或按登记路线回收。最初采用固定机械温程和刻度读出，控制芯片随后改善重复性。

器件响应统一从该状态派生，例如：

```text
f_c = f_ref + a_c·(c-c_ref) + a_s·(O^T s O) + a_T(T-T_ref)
w = w_min + b_d d + b_g * geometry_spread
p = p_max * exp(-c_d d - c_j contact_loss)
φ = φ0 + k_L L + k_T(T-T_ref) + k_u u
```

系数和有效范围按“材料族×结构模板”登记，不能在器件换角色时重新抽一套。真实实现可以逐步替换局部模型，旧记录保留规则版本，不能让不同版本数据无标记混训。

## 4. 性质怎样成为功能

| 结构/功能 | 需要的物性与实体 | 候选求值与验收 | 限制 |
| --- | --- | --- | --- |
| 选频 | 目标响应片、输入/输出耦合、定向夹持 | `T(f)=b+(p-b)/(1+((f-fc)/w)^2)`；测试目标带/邻带，0≤b<p≤1 | 只描述被动强度口；不能用强度直接做相干叠加 |
| 相位/干涉 | 同源分束、两臂、调谐件、合束、读出 | `PA,B=Pin η(1±V cosΔφ)/2`，总输出≤输入 | 相位需要参考；温变/相对位移影响差分路径 |
| 电门控 | 区域片、输入组织、偏置、恢复级、返回 | 平滑阈值响应按低/高阈值读为逻辑；逐真值/边界扫描 | 原料非线性不能自动规定门型；输出不合法时标无效 |
| 保持 | 已验证门控、反馈结构、写/读/复位口、供给 | 按写门限更新q；否则维持或随保持模型衰减；检查等待/读扰动/复位 | 慢响应不等于存储；断供不能当持久记录 |
| 光电读出 | 吸收/转换区、偏置、读出/校正结构 | 测暗态、参考、输入扫描和噪声；单位转换显式 | 光变热不自动成为电输出 |
| 晶振/参考 | 稳谱片、驱动、反馈、耦合与参考口 | 频率/幅度、启动、温漂、抖动和供给扫描 | 稳谱片本身不持续供能；多个参考域不能无成本同步 |

门控首版标量响应取 `y=1/(1+exp(-(a·x-θ)/w_g))`，再按模板的恢复结构判低/高；中间区为不确定，不能任意四舍五入获得合格门。逻辑教学模板至少包含NOT及二输入与/或中的可组合集合。晶体提供可实现这些响应的材料基础，接法、供给、恢复和测试共同决定具体功能。

### 4.1 阵列不是免费的容量数字

目录中的同名料件有制造模板字段。`region_wafer`是材料状态，RAM阵列、控制微程序区、门控区是不同模板的加工结果；不能把未加工区域片直接当任意高密度内存。初版利用可重复接触图案形成宏阵列，精密流片提高密度/一致性，不是初次获得逻辑功能的唯一通路。

| 模板 | 必须真的做出的结构规模 | 含义与初次验证 |
| --- | --- | --- |
| 门控阵列片 | 16路恢复门控单元 | 实验台可展开端口和门型；测试向量覆盖被使用通道 |
| 保持阵列片 | 两片门控阵列组织16位写读保持 | 延时、保持、复位；故障位形成容量分档 |
| 电控制芯片 | 8门控阵列、4保持阵列提供64位内部状态，另1片区域片刻256×16位固定微程序 | 有限指令解释器、标量算术和固定诊断服务；任意程序/堆栈在实际外接存储中 |
| 工作页载片 | 2片区域阵列，每片8192个保持位；另4保持片服务寻址/写读控制 | 标称2048 B；地址花纹、写读、保持窗与故障区测试，控制位不再算用户容量 |
| 持久记录载片 | 2片非易失刻写阵列，每片65536位 | 标称16384 B；刻写、断供复读、版本提交；其记录机制与易失保持不同 |
| 电矩阵模块 | 8门控片+4保持片构成有限复用算术流水模板 | 规定标量乘加、寄存、循环寻址；逐内核数值测试；没有内部无限矩阵存储 |

这些规模是虚构材料的首版游戏宏结构规格，不能当作真实晶体管计数与现代芯片面积等价。目录专列“8192位工作阵列片”“固定微程序片”“65536位记录阵列片”及其加工/测试配方，封装只接受这些合格半成品，不能拿普通区域片直接替代。模板内部重复单元可折叠显示；已验证后允许批量复制，首件需用未封装测试片证明其结构/功能。少量坏位默认整页降档到测试通过的连续区，不自动赠送纠错；可选重映射表也占真实空间。

光门/保持首版采用相同16路/16位教学宏单元；8片光保持组装的光RAM为128位，即16 B短期状态，另窗口模块控制刷新。它不自动等价2 KiB电RAM。更大光阵列必须多装单元或完成新密度模板的工艺及容量检验。

### 4.2 首个光算子采用可实现的受限映射

双输入交替测试、互不相干强度编码或时分编码后，登记：

```text
y = A x，x≥0
A = η [[q,1-q],[1-q,q]]，0≤q≤1，0≤η≤1
```

这里q由双路干涉调谐得到，η由损耗测试得到。两个输入不能作为未知相干场直接相加后还套同一个强度矩阵。编码/读出、校准、工作量程、误差与调用时间均在映射报告内。首个练习为两个波段的混合/分配与反演拟合，不能把该模块登记为任意实矩阵GPU。负权、更多维度、差分编码、多级网格是后续模板；分解、额外通道和能耗必须显式计入。

## 5. 逐层累积的物理规则

热模型：每个节点保存热容C和温度T，连接保存导热G；显式热流成对加减。`C dT/dt = Pheat + Σ G(Tj-Ti) + Qflow`。热界面差改变热阻与温度，不能额外创造一份芯片发热。电输入、光输出、机械输出、储能变化、热耗散分别记账。关闭任务后继续冷却，不能停工即清热。

首版执行采用20 Hz逻辑步；热/慢变环境每0.5模型秒更新，必要时按最小热时间常数分子步，保证被动网络稳定。教学热样例 `C=600,G=6,P=120,Tamb=20` 沿用[R3.3验算](R3_RACK_ENVIRONMENT_PROBE.md)，单位为该模型的热预算单位。对真实工况的换算需在实现标定，不能把游戏E强行当J。

风路用有限空气区、风口和回流比例；泵/风扇工作点来自实际阻力图与模板曲线，质量流量连续。冷板→管→泵→换热器必须闭环；没有环境换热边界的水箱只能储热。首版不模拟连续流场，仍保留堵塞、逆风、回流和混合风冷的因果。

机械用有限振源频带与低阶支撑网络。敏感件分别登记加速度敏感性、相对路径位移敏感性；整柜刚体同动不直接等于两臂差分位移。共用源先合成带相位的传递响应，再算功率；只有声明独立的源才功率相加。隔振器在某些频带放大响应；不能逐层乘彼此不兼容的独立传递率。

场/串扰采用实际路径的邻近段、返回面积及敏感性模型。导体长度、供给回路、屏蔽覆盖和参考连接决定贡献；不实现全空间电磁求解，也不把“光学组件”标成对供给/热/机械全部免疫。

同一个子系统可用展开网络或经验证的端口摘要，两者必须声明覆盖集合且互斥。在封装报告已覆盖内部转换与损耗时，机柜只增加其外部路径。父柜的汇总只显示和约束子件，不额外乘一个“机柜质量”。

## 6. 背景、随机实验与可见知识

世界产生模型和仪器观察模型分离：`observation = sensor(world_state, probe_pose, excitation, local_environment) + sensor_noise`。源包括当地过程、有限背景频带、共享扰动；测到的所有残差不能都叫世界底噪。首版背景用固定地点/时间规则与少量频带源，允许玩家通过多地、多方向、昼夜和仪器互换去识别其差别。

每条随机流由世界种子、源ID和单调采样序号决定；母批偏差、加工扰动、测量噪声是三条流。重复开关仪器不会回滚序号。相关噪声可用 `n[t+1]=ρn[t]+sqrt(1-ρ²)σξ[t]`，独立ξ零均值单位方差；带宽、ρ和σ属于相应源，不把所有噪声称为白噪。

玩家实验先选问题、变量、固定项、样品分组、测量窗与成本。默认提供同母批对照、至少3次重复、交替测量、空载/参考四种按钮；进阶打开随机化与分层采样。数据至少记录时间、位置、工序历史、原始读数、校准版本及有效标志。可保存失败和反例，禁止只把合格批送入模型却声称预测全工况。

先展示曲线与可观测差异，再解锁拟合参数和模型比较。真实生成参数不是界面上可直接读取的物品属性；开发调试视图必须与玩家读数分开。后期参数发现允许多个可解释模型竞争，用留出实验决定预测能力，主线不要求逐字猜中作者公式。

## 7. 默认反馈与判定

每个运行对象最多常驻显示：当前功能/目标、最紧约束、测量可信范围。展开显示八类分组；点一项沿“来源→路径→敏感部位→任务结果”追踪。未知参数显示区间/未测，不能为了画漂亮热图伪造精度。

硬错误阻止通电/提交相应操作；软约束允许保存草稿、低档运行或带记录试验。默认保护为降载、停当前工序、保留记录。永久损坏仅限模型明确记录的过热/过载/机械破坏且有可见预警，教学主线不靠随机爆炸制造难度。

局部规则已有[R3.1器件推演](R3_DEVICE_PROCESS_PROBE.md)、[R3.2空间检查](R3_HARDWARE_ADAPTATION_PROBE.md)、[R3.3环境验算](R3_RACK_ENVIRONMENT_PROBE.md)。它们支持局部边界；整机求解性能、任意几何、工艺密度与实际体验仍需后续实现验证。
