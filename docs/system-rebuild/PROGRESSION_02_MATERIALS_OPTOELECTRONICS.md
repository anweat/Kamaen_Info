> 2026-09-07阶段统合：当前取得条件、玩法、物料、板柜与运行规则见[R4完整阶段设计](R4_STAGE_DESIGN.md)。本文保留思想来源和局部推导；与R4冲突处以R4为准，旧四托盘/双视图入门不再并列执行。

状态：逐段工作稿，2026-09-06。承接[发展线一](PROGRESSION_WORKING_DRAFT.md)的S1–S3，展开旧S4并重接旧S5/S6的器件入口。本稿的A–D是讨论分段，不是新的正式时代编号；不提前定案整个计算与终局系统。

## 1. 本段要回答的问题

玩家已经知道晶体可以写入结构差异，用频率响应识别对象，并把信息送回机器。现在遇到两个限制：某些目标在安全应力范围内始终匹配不好；几块各自合格的晶体接在一起，也未必能稳定完成同一项工作。

故事随研究记录推进：**改变内部组成→控制加工留下的差异→组织不同的信息载体→让器件共同完成实验。** 信息与频率仍是主旨，卡玛恩晶体同时进入感测、门控、传递和基准环节，不退化为只在配方里出现的材料。

主要旧稿依据：[阶段表§5–7](../Kamaen_Info_Stage_Content_Line.md)、[硬件设计§12](../Kamaen_Info_Hardware_TechTree_Design.md)、[EDA设计§4、8](../Kamaen_Info_Computing_EDA_Design.md)。保留工艺和功能，修订其中“电力不作信息媒介”“电气退场”和“全光五件套齐备才可计算”的旧限制，遵循已确认的光电并行方向。

以下方程均为待验证的游戏简化模型。命名沿用旧稿不等于已经实现相应真实物理；本段暂不增加独立物品ID。

## 2. A：组成特化——调不出来的响应

### 2.1 从应力边界发现新的变量

**旧稿提炼**：二代晶体、掺杂剂、N/P晶片和离子注入已有位置，但不能仅靠“升到二代”自动改变材料能力。

玩家先拿现有晶体做目标匹配。教程给出有限调节范围与可恢复的加载模板：继续加压只会增加缺陷，目标响应却仍不进入可用窗口。这个结果引出组成实验，不要求玩家消耗大量晶体证明所有应力方案都无效。

```text
现有分离线 → 已能获得的粉末/处理剂
稳谱粗晶 + 切片/抛光 → 空白卡玛恩晶片
空白晶片 + 定量掺杂剂 → 粗制组成特化晶片
粗制晶片 + 受控退火 → 可用于比较的试片
```

初版以登记的表层处理配方提供低精度入口；离子注入器是后续剂量与方向控制升级，不要求先制造本阶段的精密控制芯片。处理剂只能改变登记的组成方向，不能任意把一种现实元素转成另一种元素。

保留`kamaen_dopant`及其类型字段。第一轮只开放一种可获得的掺杂剂与两个安全剂量；施主/受主两类在结区实验时配对引入，避免把所有掺杂都限定为N/P分类。掺杂轴使用晶片局部取向，延续前段对固定世界XYZ用途的修订。

### 2.2 初步模型与玩家可解出的内容

先用基材组成向量c和掺杂剂向量d表示登记组分，两者非负且总和为1。若实际留存的基材与掺杂质量为m、a：

```text
c_new = (m*c + a*d) / (m+a)
r = a / (m+a)
f = f0 + A*r + B*s + C*r*s
```

这里s是沿测试方向投影的归一化应力，f是一个可测峰位摘要。最后一式只在首轮安全工艺窗口内使用，系数需保证输出位于仪器范围；峰位不是全部材料性质。新增交互项表达“同样掺杂在不同结构下可能效果不同”，不预先宣称真实机制已经被解释。

质量账使用实际留存量：未进入晶片的处理剂、切削碎料和废液另计。洗脱、扩散损失和分层组成以后再扩展；不把用掉的全部处理剂都算成晶体质量，也不把掺杂浓度当成凭空生成的标签。

**实验设计**：同一母晶切四份，交叉使用低/高剂量与低/高安全应力，保持厚度和测量方向相同。第一轮观察两因素是否分别有效，下一母批复验；若仪器看不清交互项，只记录当前误差范围，不要求猜系数。另留一份未掺杂参考片区分加工本身的影响。

随机性分开记录：母批差异由共享批次状态产生；每片工艺偏差由实际处理产生；重复测量误差属于仪器。再次读取不会重抽晶体属性，复制同一次记录也不产生新证据。实验顺序交错，避免低剂量总在冷机、高剂量总在热机时测试。

**收益**：获得应力单独难以达到的响应窗口，回到分离平台改善一类已有目标的选择性；不突破前段合法产物集合与质量预算。失败试片可降级用于宽容工况或有损回收。

> “原来我一直在改变它的排列。换入一点不同的组成后，同样的力写出了另一种回应。”

## 3. B：精密制造——相同配方为什么做不出相同器件

### 3.1 从试片到有空间结构的晶片

**旧稿提炼**：保留切片、抛光、掺杂、退火、掩膜、刻蚀、互连、测试链；独立模块先可用，II型框架再集中组织。工艺不再只是每次多消耗一种高级材料。

```text
可用粗晶 → 定向切片/抛光 → 空白晶片
晶片 + 接触模板 → 选择区域处理/粗刻蚀
→ 退火与接触装配 → 粗制结区/导波试件
粗制器件改善测量与控制
→ 投影光刻/定量注入/精密刻蚀 → 可重复制造的功能晶片
```

接触模板是`lithography_mask`的粗版工艺用途，先用普通刻写与机械对位。首套模板、夹具和热处理可手工完成；投影器、F2基准及精密调谐片组成升级链，不互相充当首次制作的前置。退火顺序由模板配方指定，不假设所有结构都适用同一套线性工序。

保留`kamaen_crystal_t2`作为候选检验等级/成品名称：它表示达到某类精密加工要求，不是所有属性同时变好。空白、N型、P型沿用`kamaen_wafer`状态；废品与可降级品分开，不只用一个“defect”标签吞掉失败原因。

### 3.2 初步工艺模型：退火也有代价

本轮只为可玩对照保留四个量：缺陷D、已写入应力S、图案误差e和测试响应；不立即要求玩家管理完整半导体参数表。

```text
D_after = D_before * exp(-k*t) + D_overheat
S_after = S_before * exp(-h*t)
```

k、h在登记的温度窗口内非负，t为有效保持时间；超温损伤单独增加。此候选刻意让退火同时修复缺陷、松弛已写入结构。因此不能“退火越久全属性越好”，也不能假设S2的应力在后续工艺后永久保留。工艺路线可选择退火后再做小幅校准加载。

图案误差先由对位、模板精度和刻蚀偏差组成。器件按用途分别验收：导波看透过与泄漏，结区看正反向响应差，参考片看重复漂移。二代晶体不能靠单一总评分取代这些指标。

**实验设计**：同母批试片使用短/中/长保持，复测峰位、宽度和重复漂移；比较“先应力后退火”和“先退火后校准”。工艺记录自动保留顺序，揭示材料具有加工历史，而不只取决于最后一次操作。

**收益**：提高S3探头一致性，减少频率总线失配，并允许复制成功器件。粗版仍可用，精密版增加密度、可重复性和环境容差。损坏掩膜可以重制，研究记录不与唯一物品绑定。

> “同一张配方没有留下同一种晶体。它记住了处理的顺序，也记住了我试图修补它的方式。”

## 4. C：光电并行——让不同响应承担不同工作

### 4.1 共同工艺基础，两条同时可进入的支线

这一段不要求先造CPU再研究光学，也不要求有光RAM才能进行电逻辑。基础材料、普通供能和手动校准足以让两支各自启动，桥接在两边都能独立验证后出现。

| 共同起点 | 电气方向 | 光学方向 |
| --- | --- | --- |
| 组成试片与结区加工 | N/P区域、接触结构→整流/门控试件 | 导波区域、表面/边界处理→导波与分束试件 |
| 稳谱晶体与参考信号 | 可重复的扫输入、阈值与低速节拍 | 粗稳定光源、强度参考与相位扫描 |
| 模板与刻蚀 | 开关、比较、简单保持单元 | 滤波片、相位调谐片与两路组合 |
| 测量与校准 | 输出电响应、发热与切换延迟 | 输出强度、损耗与相位漂移 |

电气信号明确承载信息；FE仅表示供能，不把电平值直接等同于FE库存。电气门控采用本模组晶体组成/结构的受控响应，材料和应力参数继续影响器件表现。光学也需供能、激励和测量；参考稳定度、相干条件与可用能量分开记录，不能用一个“相干能条”替代所有状态。

粗稳定光源与强度测量先能完成传递实验；相位组合实验才需要能维持相位关系的源。该源通过现有稳谱材料和手动光路校准获得初版，单频精密源与自动锁相以后升级。这里的自举路线是候选工艺要求，具体配方尚待物料核算。

### 4.2 电气实验：从响应曲线到一个可靠开关

**旧稿提炼**：PN结、晶体管门、寄存器与SRAM保留。先做单器件测试，再给宏单元模板，不让玩家一上来手绘整颗CPU。

玩家比较两种结区布置的正反向响应，再增加控制端形成门控试件。N/P两片简单叠放不自动构成所有开关功能；区域布局、接触和控制端都要由模板明确。

**初步模型**：首个数字功能使用带噪声裕量的双阈值抽象。输入高于θ_on时进入1，低于θ_off时进入0，二者之间保持前态；θ_off < θ_on。组成与应力改变阈值，缺陷与温度影响可用裕量和漂移。此式是教学开关的有效模型，不作为PN结的完整电流方程，也不把所有逻辑门都默认为有记忆。

**实验**：输入逐渐升高再降低，画出输出轨迹；在阈值附近引入已知扰动，比较无滞回/有滞回控制。初版可用预设扫描器和红石边界读出，不依赖本阶段尚未制造的ADC。

**成果**：沿用S3的污染控制任务，减少阈值附近频繁启停。进一步组合两个开关形成独立保持模板，为后续寄存器与状态机留下入口；正式存储仍须说明供能、复位与失效行为。

> “同样的输入可以触发改变，也可以维持已经发生的改变。材料开始替我保存一小段过程。”

### 4.3 光学实验：强度相同，组合后的结果为何不同

**旧稿提炼**：导波、分束、相位调谐、干涉结构是光计算的前置内容，不再推迟到完整计算五件套之后。

先测直通路径和弯折路径的损耗，再把同源光分成两路、调节一路并重新合并。旧S3干涉仪在这里升级为可拆分的实验模块：早期可用预装参考路径，本段开始改变路径与器件。

**初步模型**：在选定的两路相干教学模板中，取归一化输入功率P、路径透过率η、可见度V：

```text
P_out = P * η * (1 + V*cos(Δφ)) / 2
0 ≤ η ≤ 1；0 ≤ V ≤ 1
```

本式只计算一个输出端，另一端及损耗需计入功率账，不凭空产生能量。V表示本模板中可观察的条纹对比，不能直接当作量子相干度。扩大到不等臂、不等分束与多端口时再扩展模型。

**实验**：保持输入强度与样品不变扫描相位，观察输出周期变化；再改变稳定条件，看可见度变化。已有强度仪器足以观察第一轮结果，光电探测结随后把结果自动记录，不反向成为首次发现的条件。

**成果**：获得可调滤波/组合结构与更敏感的差异测量。S3的粗谱重叠仍适用于原来的分离模板，但不能解释这里的相位现象，玩家明确遇到第一个模型适用范围的边界。

> “两路光各自看起来没有改变。让它们重新相遇后，我才看见此前没有记录的差别。”

## 5. D：第一次光电协作——完成一台能自己扫测的实验装置

**旧稿提炼**：保留`kamaen_detector_junction`、`phase_tuning_chip`、`kamaen_oscillator`、`resonant_signal_cache`和信息诊断台，以及EDA的显式桥接思想。

玩家把电气扫描/节拍、光学响应与探测读出连接起来，自动比较一批晶片：

```text
电气步进控制 → 明确的驱动/调制接口 → 光学扫描
→ 样品响应 → 探测结 → 简单读出/缓存
→ 频率总线上的带来源记录 → 玩家比较曲线
```

第一台只做预设步进与记录，保持手动读数路径。粗ADC/读出模板从已验证的比较和基准模块发展；不假定有功能完整CPU、训练模型或精密DAC。跨域转换增加延迟、量化误差与能耗，不让任意电线直接当波导使用。

**初步模型**：在登记读出范围内`读数 = 量化(增益×输入强度 + 偏置 + 测量扰动)`。超量程标记饱和，不伪装成准确值；记录采样时间、量程、校准版本及是否有效。缓存不凭空提高精度，信号年龄和数据丢失沿用S3规则。

**实验**：先遮断输入测偏置，再用两个已知参考水平校准，并用未参与校准的中间水平检验。随后交换样品顺序，判断曲线变化来自样品还是设备升温；拔掉反馈/读出线路时保留无效标记，不继续拿最后一次值当新结果。

**游戏收益**：扫描一批晶片、生成可复用工艺记录，筛出适合导波、参考、门控的不同成品，回到既有生产线装配。玩家可以暂停、改步长、选择对照，不只是等进度条结束。

> “电路让每次提问保持顺序，光路把差别展开，晶体把回答送回来。我终于能比较那些来不及亲手记录的变化。”

本段终点是可重复的自动实验与小规模器件组合。下一段才把它们组织成EDA宏单元、计算与存储板、传感器网络；数据先有来源和用途，再出现数据集、模型训练与集群需求。全光五件套仍保留为光学专化路线，电气控制、存储与接口持续发展。
