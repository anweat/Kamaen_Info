# E1.1：从工艺模型推导前期机器与合成路线

2026-09-07，解释性制造工作稿。与[矢量力学合成](EARLY_E11_MECHANICAL_SYNTHESIS.md)共同作为本轮入口。[原100条目录](EARLY_E1_CONTENT.md)保留作对象索引，本稿负责解释它们为何需要、怎样制造及怎样组合。

用途续稿见[E1.2原版增强与发展动力](EARLY_E12_APPLIED_PROGRESSION.md)：以下工艺同时服务锻造、建设备料、搬运/矢量设施、探针与培育。材料模型不因应用变化重新生成属性；应用输出与观察另按[应用模型](EARLY_E12_APPLICATION_MODELS.md)衔接。

前中期衔接续稿见[传感器、仪器到集成电路](EARLY_MID_SENSOR_TO_IC.md)：把本稿的定向、切磨、接触、区域处理与热/加载用于可复用测头和控制试件，再以实际观测改善同一套制造工艺。

## 1. 制造设计的最小单位改为工艺

先定义“哪些材料状态在什么条件下怎样变化”，再决定用什么机器建立这些条件。数据层分开三个对象：

| 对象 | 保存内容 | 决定什么 |
| --- | --- | --- |
| 材料/界面模型 | 组成、几何、相态、结构、接触、允许转变与响应律 | 实际加工会发生什么 |
| 工艺程序 | 材料布置、源/工装、随时间的动作、测量/停止条件 | 玩家这次怎样处理材料 |
| 产品规格 | 尺寸、组成/结合、可测功能及其工作窗 | 当前产物能拿去做什么 |

工艺程序写“把这两层夹在这里，按此顺序加载/加热”，产品规格写“需要某个方向的低损耗接触”。把目标改成另一个名称而不改变实际程序，材料结果必须相同。产品规格失败也要保留实际产物，供后续补加工和诊断。

物品显示可以沿用“铜板”“导波晶体”等熟悉名称，内部由材料、几何和用途报告支持。解释性不要求玩家从原子开始，也不要求每一颗螺丝都做实验；紧固、绕线、简单容器和木石工具可保留少量直接装配配方，其功能来自实际内件及连接。

### 1.1 合成的数据根源：材料有哪些可能状态、怎样走到它们

每个材料族先提供一张“材料规律卡”，不是给每台机器各写一份输出配方：

| 模型内容 | 第一种卡玛恩基材中的含义 |
| --- | --- |
| 物质账 | 实际均值化基材与投入晶种；同组成的结构转变保留组分质量 |
| 可达内部状态 | 松散料、压实未晶化坯、部分晶化、连续晶化区；定向和缺陷另行记录 |
| 响应关系 | 接触加载怎样改变形变/孔隙，温程怎样改变迁移能力，当前结构怎样响应试探激励 |
| 转变驱动与阻碍 | 接触、孔隙、晶种作用范围、温度及加载共同决定是否进入可达路径；不能只检查原料名称 |
| 动力学与保持 | 转变有有限速率，退出条件后可能停下、回退或保留；需要继续处理的半成品仍有状态 |
| 代价与观测 | 记录能量项、实际流失/残留及尺寸变化；仪器读数由加工后的状态生成 |

初版可用有限状态族和连续状态量描述，响应与转变函数仍由设计者定义。其开放性来自同一材料规律能接受多种真实历程，并产生可推断的结果；不是承诺能在任意原料之间自动发现一种现实反应。

以晶种诱导为例，第一种材料候选把可达条件拆成三个可检验关系：

1. 装填/压制降低孔隙，增加晶种与周边基材的实际接触；其结果能先通过尺寸、回弹和粗读数检验。
2. 在允许的温度/局部加载范围内，有接触的区域以有限速率转变。最初教学例用`dξ/dt=k(1-ξ)`，k由这几个当前条件确定；保温本身不绕过缺失接触。
3. 随转变改变的结构又改变后续传递与响应，因此生产模型应在作业子步更新材料，不能全程沿用初始晶坯的传递表。首个数值例暂固定边界，只验证前两步中的时序关系。

相邻过程要共同求值。例如压实可能改善接触，局部塑性/摩擦又会产生热，过热可能增加缺陷；不能各算一次“成功率”后独立发出互相矛盾的产物。若某个子步可用能量或物料不足，应缩小实际转变量或细化计算，不能先把状态加满再补负库存。

### 1.2 频率信息怎样进入制造规律

材料的试探响应可写为带条件的`H_material(f, direction, state)`。装置还有自己的路径与接触响应，两者一起决定某种激励实际到达哪个区域。调频是选择作用方式；改变材料结构则改变它将来怎样接受或传递同样的激励。

制造规律再根据实际局部作用更新状态，新的响应由更新后的状态派生。因此完整关系是“旧响应决定作用→作用改变状态→新状态产生新响应”。高幅加工中不能仅靠线性H推断一切，仍需对应非线性工艺模板。

这也是早期模型学习的核心：先辨认一段曲线与一种工序之间的局部关系，之后发现温度、孔隙或界面改变让旧模型失效，再加入新变量。晶体材料模型持续扩大解释范围，前期记录和器件/集群模型使用同一来源体系。

## 2. 前期需要的八类过程

| 过程 | 关键状态 | 输入/操作→状态改变 | 产物流与可见证据 |
| --- | --- | --- | --- |
| 粉化/解离 | 粒径、团聚、裂纹和组分位置 | 接触/剪切/冲击使团块解离 | 粗细分布、残块及新暴露组分；不直接增加铜含量 |
| 分流/富集 | 各组分质量、粒度、流速、过滤/耦合响应 | 实际输运与选择性分配到出口 | 目标料、混流、余料；称量与混入支持解释 |
| 热处理/均值化 | 内能、温程、背景偏差、缺陷 | 有效保持让合法基底接近平均参考，失控温程改变缺陷 | 均值料、未处理料、污染残留；粗谱与温程对照 |
| 成形/致密化 | 孔隙、体积、形变、回弹 | 接触加载与模具约束改变几何/紧密程度 | 板、线坯、粉体坯、衬块；尺寸/回弹/裂纹 |
| 晶种诱导/相态转变 | 晶种接触、相态ξ、局部温度与力学历程 | 在可达窗口内逐步转变，退出后可能保持或回退 | 晶化区与未转变料；同组成可有不同结构 |
| 界面构造/结合 | 接触面积、污染、间隙、结合b | 清洗、贴合、压持、有限滑移及适用温程 | 接触件、复合衬板、夹具内件；剥离/接触损失 |
| 结构调理/定向 | A、残余S、缺陷、方向响应 | 合适的加载/退火次序改变其中部分状态 | 方向母晶、稳定参考、可用耦合区；加工前后曲线 |
| 切分/装配/测量 | 实物区域、几何、端口、已有响应 | 切取实际区域并连接；测量增加知识 | 成品件、边料和报告；位置/来源可追溯 |

每一过程都有自身的状态更新与适用范围；同一台机器可以支持几个相容过程。强冲击适合的作用范围、保持能力和温程不必与压机相同。先让每个源族有可解释的能力差异，再由任务决定哪条路线更便利。

## 3. 五种具体装置怎样从这些过程长出来

这些是实体组织候选，原目录中的工装可以落在其中，也可为连续生产做专机。

| 装置家族 | 必要组成与物理能力 | 首次可以做什么 | 升级为何有效 |
| --- | --- | --- | --- |
| 材料处理槽 | 容器、搅拌/输运、可换滤材、分开的出料与清洗 | 制浆、沉降、粗分流、回用 | 加驱动提高可维持流量；加分级腔控制停留；加实际共振工作腔改变选择性 |
| 热程坩埚/炉 | 耐热容器、热源、隔热与冷却位置 | 金属/玻璃陶瓷的登记工艺、均值化、晶种制备 | 增加温程重复性和均匀性；相应工装可支撑晶化和稳定处理 |
| 加载装配台 | 台架、普通压头、可转夹具、接触工装、可接驱动和读出 | 板坯/粉坯、加载对照、简单贴合、晶体安装 | 加实际热工装和更好接触使热压/界面处理可达；加方向读出改善调理 |
| 脉冲工艺腔 | 源、可交换路径、靶/模具、边界衬层、收料与残留处理 | 粉化、冲击压实和首批晶种诱导处理 | 增加可控到达、适配源、温程和相容多区域工装，扩展可处理历程 |
| 连续牵引/切磨机 | 驱动、模口/辊或切磨头、进出料支撑、实际冷却/收屑 | 拉/轧线板、定向切片和批量整形 | 更稳定几何与接触，减少反复装夹；产能来自连续输送而非额外属性倍率 |

测量与记录作为设备外接能力共享。普通发电、泵和搬运继续支持这些装置，其内件和实际供给独立存在。台架可共用不意味着一个任务可以同时占用两个互斥工装；专机的价值包含独立产能、工作空间及稳定装夹。

首台普通机械加工从手动工具、原版金属或手筛自举取得的金属开始。高级接触和晶体压头改善已有装置，不作制造第一台晶体装置的前置。

## 4. 六条有材料依据的制造路线

### 4.1 导线与线圈：从几何和绝缘得到功能

合格铜料→成形为线坯→通过模口牵引/轧制，累计塑性变化并必要时按登记工艺调理→实际长度/截面的导线→加绝缘→绕制并装接头。

玩家先用保守模口做粗线，之后可以用多次较小变形或更好的中间热处理减少开裂。导线规格来自截面、连续性、材质和绝缘；线圈还要有绕制结构、连接和磁性内件等实际功能条件。一次“铜+共振”不能代替线长、形状和接线。

短粗馈线、长细传感线和驱动线圈由不同几何任务区分，沿用同一套材料加工；晶体稳定读出或耦合控制能够改善尺寸重复性。

### 4.2 反射衬板与缓冲：改变波路的材料有何不同

普通承载板先由金属/石质结构装配取得。进一步用基底、结合层与面层，在加载台上形成可用复合衬板；未结合区会改变接触响应，受冲击后也可能分层。

缓冲则来自颗粒、孔隙、容纳结构和可重复的填装；预压实会改变其响应，因此同名砂层经过多轮使用后不能永远保留初始包络效果。对应材料的响应表由低档对照与指定脉冲测试逐渐获得，不直接填“反射+20%/容错+20%”。

这条路线回到脉冲腔：玩家想延长到达或降低尖峰时可以换路径、换缓冲厚度或换材料状态；做出的衬板也必须经过实际安装。

### 4.3 平均背景晶种：把最初的参考做出来

可追溯滤渣/基材→分离掉登记杂质流→在有效温程内均值化→按已知保守成核/冷却程序取得晶种，留下一枚作参考。

这一过程的“接近世界背景均值”是卡玛恩世界的材料设定。粗仪器先能检验少量通道是否更一致，后期模型才逐步解释更广的平均性。世界底噪模型不在第一炉自动揭晓。

同一均值化料可以成为晶种源，也可成为后续晶坯基材；成核量受实际物料、容器和历程约束。第一枚晶种仍可由普通热工装取得。

### 4.4 可用粗晶：压实、转变、保存结构

均值化粉料＋实际晶种→定位/成坯→局部可达的热—加载历程→保持/卸载/冷却→测得晶化区→切取合格区域。

先提出两条候选路线：脉冲腔提供短时作用，另接保持/冷却；热加载台提供更慢的压实和转变，但受其局部可达窗限制。不能预先保证两者可处理所有同尺寸样品；应由第一种材料族的模型确定各自能交付的粗晶范围。初期保证至少一条已知保守路线可达。

半晶化坯仍可继续处理。配方卡记录的是“某批基材在某模具中的成功过程”，不是白噪晶种与能量换取新物品的定额券。

### 4.5 粗耦合件：形状、结构和接触共同决定传输

已测母晶→选择实际方向/区域→切磨到可安装几何→接触面处理→装入普通夹具与输入/输出传递段→低档扫测→生产对照。

玩家可以先调源、改夹持和路径；这些调整到达限制时，再尝试改A、调残余应力或重新切取区域。构造卡保留接触与来源，使一次好的加工结果能够重复制造并装到已有处理槽的工作腔。

### 4.6 粗复合接触件：为中期器件与封装准备

导体片＋绝缘/晶体基底＋登记中间层→清洗→按真实层序定位→相容加载/温程→检测结合与接触→带外部接口安装。

如果材料族和设备允许，可选择较慢的热加载结合或有限脉冲辅助结合。它们影响界面、损伤和可达面积，不因选择另一个机器名称就自动改变导体成分。早期产品用于驱动/探头/热接触，后续发展为局部图形、区域器件、封装接触和实际线路。

## 5. 用一条生产问题串起学习

**当前问题：分离工作腔时好时坏，玩家要让同样设置获得更重复的结果。**

1. 记录处理槽的流量、混入与参考读数，先找出是物料还是激励传递在变。
2. 检查耦合件接触，发现重装后响应变动；在加载台试制更稳定的接触层。
3. 制接触层所需的衬块本身有孔隙，促使玩家学习压实及回弹。
4. 改好的夹具用于粗晶脉冲合成，减少因工件位移导致的到达/作用差异。
5. 更一致的母晶再做耦合件，回到原处理槽做留样验证。
6. 将实际材料、结构、过程与结果存成工序卡；固定统计台拟合一个局部关系，后续B01接走完整记录。

这一循环产生的机器增长由生产问题推动。玩家可以保留共享实验台，也可以为固定工序复制一台专机维持产能。

## 6. 工艺界面与自动化

共同入口从“目标规格”进入，再展开“原料与层序→实际装置→工序时间线→观测→产品用途”。目标页只用已有模型和模板给建议。未测预测带适用范围，实测曲线保留探头/时间分辨率。

时间线的首版动作为：装夹、预热、加载/脉冲、保持、冷却、卸载、测量、收料。逐步允许条件停止与有限循环；它们调用真实执行口，仍须消耗供给与材料。首台可以使用固定机械序列，晶体反馈和中期计算提高控制能力。

失败页优先展示一条与证据相符的因果链，例如“右侧实际到达偏晚→共同加载不足→内部转变不足”。未装到达测量时只能显示待验证解释，不能把内部真值包装成仪器结论。建议下一次改变一个变量，保留同批对照。

工序卡可以复用到具备相容能力的另一台装置，但必须重新绑定尺寸、端口、路径及相应校准。源族/接触/污染不同即使总能量相同也不能直接声称等效。

因此原目录中的100条不是逐项解锁任务，也不是已经确定要注册的100个实体。保留旧内容去向，但首套装置数量和复用方式按工艺体验重新收敛。下一轮应先做“一个处理槽、一台加载台、一个脉冲腔”之间的空间与操作原型，再决定哪些工装值得独立为机器。

本稿已把工艺对象、操作、物料流和中期去向连起；尚未冻结全材料响应律、最终机型数、配方数量或游戏代码。数值检验范围见[有限过程例子](EARLY_E11_PROCESS_EXAMPLES.md)。
