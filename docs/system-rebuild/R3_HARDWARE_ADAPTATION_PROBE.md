# R3.2：空间、接口与因子传递的有限检查

配套[R3.2适配讨论稿](COMPUTING_R3_HARDWARE_SPATIAL_ADAPTATION.md)，由[r3_hardware_adaptation_probe.py](r3_hardware_adaptation_probe.py)生成。

这是作者侧的游戏契约例子。未实现Minecraft坐标/方块、碰撞寻路、完整光电响应、热仿真或真实调度器；数值不是器件出厂规格。

## 空间与端口

器件局部端口(0,0,0.5)、外法线+Z，经封装偏移(0.5,0,0.5)、托盘偏移(0,1,0)、机柜绕Y旋转90°及世界偏移(10,0,5)，得到世界位置(11,1,4.5)、外法线+X。信号职责仍为输出。

本例使用统一示意长度单位；尺度测试只覆盖正的均匀缩放。真实各层需明确尺寸单位与安装转换，不能把芯片微结构长度当世界方块长度。

## 贡献与容量

固定工况下，同一无源强度路径的输入耦合、选频区域、输出耦合与外部路径展开为0.9×0.8×0.9×0.95=0.6156；模块报告0.648已经包含前三项，再接外部0.95得到相同结果。重复追加内部输入耦合0.9会被拒绝。此乘法不适用于任意相干分支或有源转换。

数据路径有64、16、64 B/tick三个串联限额时，上限为16 B/tick。两份各64 B数据共用64 B/tick上联，在此仅含传输的示例里至少需要2 tick；两个节点不把该共享上联复制为两条。

## 检查结果

- 通过：器件到封装到板柜的坐标变换可追溯。
- 通过：四次直角旋转恢复坐标。
- 通过：共同刚体旋转保持相对晶轴投影。
- 通过：尺度换算不把单位法线放大。
- 通过：镜像或负尺度不能伪装成普通安装旋转。
- 通过：对接条件齐备的端口连接。
- 通过：同位置但同向法线不直接对接。
- 通过：朝向相对但位置不对不能直接对接。
- 通过：旋转不改变信号输入输出职责。
- 通过：相同光介质与连接头不保证同种信号。
- 通过：选定频带不兼容时不能直接对接。
- 通过：没有实体桥接器无法转域。
- 通过：强度编码桥有供给即可按自身契约工作。
- 通过：相干编码需所声明参考。
- 通过：普通强度读出不能冒充相位读取。
- 通过：包光链路接收无需整网相位参考。
- 通过：失去桥接供给时路径不可用。
- 通过：展开与封装报告的同一物理路径损耗一致。
- 通过：报告已含的内部贡献禁止重复叠加。
- 通过：无源转接后的带宽仍受实际窄段限制。
- 通过：共享上联不能按节点数重复分配。

共21项指定检查通过；这里只验证这些有限变换、接口条件与计费反例，不能据此声称整套硬件或任意布局可运行。
