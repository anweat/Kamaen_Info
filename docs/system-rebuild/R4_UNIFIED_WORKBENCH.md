## 1. 一个工程项目，按对象走到需要的视图

工程册从粗工具阶段取得，右键实验台、封装台、板、机柜或节点都打开同一个工程入口，并定位所选对象。工程工作台是后续带计算/存储服务的实体终端；并不再复制一套蓝图软件。项目可以包含若干关联作品，例如“退火观测站”包含终点芯片、B01板、采样节点、模型和实验数据。

```text
工程：退火观测站   版本 v7草稿   实物：柜A / 托盘A / B01
阶段：实验搭建 → 制造与封装 → 硬件组装 → 部署与运行 → 研究记录
┌────────────────┬──────────────────────────┬─────────────────┐
│ 对象树/资源库   │ 当前对象的结构或模型画布   │ 目标与测量       │
│ 柜A             │ 实体轮廓、端口与实际路线   │ 功能 / 最紧约束  │
│  └托盘A         │ 数据/供给/热/机械等图层    │ 原因与修复选项   │
│    └板B01       │ 可选对照：计划 vs 已安装   │ 材料 / 工位      │
│ 模型M01         │                           │ 校准 / 版本      │
│ 数据/实验       │                           │                  │
└────────────────┴──────────────────────────┴─────────────────┘
底栏：检查  试接/自动搭线  测试  生成工单  装配/部署  记录结果
```

小屏分成对象抽屉、主画布、详情抽屉；默认只打开当前操作必需内容。点一个错误在画布高亮具体端口/工序/资源，再显示一条可做的修复。未完成作品可以保存、标注和分享模板；不把通过所有检查作为保存门槛。

| 页面 | 主要操作 | 权威数据 | 提交后产生什么 |
| --- | --- | --- | --- |
| 实验搭建 | 放真实器件、旋转/夹持、接源与读出、扫参 | 台上实际对象、通道与测量 | 功能原型、测试记录、可复用结构模板 |
| 制造与封装 | 选材料状态、工序模板、壳体、端口映射 | 设计版本、制造路线、实物工位/在制品 | 工单、半成品、批次报告、封装实物 |
| 硬件组装 | 装板、插托盘、接背板/外线、布风路 | 实物包含树与实际连接图 | 已安装状态、验通/负载报告 |
| 部署与运行 | 画算子图、选参数/数据版本、放置任务 | 模型语义图、资源快照、执行计划 | 实例、占用、输出/检查点 |
| 研究记录 | 比较曲线、拟合、设计新对照 | 原始记录、派生数据及来源 | 模型候选、证据、下一张实验单 |

物理包含树和模型语义图不能混为一张图。用户在模型中拖远一个MatMul只是排版，不会加线长；移动机柜里的模块确实改变位置、接线及环境。两张图通过“这个算子由哪个真实内核执行”绑定，双击可跳转。实验结构被封装后仍可展开内部件，不要求再画一份无关原理图。

## 2. 入口怎样自举，不赠送看不见的电脑

工程册可做：静态说明、模板记录、有限类型/几何规则检查、可达范围内的幽灵投影、物料计数、已获得读数的显示。记录容量来自放入的研究记录载体，首版每张容纳4 KiB规范化静态内容，册子初带两张；它是人工记录载体，没有给程序随机寻址/自动连续写入的服务。项目编辑的短暂UI状态不充当世界中可运行的工作内存。离开时须保存到可用载体，满时先归档/换片；后续导入电子档案占实际记录载片空间。

工程册不能执行任意训练、解出隐藏物性或远程制造。初次实验用固定步进测试器和刻度/读出探头；它们的机械序列、固定比较和本地炉控无需通用CPU。早期检查只确认规则、端口和已知模板，不给未测原型凭空生成准确响应。

[E1补充的早期分析](EARLY_E1_CRYSTAL_MODEL.md)允许工程册整理曲线与手工拟合，并绑定一台真实固定统计台处理最多16条样本的指定统计。自动统计需该台的电源、工作区与记录载体；它不是通用编译/算子服务。模型卡和原始记录可继续导入B01，因此“研究记录”视图可以从前期使用，其自动计算能力随实际设备扩展。

第一块B01之后，连接板上有限编译/拟合服务，工程册可作为这个服务的控制界面；新造工程工作台则消耗另一块实际B01。运行服务的板、内存、供给、存储和网络都占用，不把终端内板同时拿来组柜。节点内置有限管理服务可建立两柜直连，独立编排节点为后续规模升级。

早期施工由玩家在可达范围放入实际部件、确认连接，游戏帮助对齐和走线；批量装配由已存在的封装/装配工位在其工作范围执行。跨区块建设需要加载区域及实际可用施工能力，不从背包远程瞬造机房。

## 3. 设计—制造—实物的版本与状态

```text
项目草稿 → 静态检查 → 试验原型 → 带条件的测试通过
   ↓              ↓                    ↓
继续改稿       保存失败记录         锁定制造版本 + 物料/工位清单
                                      ↓
                          预留 → 加工/装配 → 实物复测 → 能力登记
                                                            ↓
                         模型定义 + 参数版本 → 部署计划 → 运行实例
```

静态通过不能跳过实体复测。实验数据来自实际测试任务；预测曲线标为“模型预测”并显示适用范围。台上原型含外置电源、参考源或读出时，封装向导逐一询问其去向：装入、作为外部接口，或当前功能不再成立。不能删掉画布上的电源还保留无限驱动。

制造有两种路线：真实模块装配与区域/整片制造。切换路线会重新生成工序和物料账，不能同时扣已做器件与它们的制造原料。压合前可以撤销并释放预留；材料经过处理后，撤销只停止剩余工序，已发生的变化留下半成品。模板修改开新版本，在制批固定旧版本。

同一ID在仓库、台面、壳体和机柜间转移；装入父件后不能继续作为背包材料。拆装记录内件及消耗连接件，历史报告保留但相关适配/校准失效。世界物品、项目结构和库存显示只引用这一个对象。

## 4. 自动搭线的五种任务

默认操作是选两个端口，界面给出兼容路线；也可选择一组已声明连接需求后“完成剩余连接”。自动搭线处理连接工程，不替玩家决定模型数学含义。

| 任务 | 系统可自动做什么 | 必须保留的区别 |
| --- | --- | --- |
| 模型语义连接 | 补形状/类型兼容边，提出显式转换节点 | 不制造世界线缆；不暗自改公式或广播维度 |
| 插座/背板对接 | 按接口定位销、端口映射完成盲插候选 | 插上≠已通电合格；方向/深度/接触须匹配 |
| 数据与光路 | 在可用层、线槽中选择合法线/弧路线 | 铜包、光包、强度、相干场、参考口不同 |
| 供给与返回 | 同时规划供给、返回、保护与容量检查 | 不能只画一根供能线；同上游容量只算一次 |
| 冷却闭环 | 连接出入口、泵、冷板、换热器并验回路 | 管、流体库存、流阻与散热边界均须真实存在 |

没有兼容通道时显示“缺转换器/接口/通路”，并提供所需实物候选。用户选择转换方案后才加入物料单；禁止把电端自动改名成光端，或悄悄合并不同参考域。

### 4.1 路径的唯一几何

每条实际线路记录端点ID与局部姿态、所经层/槽、直线与圆弧段、截面/外径、材料、锁定段、安装状态和占用资源。渲染、材料长度、传播/耦合、碰撞和检修都读这份几何。装饰线不得代表另一个物理长度；折叠内部件时可以隐藏细节，端口摘要仍引用同一覆盖集合。

线路提交前至少检查：

1. 两端载体、信号表示、协议、参考要求与方向兼容；电源端不会接数据端。
2. 起止段沿端口允许引出方向，满足直段长度；实际对接存在。
3. 线/弧的扫掠体避开实体与禁布区，弯曲半径不低于线材规定。
4. 层间转换和穿孔有实体连接件；供给线检查返回，冷却管检查密封连接和闭环。
5. 线槽截面容量、分区及检修/托盘抽出包络有效；不同线可并行但不能占同一实体空间。
6. 材料数量与连接头、损耗、链路预算有效；现有被锁线路保持原位。

晶体器件内部微结构线长使用工艺单位，板级走线使用板单位，世界线缆使用方块长度。转换由物理封装/板模板确定的正尺度完成；显示缩放不会改变材料长度。几何镜像可能改变手性结构，只有模板明确支持时才可镜像；普通旋转用合法刚体旋转。

### 4.2 可实现的有限寻路方法

先枚举可用布线层和线槽图，按占用、端口及用户锁定段裁剪；再用确定性最短路搜索生成有限候选。为候选拐角插入合法圆弧，并用扫掠体检查碰撞、直段和包络；失败则尝试下一候选。首版每条最多评估8条候选、每次最多处理32个未连接需求；更多需求分批，可暂停，不承诺全局最优。

跨多条线默认顺序：固定/关键连接→供给与返回→参考/精密光路→普通数据→辅助管线；有预先占用的管路时视为障碍。优先顺序可以调整并重新预览。候选图以建造格/现有槽为骨架，最终物理线使用实际曲线，不能把搜到的折线直接当合格弯曲线。

硬约束先过，再比较材料、拥挤、串扰暴露、传播代价及维护便利。界面提供“省材料”“便维护”“留扩展”三种权重预设，显示各自实际指标；它们不能放松弯曲、类型、过流等硬限制。搜索失败明确是“在当前搜索范围未找到”，不宣称数学上无解。

### 4.3 预览、施工、维护

预览同时显示端点、高亮通路、材料清单、新增转换器、预计损耗/未测项和受影响报告。草稿不扣物料、不占世界通道。提交先校验对象/地图版本，再原子预留库存和通道；缺一项则整批不开始。施工逐段落地并消耗，已落地部分可保存为未完成线路，任务取消释放未用预留。

运行中的柜变更先进入检修计划：哪些任务需要排空、哪些能在其余节点继续、哪些检查点能恢复。重新搭线只改选定范围；自动保留手工锁定段。两个人同时改同一线槽时后提交者重新规划，不能都认为自己拿到了空位。

供给/参考断开使受影响实例进入对应失败状态，不能把它解释为所有柜都掉算力。恢复后先验通、检查版本/校准，再继续允许恢复的任务；不能沿用断线前的缓存读数假装新测量。

## 5. 可照着操作的两次演示

**第一次封装退火终点芯片。** 从实验台打开工程册，放选频件、读出、两片门控与窗口模块。选择“连续三次有效读数处于0.65—0.80”，系统只提供接线需求和测试向量，玩家可自行实现等价结构。试接后扫描短脉冲、三次有效、过期、离窗、换批；曲线和ready灯一起显示。验证通过后选壳体，确认外部供给/样品输入和ready输出，工位列出实际内部件、导线和热界面，压合后重新运行同一测试。炉子保持自身本地温控和联锁，ready只允许它按本批次确认一次结束请求。

**第一次给双柜接线。** 从柜A打开同一项目的硬件组装页，加入已存在柜B；选A的数据面板口和B对应口。短路线穿过托盘抽出区，界面标出“会阻止前维护”；另一条沿柜侧理线槽，稍长但合格。选择后显示两端接头、线材段数和共享出口预算。点击施工，消耗实际线材；验通后部署M01，画布高亮实际数据经过的板NIC、背板、面板和柜间线。拔掉其中一段只中断该路径，模型图仍保存。

## 6. 界面验收与实施边界

| 用例 | 应观察到的结果 |
| --- | --- |
| 在台面、封装内部、机柜中打开同一芯片 | 同一ID/历史，正确层级面包屑；库存无副本 |
| 未测样片点击预测 | 仅已知模板/区间，不出现真实隐藏参数 |
| 旋转模块90° | 所有物理端口与晶轴随合法变换；I/O语义不反转 |
| 移动模型节点 | 只改画布；真实线长与物料不变 |
| 铜包口接相干光口 | 阻止直接连接，指出所需编码/物理桥接 |
| 最短路线弯曲太急或遮挡维护 | 自动尝试其他候选；不能以减少损耗为由通过 |
| 物料不足/线路占用被别人改变 | 不施工、不扣部分未预留材料；给更新后的差异 |
| 中途取消加工/搭线 | 保留真实半成品与已落地线段，释放剩余预留 |
| 修改封装/权重/校准 | 各自版本变更、相关证据失效，运行实例仍绑定旧版本或按策略停机 |
| 存档重载 | 项目、实物、在制工序、线路预留/已完成段、随机采样序号一致 |

本稿确定产品行为及可行的有限算法边界。当前验证只覆盖部分规则反例；尚没有完整寻路器、Minecraft模型/线路渲染、多人事务或UI实现。优先实现一张实验台、一块板、一柜两托盘与直连两柜，再扩展复杂空间，不以首版穷举任意机房布局为前置。
