# L2.1：后期的三个作品目标与第一段具体玩法

2026-09-09，连续玩法细化候选。承接[L2方向](LATE_L2_INTEGRATED_PROGRESSION_DISCUSSION.md)。这一轮先收拢后期的目标与推进方式，再将首段写到可以讨论玩家操作、制造来源和实际收益的程度。没有实现游戏，没有冻结配方数值，也未重排全局能力图。

本稿首段作品继续有效。当前已接到[L3完整后期稿](LATE_L3_COMPLETE_GAMEPLAY.md)，补齐谱纹制造、工场、世界切片、边界、视界与创世，并生成[86项整合科技图](LATE_L3_TECH_TREE.md)。下面尚未重排等描述保留本稿成稿时的边界，不代表L3现状。

## 1. 后期先围绕三个能够看见的作品

建议后期的主体验是：**将已经理解和使用的响应关系，逐步组织到材料、场域和新世界中。** 玩家越来越能够决定一个过程怎样发生，信息中心则把制造、观察、计算和执行组织起来。

| 作品目标 | 玩家最终拥有的东西 | 完成之后的新自由 |
| --- | --- | --- |
| 一件可编排的材料作品 | 能按不同输入切换已制造响应的作业头、晶片或装备组件 | 组合自己的作用方式，并把它带离实验台 |
| 一处可组织的局部场域 | 用少量功能锚、作用头与真实供给搭建的织相工场，随后能重建部分环境条件 | 在空间中安排多个对象、作用和条件，形成新工艺与原版应用 |
| 一个能够持续使用的新世界 | 由边界设备、世界之心、编译核心与点火环构成的完整工程 | 选择已理解的世界条件，进入、建设、休眠并返回 |

这三个目标方便组织教学和研发，不是三道统一的许可证。玩家可以选择生产、工具、培育、运输或其他支持的用途作为自己的作品；已有应用无需全部做完。中间的每次扩展都先给可使用的收益，再提出新的问题。

我建议先用**“作业头→织相工场→世界切片”**作为示范项目串联后期。它让材料、控制、算力、探索和终局有共同对象，装备与农场等用途则使用同一批能力向外展开。

## 2. 从中期到终局，玩家的操作怎样逐步变化

| 进程 | 玩家此时想做什么 | 新的主要操作 | 在游玩中取得的成果 | 自然出现的下一需求 |
| --- | --- | --- | --- | --- |
| A：把现有技术做成作品 | 让工具/工位能处理几种不同对象 | 拼装已知部件、选择反馈、编排动作、使用与修订 | 回响作业头，初步响应方案库 | 同时准备多个响应会占体积和接口，想更独立地控制内部结构 |
| B：在材料内部组织作用 | 将台面组合压进材料，并增加可控区域 | 选择区域、写入结构、安排耦合、比较不同制造顺序 | 谱纹件、忆形晶片、可复用织构工装 | 希望多个物体和多个部位同时受到不同作用 |
| C：在空间中组织工艺 | 让一批真实坯料按位置/状态接受处理 | 布置功能锚、观察作用分布、编排对象经过和驻留 | 织相工场；批量材料、主动夹具、分选/缓冲等用途 | 不同位置和环境影响同一布局，需要理解可迁移与不可迁移的条件 |
| D：带着条件探索世界 | 寻找更好的工场地点，重建有用途的环境关系 | 做回响图、移动参考、比较地点、搭建条件组合 | 世界切片、区域关系图、稳定参照与特殊接口 | 普通局部作用难以长期保持某些关系，需要更深的材料与边界工程 |
| E：维持特殊边界 | 将高级材料、空间关系和持续控制汇合 | 约束、接界、稳定运行，选择生产/存储/求解用途 | 戈古尔斯弦锚、III型框架、可用人造视界 | 想把局部已认识的条件组织成可长期建设的世界 |
| F：组织一个新世界 | 让自己选择的关系在一处新空间共同成立 | 选择规则模板、检查组合、编译、点火、进入与建设 | 世界之心、创世核心、新维度和维护设施 | 在新环境中继续应用、探索与扩展 |

每行可以跨多个小作品；精密材料、区域探索和量子/宇观研究在C—E之间交织。这个表是体验次序，不改写已有设备的首次可达条件。

**A是中期成果的综合使用，不把门控、保持或单板控制重新锁到后期。** B增加对材料内部作用的可编排程度，C增加空间组织能力，D扩大条件与世界关系的可利用范围。这样“后期”有逐渐明显的新动作，而不只提高旧机器倍率。

## 3. 第一段的场景：一只作业头处理两种工作

示范项目选择已有的加载/表面处理工位。玩家已经可以分别用两套参数完成两类坯料处理，希望同一作业头识别当前响应并选择适合的动作，减少换件与手工切换。先从工位使用开始，具备移动控制与储能后可装到工具或无人机上。

首个目标只是完成一批混合来料，得到可继续使用的作业头。过程中的探测可以同时留下材料记录；不要求先单独完成一章光谱实验。

### 3.1 只把已有部件重新组织起来

| 部件/材料 | 首次来源 | 本段怎么用 |
| --- | --- | --- |
| 母批晶片及两个已特化区域片 | E1组成、应力与工艺路线；保留批次和方向 | 一个负责探测响应，另一个参与选择/作用；首版允许分片装配 |
| 两个可测激励档位和读出 | 已有激励器、粗稳谱光源或对应机械测头路线 | 在真实支持的频段取得两次响应；不从UI直接填写任意频率 |
| 门控、保持、路径与供给部件 | R4已能制造的电/光组件，根据所选方案安装 | 组织已有条件和状态；可用电控制直接驱动执行件 |
| 定向作用片与夹具 | E1加载、脉冲、退火及接触工装 | 执行已经做成功过的两种动作，不由控制方案凭空赋予新加工能力 |
| 本地控制与记录 | 已有B01或具备所需能力的本地控制盒 | 采样、比较、执行和保存；后续才按实际需要接集群 |
| 壳体、热界面、信号与供给口 | R4封装装配路线 | 给出可安装的作业头，保留内部方向、路径和散热 |
| 已处理过的两类试件 | 玩家现有库存；参考件可重复使用，加工试件实际消耗 | 教学从已有用途开始；不是新增两种必须跑图获取的矿物 |

光学可以承担探测/选频，电气负责步骤和执行；也允许已经取得相容能力的其他组合。第一只固定工位作业头不需要移动电池，不需要低温量子源，不依赖尚未制得的谱纹织构头。

### 3.2 一个项目从搭建到使用

| 玩家步骤 | 具体动作 | 立即可见的反馈与成果 |
| --- | --- | --- |
| 选目标 | 在统一工程入口选择已有的两种处理工序，定义哪些结果算有用 | 面板显示所需执行件、来料与可比较的实际结果 |
| 接探测 | 安装两档激励与读出，依次放入两个已知试件 | 看见两条响应；可以拖动比较分界，不必先写数学公式 |
| 拼组合 | 选择直通、带保持或分步作用的参考方案，摆部件/检查端口 | 显示对应的动作过程与实际占用，而不只给一个综合性能分 |
| 试用 | 放入小批混合来料，在工作中观察选择和结果 | 正常样品直接处理；不确定样品留在待检位，可以重测或人工选择 |
| 改一处 | 改采样时机、反馈条件、作用方向或两段动作的关系 | 相同来料上的结果可并排比较；成功设计可继续生产 |
| 做成实物 | 使用原有封装与检验工位装成可部署作业头 | 台面原型成为工位模块；离开工程面板后仍由本地控制实际工作 |
| 带出原场景 | 换到另一工位或装入具备能力的移动载具 | 发现哪些响应关系能直接复用，哪些要结合新的接触/环境调整 |

这段的正反馈是混合工作不再频繁手动切换。仪器排查与重复采样可以由已建程序完成；玩家把注意力放在作品的选择与使用上。

### 3.3 三种确实不同的组合成果

| 方案 | 结构与行为 | 更适合什么 | 玩家要接受的取舍 |
| --- | --- | --- | --- |
| 直通响应 | 测头→判断→选择一个已安装作用路径 | 状态清晰、变化快、希望立即切换的工作 | 响应在分界附近时容易频繁切换；可以选择待检而不强行加工 |
| 保持响应 | 测头→有效条件→保持件→作用路径，新对象进入时清除旧决定 | 同一对象处理时输入暂时波动，希望维持一致动作 | 对新对象要重新取得有效条件；保持供给和状态开销实际存在 |
| 分步作用 | 先执行一个可用的小动作→再探测→选择下一动作 | 只有预处理之后才能辨认，或适合分段加工的对象 | 增加时间与能量，也有机会避免一次过强的处理 |

三者用同一套原料家族，差异来自连接、状态与动作顺序。它们不是“低、中、高级芯片”的替换表；不同用途可以长期保留不同方案。

## 4. 给首段一个足够小的数据模型

首版将作业头模型分为材料响应、传感读数、选择规则和实际执行四部分，继续沿用E1/R4。控制程序的输出只能调用已经安装的动作，结果仍由工件与装置的实际过程更新。

两档响应先用一对有共同校准的非负读数`rL、rH`表示。一个可展开的比较量是：

```text
rL + rH 低于可用信号下限 → 未知
否则 z = (rH-rL)/(rH+rL)
z < -0.4 → 候选动作A
z >  0.4 → 候选动作B
其余 → 重测、保持已确认状态或待检，取决于所选方案
```

教学读数可取`(0.8,0.2)`、`(0.2,0.8)`和`(0.55,0.55)`，分别得到`-0.6、0.6、0`。这是用于说明操作的有限例子，不是已确定的材料常数；谱段、归一参考、信号下限与误差需随实际测头定义。旧对象的保持状态不得跨对象直接继承，低信号也不能靠比例放大成可信分类。

材料实体继续保存组成、结构、方向、应力、缺陷、区域几何与工序历史。首次两档响应可以由已有器件的受支持响应模型给出；玩家只见实际测量与估计。后续增加第三档、响应时间、接触方向或回响位置，是因为它能区分已有两档无法区分的对象，而不是为增加输入维数而增加字段。

组合探索先声明可编辑项，例如3种连接参考、2种反馈配置、2种端口方向布局、4种动作序列，共48个原始候选。它们不保证全部适配；已知接口/供给/过程条件先筛，模型再比较有依据的结果，保留少量代表方案试制。初始默认展示三个易理解的方案，玩家想扩展才打开组合空间。

在同一数据上反复求值可以比较方案，但不能创造没见过的响应。探索、真实试制和在新工况中的使用继续提供新内容。算力首先用于并行比较、处理更多测点和持续组织现场作业，首轮小模型不要求大集群。具体程序、缓冲和任务队列仍需落入R4硬件预算，本轮未实现端到端运行。

## 5. 从这个作品进入真正的新材料玩法

台面上三种组合已经工作后，玩家的下一个愿望是减少离散件和接口，或让同一材料的不同区域拥有不同作用。于是进入谱纹制造：选择实际母片，划分少数可加工区域，给每区选已经认识的特化/状态能力，再定义区域之间的受支持作用。

第一份谱纹可以只包含两个区域和一条可调整耦合。它不是在空白网格上随意画线就生成物性；工程面板把设计转成已有工位能够执行的分区、局部处理、连接和封装步骤。

| 制作环节 | 玩家选择 | 材料发生什么 | 可重复制造的来源 |
| --- | --- | --- | --- |
| 选母片与分区 | 可用面积、区域方向和接口位置 | 继承原材料状态，形成可加工区域 | 已有母批、切分/粗对位与模板 |
| 局部特化 | 两区的组成/结构目标及允许处理顺序 | 改变对应区域，邻区也可能受同一工艺历程影响 | E1局部加载、热处理与R4区域工艺；先用已知保守模板 |
| 形成耦合 | 接触、导波或已能制造的相容通道 | 区域之间实际交换信号/作用，方向与损耗保留 | 已有接触件、导波件和键合工序 |
| 配置与读回 | 写入输入、保持条件、复位方式 | 设置这一实例的可用运行状态 | 已有写读路径与供给；不自动获得断电永久保持 |
| 完成封装 | 对外端口、热与机械安装 | 封装改变局部条件，按用途复测 | 原有封装工位、接口件与壳体 |

“忆形晶片”的首版因此可以是**内部状态决定响应方式的谱纹件**。显示名称不承诺自由变形。R4保持器件负责已有的状态功能；新设计的重点是状态怎样与材料作用区一起制造、耦合和使用。非易失、多状态、低温或量子态版本是之后具有不同来源的扩展。

**谱纹织构头的第一次取得：** 在已有精密工位上装可定位夹具、局部作用头和已知的读出/反馈，先按保守模板制作双区域样品；这个较粗的版本再帮助制造更精细的模板与作用头。它不要求使用自己未来才能制造的高级材料。

到这里，量子和更底层的材料机制已经有具体需求：增加可区分且能操作的状态、选择特定过程、保持特殊关系，或使更细区域仍能独立工作。各项能力应改变作品；现实理论或游戏有效模型按需要提供解释，过程图可展开到相应深度。

## 6. 第二个作品：织相工场究竟怎样玩

织相工场的核心动作是**在一个空间中布置作用，并安排对象怎样经历它们**。它用已有材料和动作能力起步，新增的是空间组织方式。

第一版可在一块小型工作区域布置两个或三个功能锚，接真实供给、一个或多个源及本地控制。工件先放在实际载具/夹具上；不把自由悬浮当作首次必需能力。普通原版支撑和围护可以使用，新增方块集中在会产生、引导或读取作用的部件。

玩家拖动或旋转功能锚时，预览显示本方案的作用分布与未覆盖位置；试运行显示实际读出与工件经过记录。作用模板首先可以是沿已声明路径的分区加载、分段激励或兼容的局部处理；它们共享空间布局与调度方式，各有自己的过程模型，不用一张通用力场图代替所有物理。

| 可做的改动 | 带来的玩法变化 |
| --- | --- |
| 调整锚的相对位置、方向和作用通道 | 改变哪些区域能被分别处理，以及对象需要怎样经过 |
| 拆开或重合两段作用 | 形成不同工序顺序或共同作用，产物由实际历程决定 |
| 让工件驻留，移动作用位置 | 做同一工件不同部位的处理，减少反复搬换夹具 |
| 固定作用区，让不同载具按状态经过 | 组织多对象批次，同一场内保留不同工序进度 |
| 接入回响作业头与状态方案 | 对已测对象选择适用作用，不再只按固定时间平均处理 |

首个连续用途可以是批量制作多区域晶片；同一空间编排也可用于装配定位、实体分选或受支持的接触/缓冲应用。只有取得对应的牵引、悬浮、环境调节等组件后，才扩展相关行为，逐步出现区别于普通流水线的新作品。

这一步让集群、精密制造与世界使用形成交汇：材料决定有哪些可靠作用通道；空间与工件数量决定要组织多少对象；计算决定能在实际时限内处理多少选择。数据模型可以建议更好的布局，但布局的真实覆盖和工序历程决定结果。

## 7. 第三个目标的前半段：世界切片怎样出现

当玩家把同一工场搬到不同地点、用不同环境运行它，记录自然包含环境差异。回响网络将已有测点、原版可观察事件和远端参照组织成可用关系图。玩家可以找更适合的建设地点，也可以尝试在基地重建某个地点中**自己已经能够控制的条件**。

世界切片先作为项目里的条件组合：实际样品、光/热/加载等作用、受支持的环境组件，以及在该条件下取得的记录。它随后成为织相工场中的一个可运行小区域。观测档案和模拟预览可先存在，真实条件仍由装置产生。

例如，玩家在外出时发现某种材料工序更适合某一组环境条件，可以把可控制的部分带回工场，寻找可复用的生产方法；培育玩家可以对照一组已观测条件安排设施；探索玩家可以准备适应该区域的工具。收益来自用途，不要求三类工作全做。

还有一部分差异暂时无法靠已知条件复现。这时微观侧尝试更精细的响应和约束材料，宇观侧寻找区域、周期、天空与原版维度的关系。新资料可能改变局部布局，新材料可能使此前观察到的关系变得可控制。两侧持续围绕同一批作品交换成果。

### 7.1 探索要找到有用途的新条件

可以设计少量可复现的世界现象族：某些地点对特定激励有延迟响应；不同位置会让同一空间布局产生不同可区分的模式；某些远端参照显示跨区域的共同变化。它们由模组世界规则生成，和普通环境影响分别归因。

每个现象至少提供一种有吸引力的用途，如更稳定的参考、特别的处理窗口、适合布置连接的位置、能够识别某种对象的响应。玩家可以先利用已测关系，再深入解释；不必每发现一个地方都完成一套标准实验。

异常可表现为地形上的实际信号分布、仪器中可追踪的方向和重复出现的时段。可达的同类条件应有替代路线，支持移动测量、固定站点和后续远端观测，减少唯一遗迹与一次性事件的进度锁。

### 7.2 宇观与量子各自在这里增加什么

| 方向 | 应新增的能力或选择 | 能回到哪个作品 |
| --- | --- | --- |
| 更底层材料/凝聚态 | 新的状态保持、模式传输、约束与工作环境 | 谱纹、作业头、织相工场的可用作用件 |
| 有限量子过程 | 制备、控制和读取某些特殊状态关系，比较受支持的过程候选 | 特定探测、材料过程与协处理模块；先用小体系建立用途 |
| 宇观与远端参照 | 理解传播、周期与空间关系，提出更大范围的可检验描述 | 回响网络、选址、同步参照、世界切片与边界条件 |
| 空间/维度机制 | 描述并在获得相应组件后维持有限特殊连接或条件 | 特殊链路、接界器、区域工程 |

费曼图、谱线追踪、类视界等都可以成为深度玩法；选择它们的依据是能否解释和扩展某种操作。它们不再各自拉出一条与工坊和世界应用无关的线。

## 8. 终局如何收束，而不突然更换游戏

织相工场长期维持的是局部作用，世界切片组织的是一组有限条件。等到玩家能够制造约束材料、描述部分边界关系并使它稳定存在，旧稿的戈古尔斯弦锚和III型框架就有了明确位置。

| 终局作品 | 从前面的哪些能力组合而来 | 做出来之后玩家继续干什么 |
| --- | --- | --- |
| 戈古尔斯弦锚/特殊接口 | 可制造的接界载体＋已识别的世界关系＋实际维持组件 | 稳定一类特殊连接或边界作用，将它放进区域工程 |
| 人造视界 | 约束材料＋功能锚组织＋光电控制与供给＋边界耦合 | 先选择一个实际用途投入生产，再逐步扩展能源、存储和有限求解模式 |
| 世界之心 | 长期材料/区域/世界记录＋边界工程＋最后的整合采集 | 描述这个世界中可辨识、可组织的关系，支持选择新世界条件 |
| 创世与维护设施 | 世界之心＋规则候选＋实体核心＋点火、锚定与维持能力 | 进入新维度建设实际作业点，保存、休眠、恢复并返回 |

视界第一次运行使用前序工业供给和可制造部件；世界之心是可再取得的世界特征资料；新维度改变受支持的条件和分布，沿用固定物质种类。具体三模式与启动/恢复细节继续参考[发展线五](PROGRESSION_05_BOUNDARY_AND_GENESIS.md)，本轮表格描述它们的游玩用途。

终局不要求玩家替开发者解出所有隐藏公式。建议完成感落在“一处我选择条件、亲手建成并能继续使用的新世界”上。研究型玩家可以继续扩大解释范围，建设型玩家可以经营不同条件的工场与世界。

故事可以这样收束：最初的平均晶种提供了一个认识差异的起点；后来玩家能制作自己的响应，再组织局部的作用条件，最后能够选择哪些已经理解的差异在一个新世界中共同存在。信息与频率贯穿的是可辨认、可组织、可重建的关系。

## 9. 本轮明确的范围和接下来的顺序

这份稿子将L2收拢为三个作品目标，并具体展开首段回响作业头的部件来源、三种组合、操作过程和小模型。织相工场、世界切片与终局给出连续用途，但尚未确定全部作用模板、完整材料数量、几何范围与实现成本。

后续已在[L3材料与场域](LATE_L3_MATERIALS_AND_FIELDS.md)补出双区域谱纹的制造模型、三种空间布局和实际供给分配；[L3总稿](LATE_L3_COMPLETE_GAMEPLAY.md)将其接到终局。这里的首段细节保留使用，实际游戏原型与平衡尚未完成。

保持三类成果分别存在：实际材料/设备、可复制的方案与记录、持续工作的运行实例。原版应用的具体适配需实现阶段核对，首版可用已有模组工件与夹具演示共同机制。本轮不运行新的数值探针，也不把既有L1例子的通过状态当作这套新玩法已经验证。

依据：[R4物性与模型](R4_MODELS_AND_FACTORS.md)、[器件性质与制程](COMPUTING_R3_PROPERTIES_AND_PROCESS.md)、[R4材料与机器](R4_MATERIALS_MACHINES.md)、[统一工程入口](R4_UNIFIED_WORKBENCH.md)、[中期应用](MIDGAME_APPLICATIONS.md)和[L2方向](LATE_L2_INTEGRATED_PROGRESSION_DISCUSSION.md)。本轮先复用旧稿已有的门控、保持、光电、工位与计算基础，再定义后期新增的操控范围。
