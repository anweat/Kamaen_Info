## 1. 统一因果关系：材料、结构、运行条件共同产生功能

```text
材料状态 + 工序及其先后 → 新材料/器件状态
器件状态 + 接触/通道/反馈结构 + 当前供给/调谐 + 实际输入
→ 输出及下一步内部状态
输出与测试条件 → 已知响应、适用范围与功能说明
```

功能说明来自可重复行为。选择“滤波器”“AND门”只表示研究目标或已验证用途，不能跳过制造、改变实际结构，或把材料所有属性直接改成目标数值。

这里需要分开三个容易混淆的对象：

| 对象 | 包含什么 | 怎样改变 |
| --- | --- | --- |
| 实际材料/器件状态 | 组成与区域、取向、残余应力、缺陷/保持结构、几何和接触 | 制造、返工、实际损伤及长期演化 |
| 当前运行条件 | 外部夹具加载、偏置/泵浦、温度、相位设定、采样节拍 | 调谐、供给或环境变化；撤掉夹具/驱动后重新按真实条件求值 |
| 已知信息 | 测量记录、拟合参数、误差范围、合格用途 | 测量和分析；新知识不会自动改变物体 |

同一个世界/规则版本中的同类材料应共享可研究的物性关系，个体具有稳定的批次/工艺偏差。不同器件模型从同一份实际状态取得所需响应，不在进入“门控模式”时重新随机生成一套无关属性。

平均背景晶种仍是特化起点；后续加工改变的是固定物质种类体系内的组成和结构。谱峰、阈值、漂移、保持时间由具体物性与结构派生，不设置一个能够全面替代它们的“晶体品质”。

## 2. 最初需要认识的六类响应

| 响应 | 实验怎样看到 | 能支持的用途 | 不能直接推出的结论 |
| --- | --- | --- | --- |
| 频带选择性 | 扫输入频带，测指定输出口的透过/泄漏 | 选频、隔离邻近信号、通道分配 | 原料存在一个吸收峰，不等于对应输出口存在透过峰 |
| 相位/方向响应 | 改取向或调谐，在参考结构中比较输出 | 调相、差异测量、干涉组合 | 单路强度不变，不代表所有信息不变；相位偏移也不等于任意时间延迟 |
| 输入强度的非线性 | 同一频带逐渐升/降输入，画输出曲线 | 阈值、门控、受限非线性运算 | 非线性本身不规定输入数、逻辑真值表或自动产生反相 |
| 状态保持与历史依赖 | 写入后改变输入、等待、读取、复位 | 保持、缓冲、寄存与反馈 | 响应慢不等于可写存储；一次滞后不证明存在两个可控稳定状态 |
| 载体转换响应 | 在已知光/共振输入下读取另一载体的输出，比较暗态与参考 | 探测、读出、调制接口 | 吸收光造成发热不自动等于可读电信号；热探测需要自己的温度读出路径 |
| 稳定性与扰动响应 | 重复测试，并改变温度、加载或供给 | 基准、长期运行、可复制制造 | 窄谱不自动产生持续振荡；晶振还需驱动、反馈或对应激励结构 |

早期一次任务只展示其中两三项。曲线标明“从哪里输入、在哪里读出、测的是什么量”；频率坐标、信号幅度、功率、采样率各有名称和单位，不用同一条“频率等级”兼任。

## 3. 四个主要器件例子

### 3.1 选频器：材料的响应被组织为一个传输端口

**实际结构**：有合适响应的晶片＋输入/输出耦合＋取向/加载夹具＋支撑与接口。需要时增加结构隔离；不是所有有主峰的晶片都能在任意装法下选频。

**制程候选**：定向切片/抛光→按需要做组成处理→恢复/稳定化→形成或装配通道/耦合→小范围调谐→扫频检验。若原片已经满足组成要求，可省去掺杂；工序取决于实际输入状态。

**玩家主要选择**：目标频带、合适原片与取向；在允许范围内调整加载。带宽和泄漏来自材料、结构及工艺，不做三个互不关联的免费滑块。

首个强度传输候选采用指定输出口的有效曲线：

```text
T(f) = b + (p - b) / (1 + ((f - f_c)/w)^2)
0 ≤ b < p ≤ 1，w > 0
P_out(f) = T(f) * P_in(f)
```

`f_c`是中心，`w`是该曲线的宽度参数，`p`是峰值透过，`b`是背景泄漏。本式仅描述一个被动、强度模式的拟合输出口；其他端口及损耗另计，不能直接用于相干多路相加。

**验收**：目标带能通过，指定干扰带泄漏受限，工作条件变化后仍在声明范围。旁边频带更干净但目标也被削掉的器件，不能仅因“降噪多”判为合格。

**失败去向**：中心偏移但稳定的片可去另一个频带；宽而低损耗的片可作传输用途；超出可逆调谐范围才考虑改组成、重写残余结构或换料。

### 3.2 相位器件：有参考和组合结构，才能把相位用于功能

**实际结构**：可调相位响应的路径＋实际调谐驱动；用于干涉时再接同源分支、参考路径、合并与两个读出口。沿用`phase_tuner`、`mzi_modulator`和相应工装。

**制程候选**：取向/通道形成→稳定化→接触或驱动结构→外部耦合→扫描相位→装参考结构复验。对热预算不兼容的接触，稳定化应在接触安装前；不能统一规定所有元件都最后进高温炉。

**玩家主要选择**：两路怎样连接、调谐范围、采用什么参考和维持条件。第一课用同源双路，避免一开始管理全部相干网络。

沿用已有教学模板的两个输出：

```text
P_A = P_in * η * (1 + V*cos(Δφ)) / 2
P_B = P_in * η * (1 - V*cos(Δφ)) / 2
P_A + P_B = P_in * η
0 ≤ η ≤ 1，0 ≤ V ≤ 1
```

相位改变两个输出的分配；损耗为剩余预算。`V`仅为此模板的条纹可见度，不充当所有光学/量子条件的万能指标。

**验收**：单路与双路对照、可重复的相位扫描、总输出与损耗账、改变温度后的可用调谐范围。换一个读出口就要对应新的传输定义。

**下游**：比较、调制和明确编码下的组合结构；形成完整算子还需通道、权重范围、读出及数值误差验证。

### 3.3 门控器件：非线性响应还要有输入组织与输出恢复

**实际结构**：有合格响应的门控区＋控制/信号接触＋所需混合结构＋有供给的输出级。电门控与光非线性实现可分别存在；供给与数据端口分开。

**制程候选**：选择/形成目标组成区域→稳定化→控制区与接触→扫输入响应→检查输出范围。粗版使用已有区域模板与机械对位，精密注入/投影改善一致性，不堵住首次制造。

一个可解释的逻辑例子：两个归一化控制输入`a,b∈{0,1}`经实际等权混合得到`q=(a+b)/2`，再进入有供给的阈值/输出恢复结构。

| a,b | q | 阈值0.25时 | 阈值0.75时 |
| --- | --- | --- | --- |
| 0,0 | 0 | 0 | 0 |
| 0,1或1,0 | 0.5 | 1 | 0 |
| 1,1 | 1 | 1 | 1 |

若器件实测允许上述范围内的稳定阈值调节，同一结构可分别实现OR与AND。输出0/1是有明确定义与供给的逻辑读出，不表示被动混合凭空产生光功率或增益。NOT需对应反相/互补结构及必要参考，不能只把阈值写成负数就视为完成。

**关键边界**：普通无记忆阈值门和有迟滞的门是不同响应模型。R3退火任务的“范围判断”需要上下边界判断与组合；连续三个窗口还需另外的状态/节拍结构，不能全部塞进“非线性晶体”一个词条。

**验收**：全部输入组合、边界附近的扰动、切换时间、输出是否可供下一段辨认。报告给有效低/高范围和裕量；非线性斜率高但漂移大，可能仍不适合稳定控制。

### 3.4 保持器件：能够写入、保持、读出和复位，才成为存储

**实际结构**：支持相应状态行为的材料/器件＋反馈或耦合＋写读/复位路径＋维持供给。初级版可用已测门控结构组合，光双稳态与循环结构是后续实现之一。

**制程候选**：制备/选择门控或保持响应→形成耦合/反馈→装写读口→在工作条件内稳定化和调节→执行完整写读/等待/复位实验。普通保持并不要求先造高级光RAM。

一个易失教学模型：

```text
q ≥ θ_on  → 写为1
q ≤ θ_off → 写为0
θ_off < q < θ_on → 保持已有状态
θ_off < θ_on
```

写入后的输入回到有实际来源的保持偏置，如上下阈值之间的0.50；直接撤掉全部驱动不等同于仍满足保持条件。未初始化状态保持未知，重新供电也不能复活已丢数据。

数值推演中的特定易失器件在断供后一个采样步失效；后续器件可有不同保持寿命、读扰动与刷新策略，必须有各自的测量/有效性模型。迟缓衰减的模拟缓存与可重复写读的双稳态存储也分别标识。

上面的迟滞规则是器件的读写契约摘要。为了进一步说明“性质怎样经结构成为功能”，本轮还试一个由非线性与实际延迟反馈组成的候选：

```text
z[n+1] = sigmoid(k * (x[n] + κ*z[n] - θ))
```

`k`来自指定工作窗内的非线性曲线，`θ`来自器件与偏置，`κ`来自实际反馈耦合，`x`是写/复位端的差分控制。它有维持供给和声明的响应时间；不是无延迟组合环任意迭代，也不是负光功率。

固定`k=8,θ=0.4`，保持时`x=0`。同一个非线性件：弱耦合`κ=0.2`时，高低初态经过40步落到同一读出附近；强耦合`κ=0.8`时仍分别保持低于0.2和高于0.8的读出。单步正/负写入控制还能切换这两种状态。这个有限例子已复算，尚未证明完整扰动稳定性。

读写契约例与非线性反馈例使用两组独立参数。最终选定器件的有效写入/退出阈值应从它的实际响应模型测出，不同时运行两套互不一致的状态规则；本轮尚未把两个示例拟合成同一套参数。

因此玩家可以通过“接上反馈→逐步调耦合→分别写高/低→等待→读出”的实验发现保持窗口；耦合不足时，界面给出状态合流的观测，而不是仅显示缺少一种名叫存储晶体的材料。若其他材料本身就有迟滞，其作用也须独立测量并进入实际模型，不能与结构反馈重复赠送状态能力。

**验收**：分别写0和1；保持一段时间；读后复测；复位；改变维持供给；从未知初态启动。只测到输出有延迟，不能把器件登记为一位存储。

**制程取舍**：散射、裂纹等缺陷与有助于某种保持行为的结构不能统一记成一个“坏缺陷值”。稳定化可能减少散射，同时削弱某种保持机制；两类状态与工艺作用需分别建模。本轮数值仅验证散射缺陷与残余应力，不声称已验证全部保持材料。

## 4. 运行调谐与制程写入必须分开

| 操作 | 本轮建议改变的对象 | 撤回/返工与实际代价 |
| --- | --- | --- |
| 旋转/重装夹具 | 相对于局部晶轴的耦合、读出方向 | 可恢复；不改成分，相关接口需复核 |
| 可逆加载/偏置调谐 | 当前工作点与响应 | 在允许窗口内可恢复；依赖实际夹具/驱动，撤去后重新求值 |
| 冲击/定型等残余应力写入 | 留在材料中的结构/残余应力 | 是加工事件，可能增加缺陷；不能通过关界面撤销 |
| 掺杂/局部组成处理 | 实际留存组成及空间分布 | 消耗登记材料；溶解、扩散、再处理均按实际历史与损耗结算 |
| 切片、图案化、刻蚀 | 取向切面、几何、耦合/接触区域 | 已去除的材料不可凭调谐补回；粗模板与精密模板能力不同 |
| 沉积/接触与接口装配 | 控制/读出通路、损耗与局部加载 | 可返修部分接口；接触不良与材料本体问题分开诊断 |
| 退火/稳定化 | 缺陷、残余应力及该工艺窗口内其他状态 | 顺序相关；可能修复一项又改变另一项，不是全属性提升按钮 |
| 封装 | 外部加载、热/接口条件与可访问方式 | 保留实际器件，复测；缓冲/补偿有结构与成本，不免除容量限制 |

“锁定当前设定”要说明锁定机制。保留夹具/调谐驱动是保留运行条件；热定型或结构写入是一次新工序，可能回弹或损伤，之后必须测量。保存一个数值不能把外部加载免费变成永久物性。

## 5. 把工艺做成有因果的路线，而非越来越长的配方

### 5.1 每张工序卡只回答四件事

1. **需要什么输入状态**：材料、已有层/区域、接口与工装；不满足时说明缺哪项。
2. **本次准备改变什么**：例如峰位、接触、图案或散射缺陷；可控制变量先只开放一两项。
3. **还可能同时改变什么**：残余应力松弛、区域扩散、表面损伤、保持能力改变等已知耦合。
4. **用什么复测**：前后曲线或工作窗；未测部分保持未知。

制程记录保留工序顺序、实际留存料、条件轨迹和前后测量。不是每个器件都走表中全部动作；同一工艺框架可换工装，旧注入、刻蚀、退火等设备保留实际职责。

### 5.2 玩家需要掌握的三个决策阶段

| 阶段 | 主要决策 | 操作结果 |
| --- | --- | --- |
| 选片与成形 | 已有材料能否达到目标；是否换组成/取向 | 选定母批、切片与结构族，得到可加工的范围 |
| 制程与装配 | 必要工序及顺序，装什么接口/耦合 | 得到实际器件，可能有偏移、损耗或状态差异 |
| 调谐与验收 | 可逆调整是否足够；接受哪个用途分档 | 工作设定、功能证据、量产路线或具体返工原因 |

第一轮给保守可用路线，玩家只改一两处并做对照；后续可以复制路线、换批次、插入分支/返工、优化工况。自动化保存已理解的步骤，模型控制用于适应批次与环境，不自动赠送未研究的材料能力。

制程进步主要改变可实现的响应范围、分布一致性、密度、可调余量和维护成本。更精密工艺可减少某类偏差，但仍可能增加步骤或改变其他约束，不以单一纳米数统一决定所有性能。

## 6. 工序顺序的具体例子：为什么“修得更干净”仍可能不好用

下面全部为用于检查玩法的归一化候选，并非现实晶体定律。频率坐标`f`与R3退火任务中的读数幅度不是同一量。

取一类晶片的局部有效模型：

```text
f_c = 0.42 + 0.20*r + 0.10*(s + s_pack + u)
p   = 0.90*exp(-D_s)
w   = 0.025 + 0.060*D_s
b   = 0.020 + 0.030*D_s
```

`r`是该例实际留存掺杂比例，`s`是残余应力摘要，`s_pack`是封装加载，`u`是当前可逆加载，`D_s`仅代表本例的散射缺陷摘要。`p,w,b`用于§3.1传输曲线；材料、结构和输入域超出已登记窗口时不能直接外推。

本例写入残余应力`Δs`同时增加`0.1*abs(Δs)`散射缺陷。一次温和退火把`s`和`D_s`降为原来的1/4；本例不改变r，不包含过热、区域扩散等其他工艺分支。

初始`r=0.1,s=0,D_s=0.4`，写入量0.6，允许可逆加载`u∈[-0.15,0.15]`。目标频带0.50，干扰频带0.65；要求中心偏差≤0.005、目标透过≥0.70、干扰透过≤0.10。

| 路线 | 得到的材料与封装差异 | 最佳允许调谐后的目标透过 | 结果与解释 |
| --- | --- | --- | --- |
| 先写应力，再退火 | 残余应力0.15，散射缺陷0.115 | 0.437 | 缺陷低，但中心最多调到0.470；不适合这个目标带 |
| 先退火，再写应力 | 残余应力0.60，散射缺陷0.160 | 0.767 | 有更多写入损伤，但中心可达0.500；本任务合格 |
| 第二条路线＋高应力封装 | 额外加载-0.30 | 0.650 | 原结构合格，封装后即使尽力调谐仍不达要求 |
| 第二条路线＋缓冲封装 | 额外加载-0.05 | 0.767 | 通过范围内调谐恢复目标；缓冲封装需实际结构/材料 |

四个结果已由[有限数值推演](R3_DEVICE_PROCESS_PROBE.md)复算。作者侧使用最佳允许调谐值来检查“是否根本无解”；游戏中的调谐仍来自仪器扫描与模型估计，不直接读取隐藏最优值。

这个例子让玩家有三种后续选择：把第一路线产物改用于另一频带；换一种更接近目标的组成/结构后重新验证路线；保留第二路线但改善封装。它不规定所有材料永远先退火再写应力。

## 7. 物品与设备怎样承接这些变化

| 实体/记录 | 保存的内容 | 玩家查看或使用 |
| --- | --- | --- |
| 晶体/晶片 | 实际组成、取向、残余结构、加工历史与母批 | 看已测响应，选择加工/器件用途 |
| 接触、耦合、夹具与状态模块 | 实际结构、接口与作用范围 | 组织晶体物性，不能用纯数据图标替代实体能力 |
| 已装配器件 | 实际组成件、通道、运行设定、环境要求 | 接实验台测试，再封装/装机 |
| 结构蓝图 | 拓扑、需要的响应范围、接口、可调项 | 新批复制，不复制原件的物性偏差和活动状态 |
| 制程记录/模板 | 工序、窗口、材料留存与复测位置 | 手动复现、流水线执行、跨批修订 |
| 测试与校准记录 | 对象实例/结构/条件、输入输出、误差与适用范围 | 给用途分档，校准不修复不存在的结构 |

沿用`kamaen_wafer`、`kamaen_dopant`、`phase_tuner`、`electronic_logic_gate`、`kamaen_bistable_cell`、`eda_module_plate`等现有设计来源。类型名表达其制造结构族与已验证用途，不以改名触发功能。本轮不再新增一批“每个响应一种矿物/方块”的注册ID。

组件卡默认显示三项与任务直接相关的结果，例如目标带通过、干扰泄漏、可调余量；展开才能查看完整曲线、工况和历史。不同用途有不同摘要，不反向汇总成万能品质分。

## 8. 接下来的四组实验

| 实验 | 保持不变 | 有意改变 | 需要区分的解释 |
| --- | --- | --- | --- |
| 同一晶片、不同接口/取向 | 晶片本体、输入与仪器 | 夹具取向/输出耦合，每次只改一项 | 材料主峰与器件端口响应的区别 |
| 同母批、不同工序顺序 | 总处理种类、目标条件、来源组 | 写应力/退火先后 | 最终结果取决于历史，不只取决于材料名称与总耗时 |
| 同一非线性件、不同反馈/维持 | 器件与读取方式 | 反馈、保持驱动、写读/复位序列 | 非线性、延迟、迟滞和可用存储不是同一件事 |
| 同一装配件、不同封装条件 | 逻辑结构与测试集 | 接口装配/封装加载，分别测试 | 台上成功与装机成功的区别；哪些偏差能靠调谐补偿 |

同母批分样并保留参考，交错实验顺序，再换独立母批复验。不能拿一枚晶片先做不可逆实验A、再做B，就宣称得到了两个独立对照。

随机性分成稳定母批差异、每次加工留下的偏差、仪器测量误差和环境变化。候选生成规则应固定规则版本及样品/工序来源；重开界面不重抽物性，复制日志不增加独立样本。独立测量可帮助估计随机误差，仪器偏置仍需参考校准。

玩家早期发现“改哪一步会让曲线怎样变”，中期拟合局部关系并预测工艺参数，后期比较多个候选物性模型在新实验下的差异。这样公式解密来自生产与实验遇到的实际问题。

## 9. 本轮边界与下一步

已经落实到候选规则的是：性质/结构/运行条件的分工，四类器件的功能成立条件，可逆调谐与制程写入，工序卡与少量主要选择，以及一组可复算的工序/封装反例。

有限推演检查了12项指定例子的因果、功能、状态与预算关系。尚未证明完整材料物性模型、随机生产良率、所有工艺顺序、微型化映射或游戏运行；也未重写R1全部科技依赖。

下一步适合把“选频片＋门控/窗口结构”的一轮实际制作拆成少量界面动作与物料状态变化，再用试玩判断调谐、工序比较、测试是否各有足够反馈。相位与多通道组合继续作为下一条实验线，逐步接到阵列与算子。
