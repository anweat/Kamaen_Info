## 1. 本轮解决的问题

让玩家第一次做芯片时，先完成一个看得见、测得到、能修改的信号处理结构。玩家接触晶体响应、通道、状态和实验；设计工具负责记录、复用与制造转换。

共同主线仍为信息与频率。白噪晶种是平均背景属性的初始结晶；材料特化使晶体形成不同响应。应力、组成、取向、结构与加工历史决定可用范围。频率不是物品编号，也不是统一算力等级。

本轮闭环：

```text
实际晶体 → 测出可用响应 → 在实验台连接、调谐
→ 用正反样本与扰动测试 → 保存结构与测试记录
→ 封装样机 → 接入实际机器 → 观察失败工况
→ 重调 / 换材料 / 改结构 → 再次验证
```

要保留的开放性来自不同材料、连接、调谐和验证方案。金属层、过孔、逐引脚映射等工艺细节是否继续成为独立可玩层，后续另议；不把它们作为这个入口的必修条件。

## 2. 实验台怎样操作

候选形态是一张可扩展的实体实验台，放置实际夹具、晶体和接口。初版用有限位置的托盘，界面只提供放大查看、接线和读数；不再要求额外抄一份原理图、再画一份微结构版图。尺寸与扩展上限暂不冻结。

| 操作 | 玩家做什么 | 反馈 |
| --- | --- | --- |
| 放 | 在夹具里装实际晶体/已测器件，接输入与读出 | 显示母批、可用响应与尚未测清的范围 |
| 接 | 选输出口与兼容输入口；连接明确的耦合或信号通道 | 高亮载体、方向和断点；光口与电控制口需实际读出/调制接口 |
| 调 | 转取向、调加载、改已有调谐件的设定 | 同屏显示调节前后曲线；越过可恢复工作窗会预告需返工/损伤风险 |
| 测 | 选择参考、真实样品、重复次数与扰动条件 | 显示逐段信号、输出事件、失效和记录来源 |
| 保存 | 命名结构、输入输出及适用条件 | 生成结构蓝图与对应测试记录；不产生第二套器件 |
| 封装 | 选择兼容载板/封装，将实际部件转入 | 预览占用与接口，封装后重复同一组测试 |

默认仅显式连接产生信号耦合。画布排版距离不另收一遍延迟；确需路径长度、方向或邻近效应的专门实验，用可测的路径/耦合单元引入。晶体在夹具中的取向依然可以改变响应。

实验台保留固定步进、读出和测试功能，不依赖玩家即将制造的控制芯片；首轮也不需要机器学习或集群。

## 3. 第一层原件尽量由物性和工装共同定义

建议先让玩家看见“窄带响应的晶片”“有可调相位延迟的晶片”等观测，再逐渐用“滤波”“调相”命名已经确认的用途。原件不能只是一组写着算子名字的图标。

但晶体也不凭一种词条自动变成完整功能。接触、耦合、读出、门控和供给工装负责把物性组织为可用器件。

| 结构族 | 来自晶体的差异 | 工装/结构补足的部分 | 最初调节 |
| --- | --- | --- | --- |
| 选频 | 响应峰、宽度、方向、背景泄漏 | 输入/输出耦合与支撑 | 在实测范围内调整中心与取向；带宽不能任意手填 |
| 调相/延迟 | 相位响应或保持过程 | 调谐驱动/路径或受控延迟结构 | 先看可重复偏移；相位和时间延迟分别标示 |
| 耦合/组合 | 通道间传递响应 | 显式分支、合并、耦合结构 | 连接目标与允许耦合比例；拆分本身不增加信息或能量 |
| 阈值/非线性 | 输入改变引出的非线性响应 | 读出、控制端与必要的供给 | 触发/退出范围；输入载体、量纲与工作窗明确 |
| 保持/状态 | 可保持状态的器件及其寿命 | 写入、读取、复位与节拍 | 保持窗口、初态、复位方式；失去供给后不能无限保留 |

这五类是待验证的设计分组，不是承诺仅注册五个方块。第一项任务只开放选频、读出、阈值和窗口判断；调相/耦合在下一项对照实验展开，避免一次学习所有自由度。

界面先显示“通过哪些输入、输出怎样变化、在哪些条件下失效”。更细参数由更好的测量和模型逐步解释；未知不代表随机重抽，重复读卡不会重置材料属性。

## 4. 第一颗芯片：退火终点判定

### 4.1 任务约定

已有退火设备、可用的样品响应读出、固定步进测试器和一批可对照样品。玩家希望：**指定测量窗口的读数连续达到要求时，输出“就绪”信号，交由炉控制接口结束这一轮处理。**

读数表示当前仪器与编码下的测量值，不直接读取隐藏材料真值。这个判据是初始工况下的经验规则，能否泛化需要更多独立样品检验。

最小结构：

```text
样品响应输入
→ 选频晶片
→ 对应载体的读出
→ 范围判断单元
→ 连续窗口判断器
→ 就绪输出

新批次/复位输入 → 清除窗口状态
无效读数 → 清除连续计数并标记输入无效
```

连续窗口判断器是已知的保持/节拍组合模板，可以展开看结构。它有实际状态与节拍部件，不把普通延迟线改名就赋予计数功能。

### 4.2 玩家这一轮怎样完成

1. **比较样品**：查看未完成、已达到当前工艺要求的独立样品；找到能区分它们的响应窗口。仪器读数与工艺验收记录分开保存。
2. **装选频片**：从已测库存中选一枚可覆盖目标区域的晶片，转取向或调可恢复加载，使所需响应进入读出窗口。
3. **连读出和判据**：先用模板设置合格范围，观察样品输入对应的判断。教程允许提供一个已确认可用的起始区间。
4. **加入时间条件**：选择“连续三个采样窗口”，看到单次脉冲不能直接宣布完成；三个是教学假设，不是最终平衡数值。
5. **测试反例**：尝试短干扰、频谱偏移、缺读数、新批次和持续合格信号。定位是选频、判据还是状态更新导致失败。
6. **封装复验**：通过既定测试集后，将实际部件装入兼容封装，用同样输入重测，再接实际炉子。

一组用于解释状态的归一化样例：合格区间暂设`[0.65, 0.80]`；每收到一个有效采样才推进一步，连续计数上限为3。

| 采样次序 | 测量值 | 连续合格数 | 就绪输出 |
| --- | --- | --- | --- |
| 1 | 0.20 | 0 | 0 |
| 2 | 0.70 | 1 | 0 |
| 3 | 0.72 | 2 | 0 |
| 4 | 0.74 | 3 | 1 |
| 5 | 0.50 | 0 | 0 |

无效读数或过期缺帧会清零并输出无效标记；不能把上一个好读数重复当三个新样本。采样周期改变后，三个窗口代表的时长也改变，须重新核对任务需求。复位在新批次采样前生效。

芯片输出的是就绪电平。炉控制接口按本批次首次有效就绪处理一次结束请求，并保留自己的温控/联锁；不会因为连续多个采样输出1就重复交付产品。后续执行网关沿用明确动作编号。

### 4.3 验证关卡检查行为，允许不同结构

教程提供一组明确验收条件；自由实验允许玩家自定义输入输出和测试集，也能保存尚未充分验证的结构。任务完成与结构保存分开，避免所有创作都必须匹配预设用途。缺少证据的范围标为未验证，不伪造合格结论。

| 输入/工况 | 应观察到的行为 | 可能需要的改动 |
| --- | --- | --- |
| 未达标但稳定的响应 | 不就绪 | 修选频或判据；不能靠长时间等待刷成功 |
| 只有一个窗口的强脉冲 | 不就绪 | 补窗口判断，检查状态是否确实连续更新 |
| 连续有效达标响应 | 在所声明时限内就绪 | 排查信号损耗、判断范围、采样和时序 |
| 测量失效/过期，随后恢复 | 失效期间不就绪；恢复后重新累计 | 明确输入有效性，不复用旧值冒充新读数 |
| 新批次开始 | 先复位，再重新判断 | 增加实际复位路径 |
| 样品与邻近干扰/温漂 | 在声明工况内满足已登记误判和漏判要求 | 改材料、选频范围、参考或统计方法；当前无法区分时缩小适用域 |

测试通过只说明在该测试集和工况中通过。保存样本来源、版本和适用范围，不生成“万能正确芯片”标签。未见过的材料或环境仍可能要求重新研究。

开放解法包括窄带筛选、较宽窗口配时间验证、增加参考对照、改善晶体稳定性。参考/统计方法需要实际读出与运算结构，不在后台自动赠送。若目标与干扰在现有观测下不可区分，增加测量维度或承认局限，不能强迫玩家调出不存在的解。

## 5. 封装怎样保留实验意义

### 5.1 首版是实际部件封装

选择可容纳该结构的载板/封装，转入实际晶体器件及必要接触、互连、读出/状态模块。实验台只释放夹具，已转入的部件不会同时留在台上。实验台的外部信号源、样品和测试仪器不全部塞进芯片；封装记录它们所需的外部接口与参考条件。

输入输出、连接、工作设定及器件身份保留。封装自身改变接触、热或应力条件，因此要复验；有效测试报告绑定实际封装实例。调谐设定只在器件允许的范围内可改，内部状态从声明初态开始，不把台上的运行历史默认装进新任务。

大结构可以先成为较大的可安装模块。能否压入更小封装取决于制造与接口能力，不因完成测试就无条件缩成一格。

### 5.2 蓝图复制与微型化随后引入

结构蓝图保存连接、所需器件响应范围、可调项、外部接口及验收方法。复制消耗新的实际材料/器件；新批次要调谐和复验，不能复制原样机的隐藏物性。

微型化时，EDA为已经掌握的结构族提供制造映射：将可映射部分转换为工艺模板、列材料、预估条件，制造后比较输出与原实验结构。不能映射的结构继续模块装配，或先研究工艺；不会自动把任意大实验台合成为通用微芯片。

投影、刻蚀、退火和封装仍有生产用途。逐层手绘和引脚细节是否作为可选深度保留，后续结合具体收益讨论；当前不重新引入首颗芯片的必修列表。

### 5.3 修改代价分三层

| 改动 | 所需操作 |
| --- | --- |
| 已有器件允许的调谐值 | 调谐/加载新设定，按影响范围复测 |
| 明确可配置的路由或参数 | 重配置，检查该硬件支持范围，再验证 |
| 新增端口、状态容量或结构功能 | 换部件、扩大封装，或重新制造 |

模板复用逐渐减少重复劳动。量产可以运行固定测试序列；首次发现或新工况才需要展开实验，不要求每批重新手解一遍。

## 6. 向后连接，但不把全部系统带进第一项任务

电与光从第一台混合实验中共同存在：光/共振路径提供可选择和比较的响应，电读出/门控/状态参与组织测量和动作。后期可以替换具体实现，仍保持同一输入输出约定。

下一项候选实验是“同样强度，两路组合为何不同”，引入相位、参考与耦合。随后由经过验证的多通道组合结构研究明确编码下的加权运算，再封装重复阵列。模型算子绑定这些实际能力，不能凭一个“矩阵”名称获得任意MatMul。

模型图表达数据处理/预测关系，实验结构实现具体信号行为。两者通过编码和已验证算子对应，不要求玩家为了同一条简单回路再抄两张图。主板/机柜承担安装、存储、供给和互联，集群承接规模化任务。

本轮只讨论有限单元、有限频带与显式状态的有效模型。它必须实际处理输入并产生输出；完整物理方程、任意结构自动综合、量子行为和大模型执行不能因入口简化就被宣称已经解决。
