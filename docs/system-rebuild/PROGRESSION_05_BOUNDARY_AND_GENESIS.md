## 1. 戈古尔斯弦：从记录到可维持的边界结构

**旧稿依据**：[GDD§5.10–5.11](../Kamaen_Info_GDD.md)、[阶段表§10](../Kamaen_Info_Stage_Content_Line.md)。保留“戈古尔斯弦是维度初始边界条件的残留映射”这一原有定义，落实到信息与频率主旨。

世界边界模式不是某个人写给玩家的消息。玩家在跨地点残差中识别稳定关系，再用特化晶体耦合其中一类模式。所谓残迹有两层：观测档案记录模式；实体残迹是锚定装置把这种结构稳定到实际载体后的材料。两者显示与配方类型分开。

```text
微观边界材料 + 接界棱镜 + 互证谱册
→ 接近边界的受限耦合实验
实际晶体/末地类基材 + 登记边界模式 + 普通外部供能
→ 实体弦残迹 → 弦锚定器 → 戈古尔斯弦
```

“末地类”可以由可达的原版探索/交易/对应基底路线取得，不能用世界任意一个方块伪造；唯一龙蛋不作必需条件。天空观测可在主世界完成，本地残迹仍绑定实际维度与边界区域。

**初步模型**：弦具有与本世界绑定的模式索引、匹配M、约束C、退相/泄漏L；候选稳定量`q_next=clamp(q+Δt*(a*M*C−b*L−c*负载),0,1)`。输入、步长、系数有限；该式只为有限装置工作窗服务，不表示真实弦动力学。断电时按储备衰减，预备停机将剩余结构退回可回收载体。

**实验**：同一模式用匹配/失配棱镜、稳定/扰动供能对照；换维度后旧标定失效或只可作先验，不能永远通用。合格弦证明能维持一个受限边界结构，不等于已经创造视界。

**收益与故事**：弦连接原有材料工程与后续边界约束；跨维度链路作为本公设下的独立设备升级，仍要成对锚、服务授权、预算和离线处理。

> “我没有把边界装进盒子。我只是让一小段材料，持续回应它的一种变化。”

## 2. 第一台人造视界：先证明可以停止

**旧稿提炼**：III型框架、约束片、熵流泵、全息膜、霍金采样、熄灭器与有限体积保留。自举与恢复需要比旧稿更明确。

```text
已有超导/拓扑/抗压材料 → 约束片与冷却模块
普通基膜 + 初级刻写头 → 空白信息膜
弦 + 约束环 + 空白膜 + 外部电/泵浦供能
 + 独立熄灭器 + 启动储备 → 完整III型框架
→ 低负载成型 → 测量/停机演练 → 合格视界
```

普通膜刻写头由已有光电与精密工艺制作，高容量视界刻写器是后续升级，修复“写入器需要膜、膜需要写入器”。首次启动使用先前燃料/工业供能和普通储备，不能依赖还未产生的黑洞残渣、视界电池或黑洞发电。III型雏形只承担低温材料试验，名称不意味着它已经有视界。

**初步模型**：分别记供能储备E、热负荷H、约束裕量C、边界匹配M、泄漏L和工作模式。能量积分按`E_next=E+输入−维护−任务−损耗`结算，支出前检查可用额；热负荷由明确散热和任务产生，不用“熵”统一吞掉所有成本。C/M低于窗口或L超限触发降载，不能只看一个综合成功率。

结构尺寸有明确上限，变更时重验；运行分有限步结算，不模拟真实引力吞噬周边区块。玩家可自由布置有限模块，诊断显示是哪处约束、读出或冷却不足。

**毕业实验**：空载成型→施加小扰动→恢复→切断主信息总线→独立熄灭器降载/终止→回收→重启。断电且储备不足时允许受控退役，有材料折损，档案和基地不因教学失败全毁。第一台必须能靠前序工艺修复。

> “能让它出现，只回答了第一个问题。直到我能让它安静地停下，再从记录中恢复，我才真正拥有了这项技术。”

## 3. 三种用途：发电、存储、求解

**旧稿依据**：[阶段表§11](../Kamaen_Info_Stage_Content_Line.md)。同一视界一次只运行一种主模式；一台可切换用途，也可建多台分工。L3按当前需求选择首次用途，不要求三种全部完成才推进创世。

| 模式 | 玩家操作与产物 | 初步预算/验收 | 前后反馈 |
| --- | --- | --- | --- |
| 发电 | 登记质量进料、调节线圈、冷却→封顶可用能量 | 进料等效能量账与效率上限，扣除启动/维护/损耗；比较净收益 | 为大型实验供能；外部启动线保留 |
| 存储 | 数据页→全息膜编码→写入、校验、读回 | 实际容量、冗余、错误注入和恢复；未知页不能自动出现 | 保存大型档案和模型版本 |
| 求解 | 登记有限候选集/目标/约束→有预算搜索→候选与残差 | 有限求值次数，记录停止原因，独立验证候选 | 选择维度规则与改进复杂工艺 |

彭罗斯吸积线圈、霍金采样器、熵差整流器等保留原名，知识册标“视界公设设备”。采样是读出，回收是物料/能量账内的支路；不能对同一份进料把全额能量分别记给每一种抽取方式。

黑洞解析残渣来自有损退役或登记副产；只回收未转化/未输出的份额，不能把已发出的能量对应质量又完整还原。视界能量缓存因此成为后续储备升级，先前普通电池仍能启动和救援。

切换顺序：停止接单→完成或取消当前批次→保存持久结果→降载→换模块/模式→自检。离开存储模式不删数据，读出可能暂停；创世所需工作副本可放普通存储。任务失败保留输入与已确认记录，不把未完成输出当成成果。

**实验**：发电比较同量进料的不同负载；存储写入已知页并注入有限错误；求解用有经典答案的小任务检测候选。首次为所选用途完成交付与停机恢复，多模式切换在继续扩展时进行。

长期光存储、WDM、全光交换核保留为进阶，L3取消其统一的视界存储前置：普通持久介质和光网可以独立发展，全息版本另加相关组件。存储有持久性/维护条件，WDM有串扰/波段占用，全光交换有控制和校准成本，电气节点继续可用。

> “它可以把消耗变成输出，也可以保存记录、筛选解释。用途不同，必须付出的代价也不同。”

## 4. 双尺度闭合与世界之心

**旧稿提炼**：世界之心频率、巨型节点框架和维度规则候选保留；“萃取”解释为受控信息辨识，不要求挖掉或破坏当前世界的核心。

局部视界只能证明自身在某些条件下可控。玩家再将其模式响应，与早前留下的天区参照、当地底噪和新地点观测比较，形成**双尺度闭合图谱**。训练时用过的内部视界数据不能充当唯一独立证据。

本轮主线要求用既有混合集群组织一次跨来源批量复核，让此前的计算建设参与收束。保守模板可用小集群完成；这是玩法上的综合验收，不是声称辨识世界边界在物理上必须使用某种硬件。

**初步联合模型**：候选参数θ预测多种测量，按各自误差尺度计算残差；分开报告材料、天空、局部边界三类误差，不用总平均隐藏某一路完全失败。部分参数不可辨识时给允许区间，限制后续模板，不硬编造唯一宇宙真值。

```text
视界测试 + 独立宇观/底噪档案 → 双尺度闭合图谱
图谱 + 巨型节点框架的受控采样 → 世界之心频率
世界之心 + 弦关系 + 有限规则搜索 → 维度规则候选
```

世界之心是一份版本化的世界特征记录：维度来源、参考频率向量、可测边界模式、适用范围与不确定度。它不是包含每个区块/实体全部信息的文件，也不是热噪均值本身。频率向量承载被辨识的世界特征，具体参数含义来自模型。

**实验**：选择一个新地点/天区做外推验证；更换传感器后按校准版本复核；保留一个被当前模型解释不了的残差。世界之心可重新采集，丢失纸本不锁死，不能复制一个记录就复制已有世界实例。

> “最初我试着让一枚晶种接近共同的背景。现在，我能描述这个世界怎样从背景中显出自己的差别。”

## 5. 创世：用已经理解的差异构建一个可返回的世界

**旧稿依据**：[阶段表§12](../Kamaen_Info_Stage_Content_Line.md)。保留七组参数、预注册模板、创世编译、点火环、锚与维护。

| 参数组 | 玩家实际选择 | 首版限制 |
| --- | --- | --- |
| 地形基底 | 平原、浮岛等登记生成模板 | 固定槽位，不任意在线注册生成器 |
| 群系权重 | 已认识群系的有限混合 | 权重归一，生存条件有检查 |
| 物理规则 | 登记的低重力等局部规则组合 | 只能修改模组支持的规则，不任意改MC物理 |
| 资源频谱 | 已解锁物质的分布/开采条件 | 固定物质种类不变，预算有约束 |
| 实体生成 | 支持列表、密度与活动范围 | 有容量和可居住性上限 |
| 底噪结构 | 已辨识模式的强度与空间关系 | 固定规则族内调参，保留版本 |
| 熵增速率 | 模组定义的维护/规则漂移强度 | 明确这是游戏维护指标，不等同热力学熵 |

选定“物质种类固定”的世界观后，创世不引入任意新元素。R1建议平均基底参考也在同一模组规则版本内共享；新维度改变环境、丰度与边界模式，而非悄悄重定义每种材料的基础坐标。特殊维度的材料实测受环境影响，可回标准条件比对。这是便于跨世界实验衔接的候选实现选择，待审核。

```text
世界之心记录 + 戈古尔斯弦关系 + 规则候选
→ 创世蓝图 + 七组参数矩阵
→ 编译检查/有限预演 → 已编译维度核心
实体核心/空间锚 + 独立返回锚 + 点火环/储备
→ 激活一个空闲维度槽 → 首次进入与基线复测
```

**初步规则模型**：离散约束表处理互斥/前置，连续预算约束处理供能、稳定、资源与维护。先给3–5个可行模板；自由编辑可优化，但不能靠改变目标函数绕过硬约束。模拟预演只筛掉已知冲突，点火后的真实观测仍须验收。

“晨曦世界种”作为已编译实体核心的候选显示名，复用`compiled_dimension_core`实例绑定，不另造免费世界复制道具。蓝图可复制，已绑定核心只引用同一个世界实例；二次创建需要新槽、资源与点火，不覆盖现有存档。

**研究闭环**：进入新维度后测平均参考、环境底噪、三类材料响应与维护负载，比较编译预测。规则偏差来自明确模型/工况，不能因为玩家升级研究就悄悄改旧世界定律。调参形成下一版蓝图，不原地重生成已建设区块。

> “这一次，频率不只是用来辨认已有的差别。我开始选择哪些差别可以共同存在，并为它们的延续负责。”

## 6. 维护、返回与终局后的研究

完成条件不是合成核心，而是：进入、建立一处实际作业点、稳定运行、离开、休眠、恢复并返回。母世界留有不依赖新维度供能的返回/救援设施。

维护塔在有限采样点估算游戏规则漂移，任务生产低于入口/救援的储备优先级。储备不足时先关闭生产并提示撤离；有人留在内部时保持应急退出路径，不直接把玩家封在禁止进入的维度。休眠停止新增产出与大部分维护结算，保存已有结构和档案；恢复先自检再开放运行。

区块卸载/服务器离线不累积无限灾难，采用有上限且可解释的补算或暂停约定。故障只影响登记设施/规则范围，不随机删基地。重启、迁移与多人同时进入的实例绑定需要实现阶段专门验证。

终局后的玩法：比较不同模板的预测与实测、维护不同用途世界、优化电/光/量子/视界分工、扩大模型适用范围、探索登记边界模式。允许“仍有未解释残差”，不必把解出全部开发者公式作为通关条件。

最终笔记回到初始晶种：

> “那枚最初的晶种还在。它没有替我藏好答案，只给了我一个可以反复比较的起点。后来，我学会辨认差别、留下解释，也学会让一个新的世界保有自己的差别。”

## 7. 本段反向修正

视界前三项工程必须独立存在：普通供能、基础膜工艺、独立停机；创世前三项必须独立存在：知识档案、可制造实体核心、母世界返回锚。知识与实例、状态与副本、输出与预算全部延续早期信息系统的边界。

至此主线从平均背景结晶到可维护新维度闭合。数值阈值、配方数量和每段时长尚待原型，不因候选流程完整就宣称已具备完整物理仿真或可通关实现。
