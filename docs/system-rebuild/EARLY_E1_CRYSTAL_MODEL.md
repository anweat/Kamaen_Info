# E1：贯穿始终的卡玛恩晶体模型与早期分析

2026-09-07，模型讨论稿。配套：[前期玩法](EARLY_E1_GAMEPLAY.md)、[物品工具目录](EARLY_E1_CONTENT.md)。以下是虚构材料的降阶游戏模型，提供一致的因果关系与可检验例子，不当作真实晶体或爆轰的数值模拟。

本轮力学与制造细化见[E1.1矢量力学工艺](EARLY_E11_MECHANICAL_SYNTHESIS.md)及[从工艺推导机器](EARLY_E11_PROCESS_MANUFACTURING.md)。M2现按局部有序历程解释；原D算例仍供追溯，不能独立判定晶化、结合或完整合成。

## 1. 一个晶体对象，三种不同的信息

晶种、粗晶、用途晶体、切片和器件区域沿用同一物质模型。加工改变实际状态；测量增加已知信息；模型卡保存玩家的解释。改名字、打开界面、换用途槽不会重新生成一套晶体属性。

| 对象 | 内容 | 谁能改变 |
| --- | --- | --- |
| 实际晶体 | 材料/内部结构、残余应力、缺陷、质量与几何、工艺历史 | 实际成核、生长、加工、接触/损伤与环境演化 |
| 观察记录 | 激励/方向/温度、探头/参考、读数、误差、有效性、来源 | 测量生成新记录，旧记录不被新校准悄悄改写 |
| 玩家模型 | 假设、选用变量、参数、适用范围、训练/留样来源、预测误差 | 比较、拟合、验证；不直接写回世界真值 |

玩家通过后两类对象逐渐认识第一类。研究进步表现为能解释更多现象、预测更多工况，并以更少试错获得需要的材料。

## 2. 从晶种延续到中期的状态模型

```text
CrystalState
  object_id, parent_batch_id, material_model_version
  mass, geometry, region_map
  composition c
  structure A, crystal_orientation Q
  residual_stress S, defects d
  background_deviation z
  process_history_ref

RuntimeConditions
  temperature, applied_load, excitation, contact_map, supply_state

Measurement / Knowledge
  observation_id, object_revision, instrument_and_reference
  excitation_domain, frequency_axis, pose, conditions, raw_reading
  uncertainty, validity, sampling_sequence, model_links
```

`c`为固定物质集合内的组成比例，非负且和为1。前期采用登记的固定基材配方，暂不让玩家同时调节所有组分；中期开始区域处理与组成实验。质量、体积与晶种/生长料来源始终保留，不能由一次波形记录生成一大块晶体。

`A`为有效内部结构的低阶摘要，`S`为残余应力，两者分开：外部卸载、退火松弛后，材料不一定回到初始结构。首版A采用对称、半正定、迹为1的定向分布张量；平均各向响应示例取I/3。它描述当前模型分辨率下的结构倾向，不声称完整表达原子晶格。

`Q`是晶体坐标到设备坐标的旋转。世界位置、装夹朝向与晶体局部轴各自保存。`d`至少分裂纹/结构不连续、散射/混入、可恢复缺陷三类；早期只给粗可见征象和部分推断，不让每类缺陷都成为一个必须满分的进度条。

`z`描述相对世界平均背景参考的属性偏差。它不是万能质量分，也不替代组成或结构。一次均值化只能沿合法材料/工艺路线改变对应状态，不能用独立调节z把任何原料任意改成中性晶体。

E1.1按工艺需要增加区域相态ξ、孔隙率φ、塑性形变/体积、内能以及界面结合b。它们与晶体状态一同演化：压实不等于晶化、晶化不等于定向、贴合不等于均匀混合。残余应力当前采用拉伸为正；旧压缩为正的算例须带约定转换，卸载后的残余状态不能直接等于外加载荷。

初始晶种的平均性是世界设定；初级仪器只能在有限通道上提供支持这一认识的证据。“白噪”在名称中指背景起点，不意味着所有仪器、所有频带的噪声都服从白噪声模型。

## 3. 按发展顺序引入五个局部模型

### M0：均值化与成核

登记原料先经处理接近参考状态。在有效窗口内用如下松弛关系作为首版候选：

```text
z_next = exp(-k_m * D_m) * z + process_deviation
D_m = 在有效温窗内积累的处理剂量
```

参考零点对应世界规则中的平均属性向量μ。`process_deviation`来自固定母批和真实工序扰动；测量误差另算。偏差小不保证缺陷少：过热、接触污染或冷却失控仍可能使成核和后续加工变差。

成核要求合格基底、足够实际料量、允许的保持/冷却历程。公开保守工序保障第一枚晶种可达；玩家之后通过温程对照认识更细窗口。失败保留未成核料/缺陷样品及历史，不通过重新打开容器抽一次成功。

第一张模型卡只需表达“这个保持区间内，可观察偏差通常减小”，并附实际数据与未检验的范围。

### M1：弹性响应、持久结构与方向

早期仪器对指定激励域/读出口测有限响应R。局部模型写成：

```text
u_local = Q^T * u_device
r = r_ref(c) + a_A * u_local^T A u_local
              + a_S * u_local^T S u_local
              + a_L * applied_load + a_T * (T-T_ref) + defect_response(d)
```

这里r只是一项指定观测，例如峰位或归一化透过指标；不同指标有不同关系和单位，不能一式代替所有物性。a_L作用在当前加载，卸载即撤除；A和S是否改变取决于是否进入相应加工窗口。

玩家先做加载/卸载与90°转向对照，再做不可逆加工。第一次无需知道全部张量元素，只需证明“这条方向上的响应变了”和“变化是否在卸载后保留”。方向测量不足时不绘制伪精确的完整应力椭球。

### M2：冲击怎样写入材料

输入按来源保存相容的力/运动关系、能量预算、时间包络、激励域、作用位置/方向和路径。电能经实际驱动形成机械作用；能量是标量，冲量是矢量，局部应力是张量，FE接口本身不携带机械波形。

```text
源与结构 → 接触/到达历程 → 少量区域内的加载、温程和材料演化
         → 卸载/冷却后的结构、相态、界面与缺陷 → 实际产物流与复测
```

两次作用的总能量和净冲量相同，空间/时间历程仍可能不同。首版分别计算粉化、压实、晶种诱导、定向和结合的有效窗口，保留作用次序与区域；详见[E1.1](EARLY_E11_MECHANICAL_SYNTHESIS.md)。弱激励响应不直接外推为强冲击模型。

原`D=Σ(E_abs/V)nnᵀ`可记录某个压缩模板内的定向能量沉积，丢失的时序、符号和空间信息须由其他状态保存。原`A_next=(1-λ)A+λD/trace(D)`仅在已知适用的定向重排模板中候选使用；λ由有效不可恢复历程决定，可恢复加载或零剂量不改A。不能据D或λ直接决定晶态ξ和所有产物。

原`S_next=relaxed(S)+k_SD`停止作为完整合成规则。新残余S需由区域材料变化和卸载约束求得，含平衡边界；首版只执行已有模板。过载损伤、相态转变能和内部耗散/热交换分别收账，不能用clamp掩盖。

反射仍只搬运装置中尚存能量，衬板具有有限反射/耗散/承载。未解析尾波或空间模板不能默认为零然后判定成功。新的[有限过程例子](EARLY_E11_PROCESS_EXAMPLES.md)专门检查相同总量、不同历程的反例。

### M3：晶体与生产设备的耦合

先确定工作域、激励、晶体响应和实际安装路径；再估计哪些组分进入哪个出口。能量传输量采用非负份额，所有端口的输出/损耗共同守账；不是任何表示方式下的振幅都必须小于1。

一个可计算的分离模型为：原料有合法组分质量m_j；每个组分分配到目标口、其他口或余料。用归一化权重或对应受限函数得到p_kj，要求每一输入组分`Σ_k p_kj=1`，且全部非负。

```text
outlet_mass[k,j] = m_j * p_kj
p_kj = response(input, crystal, installed_path, excitation, process_state)
```

晶体改变的是这组分流概率/有效回收和实际处理速率。目标口的铜增加，可以来自原先进入其他口/余料的铜；不能由它制造更多输入中不存在的铜。粗分离中“其他口”是混合流，不能隐含免费再变成各类纯成品。

[有限例子](EARLY_E1_MODEL_EXAMPLES.md)把这条因果链连到A：结构和安装方向改变指定机械峰位，峰位与实际驱动/路径决定该工况的作用份额，最后影响各组分分流。其三角形频带窗口只是粗模型候选，不能替代全部传递谱。驱动能够改频时，旧晶体也可能通过重新调谐达到同样效果；改材料、改安装、改激励都可以是工程解。后续以实际可达频窗、共用源、稳定性和几何需求区分用途，不能人为规定只有新命名晶体才有效。

玩法报告分别看目标回收率、目标口纯度、处理时间、能耗和维护。改善一个指标可能恶化另一个指标；模型卡写清到底预测哪个量。前期先观察两三个指标，其余保留记录供以后展开。

### M4：退火、维护与长期状态

在指定温窗内，残余应力和某些可恢复缺陷分别松弛；A可按更慢或不同条件变化，裂纹不自动消失。例：

```text
S_next = S * exp(-k_Sa * D_a)
d_recoverable_next = d_floor + (d_recoverable-d_floor) * exp(-k_da * D_a)
A_next = (1-λ_a) A + λ_a A_eq       （仅当该结构恢复条件成立）
```

外部夹具和表面污染也有自身状态，清洗/重新装夹不能被错误记录为改变晶体组成。维护前后用同一参考条件复测，已有生产设备因此成为持续的实验对象。

## 4. 玩家逐渐认识模型的工具

| 工具层 | 玩家能做什么 | 实际数据/计算边界 |
| --- | --- | --- |
| 留样与工程册 | 标注母批、整理已测表格、叠加曲线、手工画拟合线 | 只对已有读数操作，人工判断不查询世界隐藏真值 |
| 简易比较架/拟合尺 | 同一激励下比较两样品，选两个点读取差值/斜率 | 单域、少量通道，夹具/刻度误差可见 |
| 固定步进扫描器 | 在允许窗口内按固定序列改变一个变量 | 每步确实驱动、等待和采样，重复旧数据不增加样本 |
| 固定统计台 | 对最多16组x/y/条件标记，求均值、离散程度、直线拟合和留样残差 | 固定累加/比较/记录功能；有限寄存/记录空间和电源，不执行任意模型图 |
| 中期控制板/模型系统 | 任意受支持算子组合、多变量拟合、参数学习与主动实验 | 正式计算/存储资源、部署与版本，继续使用同一记录/模型协议 |

固定统计台由普通机电计数/累加模块、比较结构、记录机构和读出接口组装；晶体参考可改善对应测量，并非台中凭空藏有通用CPU。首版工作区容纳16条样本槽，每槽x、y和条件标记，统计寄存区另计；候选为128 B等效固定寄存与384 B样本容量。每槽按24 B等效预算：x/y各8 B、记录/条件索引8 B；完整来源与实验条件保存在实际记录载体中，不假定一个索引能容纳全部元数据。它们不可寻址为通用RAM，不导出算子执行服务。

若实际实现选择将固定统计台表现为机械/模拟计算工装，必须保留相应精度、范围与操作时间；这些容量是游戏记录预算，不声称给出了现实电路实现。工程册仍只做记录/展示与手工拟合，自动统计必须绑定已存在的设备。

第一条拟合模板：

```text
y_hat = a + b*x
b = Σ(x-x_mean)(y-y_mean) / Σ(x-x_mean)^2
a = y_mean - b*x_mean
```

全部x相同时不能拟合斜率；样本数不足、条件不同、测量无效时分别提示。模型卡保存目标量、单位、x/y定义、方向/温度窗、参考版本、拟合记录与留样记录。它不是一颗只要放到机器上就永久改善产率的科技物品。

## 5. 三张可以很早出现的模型卡

| 卡片 | 研究问题 | 数据来自哪里 | 怎样验证/回生产 |
| --- | --- | --- | --- |
| 均值化窗口卡 | 保持到什么时候有用，什么时候开始增加缺陷 | 同母批的短/中/长温程与重复读数 | 留一批复验，再把有效窗写成坩埚工序 |
| 晶体方向响应卡 | 某个加载/方向区间怎样改变指定响应 | 定向加载、卸载、转向和参考对照 | 对未参加拟合的试片预测，选择加工设置 |
| 分离工作窗卡 | 哪个激励/安装使目标回收或纯度更好 | 同批泥浆、同一工作晶体、改变一个设置 | 用新批次复验，指导生产设备调谐 |

同一母批中，处理偏差、固定个体偏差和测量噪声分开。记录需要时间和执行顺序，避免总在热机时测高档、冷机时测低档。初始实验每条件建议3次有效测量，条件数先限制在3—5个；更大样本需求才促使自动扫描和统计升级。

分析结果先作为下一次操作的建议。模型在已知窗口内表现好，不能自动获得全域正确性；改变材料族、几何、方向或温度后应标为未验证。误差突然变大时，用参考和对照判断是模型、仪器、安装还是材料历史发生变化。

## 6. 数据如何进入中期

粗谱可以只有少数频带，后续测量增加分辨率。每条记录保存自身频率坐标、激励域、量纲、采样窗口与探头；细谱不能伪装成把粗谱插值后得到的新测量，机械响应频带也不能直接冒充光频谱。

切片/器件继承母批和所取区域的实际状态，重新建对象与几何；加工历史关联到原件。生产安装、封装、热和夹持条件继续进入响应模型。R4的器件模型在这个状态上增加区域、接触、反馈与端口结构，模型图/集群只负责组织数据和计算。

研究记录可导出到中期数据集；手工录入标记为人工记录，原始仪器记录保留来源。模型卡的参数、验证和有效域进入中期模型工件；固定统计台不会因接上网线就升级成无限通用计算节点。

## 7. 本轮明确的模型边界

本稿先确定对象、因果、观察和逐步认识的方式，保留后续扩展接口。未冻结全材料的真实响应函数、全应力/裂纹解、全部工艺常数和随机过程。有限算例验证方向信息不被净冲量抹掉、分离质量账、拟合与留样等指定关系，见[模型例子](EARLY_E1_MODEL_EXAMPLES.md)。
