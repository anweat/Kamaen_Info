# R1模型、随机实验与研究验收目录

状态：初步模型候选，随[完整发展线](REVIEW_SYSTEM.md)统合。这里统一模型边界和实验入口，不把全部候选公式冻结为最终物理。精确公式与故事操作见对应发展线，D1仅提供局部推演参考。

## 1. 共同底层：真值、读数与解释分开

**世界规则层**产生材料状态、工艺转移、环境场与登记天区；**仪器层**根据响应、带宽、偏差和噪声产生读数；**玩家模型层**用可取得的数据解释、预测与控制。玩家只接触仪器公开结果，不直接读取隐藏标签作训练目标，除非该任务明确给出校准真值。

最初固定物质种类R，共同属性空间中的平均参考`μ=Σw_r*v_r`，w非负且总和为1。权重按登记类别分组或按种类加权仍是待审选项，不能因为某MOD重复注册大量等价物品就自动改写背景。R1暂建议基础种类/权重随模型版本固定，新维度改变环境与丰度，不静默改共享μ。

平均不是“每种组成都相同份额”。不同组成可能映射到相近可测属性；同均值也可能具有不同方差、相关结构和缺陷。初级仪器只能证明有限可观测性质接近参考，不能一次显示所有隐变量已精确为均值。

晶体状态暂归纳为`X=(实际组成c,应力S,取向Q,缺陷D,加工历史h)`；应用响应是`y=F_task(X,环境,激励,几何)`。当前各段F是局部模型，未来统一时须保持早期有效工况可复现，不能用一个多项式把所有物性强行揉成万能分数。

## 3. 随机实验怎样成为玩法

每次实验由玩家选择：研究问题、样品/参考、可操纵变量、要记录的通道、采样预算、停止条件与用途。入门给模板和合理窗口，进阶允许修改；不用要求玩家手填统计术语才能开始。

随机层次至少分四类：世界固定参数、共享母批状态、真实过程/环境波动、仪器测量误差。真实历史一旦发生就存为记录；重复加载存档不能把同一件晶体刷出新属性，改变实际工况则应改变后续过程。多人同时测同一源需共享物理真值，各自仪器误差另算。

首轮实验预算候选为少量工况×少量重复，二因素实验从四个组合起步；精确次数由噪声、成本与试玩决定。抽样结果有误差条，不要求每次必定显著；达不到区分能力时提供继续测、换仪器、改变干预的解释，不直接判玩家答错。

研究验收分三层：

1. **操作成立**：设备/输入有效、对照可比、采样有来源。
2. **解释有效**：在声明范围内，对未见样品/时间块/工况给出足够好的预测；等价模型可通过。
3. **技术可用**：把预测或策略装回实际设备，完成有成本/稳定要求的任务。

前两层不能替代第三层，训练分数也不能直接授予材料。科研成果保存在研究档案，丢失一个载体可恢复；已掌握公开保守工艺不因模型设备损坏而被撤销。

## 4. 尚需验证的反例与后续原型顺序

| 原型 | 必须主动尝试的反例 | 通过标准 |
| --- | --- | --- |
| 平均/晶体/分离 | 未经处理滤渣重新加偏、循环回收刷质量、专化被误判低质量 | 有质量账；中性/缺陷/用途指标分离；参考可复现 |
| 组成/工艺 | 剂量与应力共线、退火抹去特化、频谱幅值相同相位不同 | 需要交叉干预/历史/新观测，不强迫猜唯一隐变量 |
| 光电/数据 | 光强当负权重、光RAM强制前置、断网重试重复投料 | 显式编码与预算；混合替代可用；任务副作用去重 |
| 学习/策略 | 标签泄漏、旧轨迹刷分、停机策略最高奖励、传感失效 | 独立分组与实际验收；任务完成和安全预算同时达标 |
| 底噪/宇观 | 同维度全空间同读数、把复制当样本、用前景证明宇观结论 | 稳定索引+空间信息+独立数据与通道 |
| 量子/过程图 | 关探测器得满分、HOM证明一切、玻色采样冒充VQE | 计数完整、任务能力明确、经典基准与实际试制 |
| 视界/创世 | 启动依赖自产电池、发电又全额返质量、暂停删数据、返回依赖新世界 | 普通启动、守账、持久记录、母世界独立救援 |

D1的[模型原型结果](MODEL_LAB_RESULTS.md)仅为组成/应力可辨识性与噪声归因提供早期局部证据。R1未运行完整数值原型；上述反例是验收设计，不是已通过测试的宣称。

## 5. 资料与科学表述约定

发展线四已逐项链接HOM原论文、混合变分求解原论文、NIST热噪/边界研究、NASA红移/透镜与诺贝尔奖科学背景。使用的内容是实验要操纵什么、测量能说明什么；不借来源证明卡玛恩晶体、戈古尔斯弦、视界工厂或创世真实可行。

未在本轮给出完整一手理论推导的名称，先作为候选显示名而非准确模拟承诺。后续若增加具体公式（例如完整材料响应、编码器、纠错或复杂天区模型），需对该公式单独核对来源、适用域、数值稳定性与游戏成本。
