# L1.2任务稿：提前抵达的回声

状态：2026-09-08，讨论候选。承接[L1.1方向](LATE_L11_EXPLORATION_AND_THEORY_DISCUSSION.md)；与[材料过程任务](LATE_L12_PROCESS_GAMEPLAY.md)并行。这里把天区探索、预测和传播模型拆成连续操作；有限数字见[复算报告](LATE_L12_TASK_PROBE.md)。不新增空间维度、天体实体区块或全局通关门槛。

L2修订定位：本文作为玩家已有回响图、远端参照与探索网络后可遇到的特殊观测项目，不再单独承担信息时代到宇观的开场过渡。主要连续体验按[L2讨论](LATE_L2_INTEGRATED_PROGRESSION_DISCUSSION.md)，材料与世界探索先在实际作品中共同发展。

## 1. 故事从两次相似的变化开始

玩家已能给天区目标测谱。在一份巡天记录里，两个位置不同的光点有相近谱线，而且亮度变化的细节非常相像，只是先后错开。研究笔记暂名“回声”，并不认定它真的反射过，也不声称信息超光速。

前期同一块晶体的性质随测量方向改变；这里则是同一份信息可能沿不同路径到达。玩家需要找到合适的观测条件、保存时间记录，并尝试在新事件发生前指出另一处应该出现什么。故事由玩家的可检验预测推进，不依靠必须刷到的遗迹碑文。

现实启发是Refsdal超新星经引力透镜再次成像的预测与观测：[NASA项目报道，2015](https://science.nasa.gov/missions/hubble/hubble-captures-first-ever-predicted-exploding-star/)。游戏改用可反复活动的有限天区源，压缩角度和时间尺度，不让超新星按任务需要反复爆炸。

## 2. 探索发生在哪里

| 探索对象 | 玩家能做什么 | 实际影响与边界 |
| --- | --- | --- |
| 基地附近、山脊、地下出口等测站候选 | 搬便携测头，记录遮挡、杂光、振动和可见时段 | 地势并非等级加成；实际遮挡和本地干扰决定是否适用 |
| 天区目录与相邻目标 | 巡天、测谱、保存时间序列，追踪候选 | 目标是有限天空观测场；不是每颗星一个实体或加载区块 |
| 暗弱中心区域 | 选择口径、响应窗、曝光和中心背景处理 | 看见中心像需要真实分辨与对比能力，放大界面或增加电子增益不足以替代 |
| 已有原版维度中的测站 | 携带同一参考源、晶体和仪器，测当地条件后返回复测 | 没有天空视线的地点不能凭空看见同一天区；仍可作本地传播/仪器对照 |
| 可重复活动事件 | 等待下一次独立变化，或先做其他研究后返回 | 错过一次不锁死科技；不能把同一记录反复读取当新观测 |

首个任务可在一处合适主世界测站完成。远行用于找更好的条件、替代目标或验证地方性干扰，不设固定距离跑图，也不把步行几百格解释为足以测出遥远天体视差。

设备沿用L1的谱仪、天区收集头、追踪支架、计时/记录与温度参考。在现有光学部件上逐步增加有效口径、角度读数和稳定跟踪能力；桌面或少量功能方块可搭成测站。普通原版材料负责确有定义的遮光、支撑或导热，不要求铺满专用“天文结构块”。角分辨、通光率、视场和PSF都来自组件与装配，不能统合成一个观测等级。

## 3. 从发现到新预测的完整任务

| 步骤 | 实际操作 | 界面反馈 | 完成证据/失败后继续方式 |
| --- | --- | --- | --- |
| 找站 | 在2—3个可达位置各测一次参考源和本地背景 | 站点卡列遮挡、噪声、有效视场；不显示隐藏天体参数 | 选能胜任的站点；已有基地达标也可用 |
| 巡天 | 在相邻方向采集角位置、粗谱和亮度时间序列 | 星图只显示测过的对象，未探区域保留不确定 | 识别值得追踪的一对信号，不预标“透镜目标” |
| 排伪 | 换/旋转读出，参考校时，对照空天区与未受影响目标 | 目标在天空坐标与探测器坐标中的表现分开 | 排查鬼像、共同背景和时间偏移；异常不消失也不等于唯一解释 |
| 配对 | 比较谱线与两次变化的形状，搜索有限时差 | 显示匹配峰及其他可行时差；周期别名另列 | 不能只比较“都变亮过”；增加非周期细节或下一段观测 |
| 推演 | 从点质量、有限核等已提供的传播模板开始 | 能拟合已有两像的模型并排保留，显示所需额外约束 | 首轮不给一条拟合曲线盖“真理”章 |
| 预告 | 保存第三像位置范围、到达窗口与最低灵敏度 | 星图上是带宽/时窗的预测层，与实测层分色 | 检查能否观测；预测域内也可能需要升级收集与稳定性 |
| 守候 | 在下一次独立活动事件，记录A后搜索中心区域 | 事件进度、曝光覆盖、时钟/背景状态均可查看 | 视线被挡或错过窗口可等下个事件，不生成虚假补录 |
| 判读 | 比较新信号的位置、时间、谱形和变化细节 | 支持、排除、约束不足分别说明原因 | 没看到时必须先看检出限与覆盖，允许输出有用上限 |
| 交付 | 保存错时星图、传播约束和测站配置 | 下一次观测可按预测安排，设备改进目标明确 | 得到可复用研究能力，不从天图中取出黑洞原料 |

第一轮使用接近轴对称、已能估计前景中心的教学目标；复杂星场、偏心/外剪切、多透镜等留作后续。前景中心的位置是观测估计，前景发光强度不直接等于质量，也不能直接读出真实透镜势。

## 4. 同一套物理规则如何生成像与到达时间

本节是作者可复算的有限模板。实际世界参数、测量估计、玩家候选分别保存。改变候选图不会改变天空；目标种子/规则版本和事件历史稳定，重开面板不重抽答案。

透镜方程与费马到达时间方法的依据见[Narayan与Bartelmann，引力透镜讲义，§3.2—3.4](https://arxiv.org/pdf/astro-ph/9606001)。在该近似下像的位置是到达时间面的驻点，相对高度给出时延，放大率的符号表示像的奇偶。以下势函数和缩放是为游戏选取的有限例子，不能拿来反推现实天体单位。

选二维轴对称有效势`ψ(r)=b√(r²+s²)`，`b>0、s>0`。在已知源—透镜轴的一维截面上：

```text
β = θ - bθ / √(θ²+s²)
τ(θ;β) = 0.5(θ-β)² - b√(θ²+s²)
Δt_i = K [τ(θ_i;β) - τ(θ_A;β)], K>0
λt = 1 - b / √(θ²+s²)
λr = 1 - bs² / (θ²+s²)^(3/2)
μ = 1 / (λt λr)
```

`θ、β、b、s`都是同一声明单位下的归一化角量，`K`把本例归一化时间面差映射为游戏秒；现实距离/红移因子不从这个数字自动取得。像通量用`|μ|`，负号只描述奇偶。相对于A的零点任意，不能把τ的负值理解为信号在源发出前抵达。

首个模板工作在远离焦散的范围，使用有限源、已标定PSF和有限曝光；点源放大率只作此范围内近似。接近雅可比行列式为0时须转用有限源计算或报告近似失效，不能获得无限亮度或能源。首版不需要做全三维宇宙模拟。

作者验算目标取`b=2、s=0.5、β=0.2`。从方程求根再按到达时间排序，而不是预写三个像坐标：

| 像 | 角位置θ* | 相对A到达时间 | μ | C相对A的通量 |
| --- | --- | --- | --- | --- |
| A | 2.147919 | 0 | 11.264717 | — |
| B | -1.720547 | 120秒 | -9.421740 | — |
| C | -0.067475 | 238.700秒 | 0.116611 | 约1.035% |

选`K≈154.978989`令本例A→B为120游戏秒。它们是作者侧教学真值，任务界面只能得到角位置、时延和通量的测量结果及误差，不显示`b、s、β、K`答案。内侧像相当暗，所以“把模型算对了”尚不足以把它看见。

## 5. 只看两像还不够：把不确定性做成下一步玩法

以已测A、B角位置和120秒时差为第一批数据；为便于复算，表中暂不加测量误差。任选一个候选核尺度s，可得到恰好拟合这两个位置的：

```text
b_s = (θA-θB) / [θA/√(θA²+s²) - θB/√(θB²+s²)]
β_s = θA - b_s θA/√(θA²+s²)
K_s = 120 / [τB_s - τA_s]
```

| 候选核尺度s | 同样能拟合A/B位置与时差 | 预测C位置 | 预测C在A之后 | 预测C/A通量 |
| --- | --- | --- | --- | --- |
| 0.35 | 能 | -0.045211 | 260.024秒 | 0.459% |
| 0.50 | 能 | -0.067475 | 238.700秒 | 1.035% |
| 0.65 | 能 | -0.090586 | 221.848秒 | 1.895% |

因此第一张预测卡应是“这三个候选预计中心附近约222—260秒出现约0.46%—1.90%的像”，加上角度、校时和参数测量误差；不是直接显示239秒。这个范围仅代表所列三个候选，不是假装已经覆盖所有连续参数与其他透镜模型。

另一种点质量模板`ψ=m ln|θ|`也能通过已有两像：取`m=-θAθB>0、β=θA+θB`，再用实测时差定K。它只有两个像，不预测中心第三像。这里才有值得探索的分歧。点质量不是所有紧致天体的完整模型，看见第三像支持这些有限核候选并限制该两像模板，不直接证明或否定所有黑洞。

若先得到更多通量比、形态或前景约束，可提前淘汰部分候选；不能为了剧本保留三张卡而忽视玩家已有好数据。仪器足够好时允许提前完成；数据较差时允许延长观察或换目标。

## 6. 光变、计时与“没有看见”的实际计算

后端先生成一个源的有限光变`S(t)`，各像复用同一段事件，经真实到达延迟、通量、PSF和仪器响应生成观测：

```text
I_i(t) = |μ_i| S(t - t_event - Δt_i)
readout = exposure_integral[PSF × I + local_background] + detector_noise
t_recorded = t_world + clock_offset(t)
```

`t_event`在此是A像到达的参考时刻，不是未测的源发射时刻。相邻像泄漏、前景背景和暗电流进入实际探测通道；光谱同样经过仪器，而不是直接输出对象ID。源变化的振幅在一个事件内共用，局部读出噪声不同；独立事件使用新的光变细节，不能复制同一张曲线刷研究次数。

初始事件可由“约每900游戏秒出现一次活动窗口”的目录规则提供，窗口内具体脉冲形状变化；具体节奏待试玩。玩家观察下一轮A后才以它为时间原点寻找B/C，不要求第一次发现A后立刻造完所有设备。天气/遮挡遵守世界和仪器条件；若连续不适用，可找另一可达站点或目标。事件不会等到打开UI才发生。

一个测站可同时覆盖全小视场，或由同一参考时钟顺序跟踪各区域。多站不是必需品；需要多站时再使用R4同步与网络，校时要计入参考传输时延。若B站时钟比A快15秒，真实120秒会读成135秒；互相关不会自动消除此偏差。前后参考、共钟对照和漂移估计应与天体时延一起记录。

| 未检出情形 | 能得到什么结论 | 接下来做什么 |
| --- | --- | --- |
| 中心区域的实测检出限是A的2% | 上述三个候选都可能太暗，不能因没看见而排除 | 改善实际收集、背景/PSF、稳定性或曝光覆盖 |
| 条件检出限0.8%，并完整覆盖各候选时窗/位置 | 在当前误差与背景假设下可检验两个较亮候选，最暗候选仍可躲过 | 记录有条件的上限，检查系统误差后再缩小集合 |
| 只在239秒附近看了一小段 | 不能排除222或260秒附近的预测 | 下一独立事件扩展覆盖，不重放旧图当补测 |
| 中心出现亮点，但光变/谱形不匹配 | 可能是前景、本地伪影或另一对象 | 保留异常记录，追加排伪，不强行认领C |
| 同时符合位置、时差、谱与光变细节 | 新数据支持其适用范围内的候选 | 再选新事件或新参数范围验证，收紧传播约束 |

检出限不是“曝光N次即解锁”。应通过相近中心背景与位置的校准/注入恢复分析或实际已知参考估计，注明假阳性概率和覆盖。合成注入只用于验证分析流程和估计灵敏度，必须标为合成，不能作为发现天体的观测证据。固定系统误差不会随重复曝光无限缩小。

## 7. 统一面板、数据与性能如何适配

工程项目增加天区页签：左侧是实测星图和站点，中央切换光变/传播图，右侧是候选、预测窗口和仪器是否胜任。未探区域与候选像用不同样式，第三像不会因画出预测就变成实测。世界中保留可操作收集头与实际视线；界面处理目录和图，不造大量天体占位方块。

| 记录 | 需要保存的内容 | 与其他层的边界 |
| --- | --- | --- |
| 测站配置 | 世界位置/维度、方向、组件实例、有效口径、PSF/背景和校时版本 | 不是研究图节点位置 |
| 观测块 | 采集区间、原始数据、坐标/参考、曝光、时钟、来源及遮挡缺失 | 测量记录不含隐藏透镜参数 |
| 事件配对 | 引用哪两段、有限时差搜索、多个候选峰与匹配条件 | 分组标签不自动等于同一个天体事件 |
| 传播候选 | 势模板与参数范围、拟合使用的数据、失效范围 | 与世界的生成参数隔离 |
| 预测卡 | 保存时刻、未来观测条件、位置/时窗/通量范围 | 改版另存，不能事后替换旧预测 |
| 错时星图 | 实测对象、带条件的约束、已验证/未验证推断和配置引用 | 是知识与作业规划资料，不是空间能源物品 |

只对实际工作的已加载测站采样，除非玩家配置了已定义且付费运行的持续加载能力；区块离开后保存时间和缺测段，不声称整段都采到了。重新加载可计算当前天区状态，不能补造仪器未运行的历史。分布式观测必须考虑在线情况、存储、传输与同步。

首轮B01可对已提取的两条64点、每点32位亮度数组作有限相关，共512B；再留512B候选/暂存、512B程序及256B输入输出，总1792B，剩余1792B待运行开销核算。逐时差计算累加，不需要完整FFT。各候选的归一化时轴、采样间隔和记录来源在持久记录头中，不能省略缺测处理。此数字只证明一个小数据布局有空间，不证明完整采集/求根软件已经可运行。

求根可分区间扫描后用标量二分，比较少量势模板；高清巡天、多源分离、长时序、更多候选才形成真实计算负载。自动化帮助选择观测窗口与调度设备，不能凭更高算力消除没有覆盖的时段或不够好的光学分辨。

## 8. 向量子、黑洞、时空与维度的具体过渡

两条首轮任务都不必单独证明终局理论。它们提供可验证的方法和可制造的测量能力，然后提出新的实验：

| 后续段落 | 由本轮留下的具体问题 | 下一类动作与可能产物 |
| --- | --- | --- |
| 宇观紧致源 | 一个传播解释能否同时描述更多像、时间和谱；波形独立片段是否一致 | 扩展观测与有限传播/波形模板，产出紧致源约束图；研究引力波须另有对应位移/相位设备 |
| 材料模式与类视界 | 既然不同路径产生不同到达时间，能否在可控介质里改变某一支模式的传播 | 测色散、群速与介质状态，绘制可逃逸/受阻路径；初始产物为模式通道与边界测量组件 |
| 量子统计与相关 | 同样的输出谱是否可能来自不同过程；配对记录能否区分 | 先补实际态制备、计数、计时与暗事件对照，再做联合统计；不会由两条光变相似直接解锁纠缠 |
| 类霍金研究 | 受阻边界附近的输出究竟是驱动泄漏、热噪还是特定成对过程 | 改边界参数、测谱和跨边界相关，逐个排除替代解释；类比体系与天体霍金观测保持区别 |
| 维度与边界假说 | 同一参考在原版维度往返后，剩余差异能否由已知材料/环境解释 | 有条件的跨维度对照、局部模式谱与天区约束交织，形成边界项的候选；不将MC维度等同数学额外维度 |
| 戈古尔斯弦与后续终局 | 哪些稳定、可复现的剩余关系需要卡玛恩世界的额外公设 | 再定义可加工载体、耦合/供能/稳定条件，进入弦锚与维度工程；星图和研究卡不是消耗性配方材料 |

类视界首个候选只采用明确介质中的波包规则`dx/dt=v_flow(x)±c_group(k,x)`，从实测色散和流速检验某个波段能否逆行。光学移动调制需另给适用的参考系/色散模型，不能把这个式子原样贴在所有光学设备上。透镜研究与类视界研究共享传播和预测方法，但二者不是同一种物理现象，也不要求必须先做完天文才准研究介质。
