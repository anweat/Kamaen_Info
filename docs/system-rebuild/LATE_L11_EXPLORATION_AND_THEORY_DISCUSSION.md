# L1.1讨论：探索、过程推演与时空研究怎样成为后期玩法

2026-09-08。承接用户对L1的补充：后期加入探索，尽量少依赖批量新增的非原版建筑/占位方块；宇观研究应通向量子、黑洞、时空与维度；理论物理应能拆成可操作、可量化的玩法，不能只有不断增加模型复杂度。

这是方向讨论候选，补充[L1研究入口](LATE_L1_DIRECTION_AND_RESEARCH.md)，尚不改写全局科技依赖或冻结新增物品。已有四组实验保留为仪器基础，不能代表后期全部内容。

用户认可后继续展开为L1.2：[材料过程与器件任务](LATE_L12_PROCESS_GAMEPLAY.md)、[错时天区探索任务](LATE_L12_SKY_EXPLORATION.md)。以下保留方向与理论边界；操作、候选差异、数值与恢复流程以两份任务稿为当前细化。

后续用户指出实验与应用连接生硬、两线过早分开，现以[L2连续玩法讨论](LATE_L2_INTEGRATED_PROGRESSION_DISCUSSION.md)重新组织后期：从协同生产、组合遍历与精细操控中逐渐展开物质和世界研究。本文第7节的两项任务保留为可插入内容，不再代表优先开场骨架。

## 1. 重心调整：探索提出问题，理论指导下一次行动

后期的共同循环改为：**发现现象 → 追踪或创造观测条件 → 提出几个过程解释 → 作出具体预测 → 去验证 → 将可用结果变成技术。**

玩家的主要动作可以是寻找方向、选址、携带样品穿过已有维度、布置两个测站、拼一个相互作用过程、改变边界、预测信号在哪儿再次出现。模型与算力支撑这些动作；“换更大的网络并等待训练”只是其中一种工具。

主旨沿三步扩展：早期改变晶体对频率的响应；中期用响应承载控制与信息；后期研究信息通过什么过程、路径和边界传播，以及哪些差异能够被保留、辨认和重建。卡玛恩晶体仍是可加工、可标定的媒介，不把所有自然现象都改名为一种晶体特效。

## 2. 探索以现象、条件和已有世界为载体

| 探索内容 | 玩家实际做什么 | 世界中的表现与产出 |
| --- | --- | --- |
| 原版地形中的观察条件 | 对比山地开阔处、洞穴、海岸或已有基地；改变朝向、遮挡与附近活动 | 地形决定视场、安装和实际传播条件；得到测点、路线、背景与合适工况，不需要每处生成科研遗迹 |
| 天空目录与信号事件 | 按粗方向寻找目标，换波段辨认，跟踪周期或突变，预测下一次可测窗口 | 望远镜/接收界面中的天区、光变、谱线、偏振和波形；可辅以有限天空视觉，不用方块堆出天体 |
| 原版维度间的对照考察 | 把同一标定件、时序记录和测头带到主世界、下界、末地等已可达环境，再返回复测 | 已有通行路线产生调查动机；读取的是本模组明确登记的环境/边界响应，不假定原版已经实现相对论或额外空间维度 |
| 传播异常与边界线索 | 沿测得的梯度或方向缩小范围，做两站/往返/交换仪器对照 | 探头反馈、标注地图与少量粒子/声像表现；现象有稳定生成规则，不能只到隐藏坐标领取一张科研票 |

探索奖励分为：新目标、新条件、新约束、可复测样品/工艺线索。允许同一种研究问题有多个可达目标；关键进度不绑定唯一罕见建筑、一次性掉落或错过即永久消失的事件。

对天空而言，地面移动主要改变遮挡、当地干扰与可用测站条件；不要默认走几百格就造成可观测的遥远天体视差。真正的长基线任务另声明其物理尺度与游戏近似。观测目录不要求生成或加载“星体所在区块”，地面仪器仍按实际运行范围工作。

事件由固定目录/世界规则与游戏时间组织。模板给出可操作的短观察窗口、多个同类对象或后续独立事件；回放旧档案可以验证分析方法，但不能冒充新观测。线索先给方向、频段和适宜条件，避免无提示走遍地图找一个数值异常。

### 建造量怎样控制

默认让新增实体集中在主动部件：探头、激励/参考、接收头、控制与必要接口。原版方块可按登记规则承担支撑、遮挡、围护和可验证的材料作用；普通玻璃不会因被摆成外壳就自动获得精密光学功能。

复用同一底座的测头、载台与模块变体，避免每换一个理论都新增整套机壳。新增专用方块必须有独立作用；扩大装置应实际改变基线、容积、热路径、通量或测量能力。单纯占体积的装饰壳不作为科研等级门槛。外观仍可以由玩家自由建造。

## 3. 理论物理需要几种不同的操作语言

| 操作语言 | 玩家可操作的对象 | 当场可量化的结果 | 后续用途 |
| --- | --- | --- | --- |
| 过程图：从有效过程到费曼图 | 选择入/出态，连接允许顶点，比较通道和近似阶数 | 守恒/选择规则、振幅贡献、概率或谱线预测、失效范围 | 光电转换、散射/制备、材料过程与有限协处理任务 |
| 传播图与时空图 | 发射/接收事件、路径、介质、时钟和边界 | 到达先后、时延、相位、可通信范围、预测新像 | 巡天定位、透镜、有限类视界、跨维度链路 |
| 模式与边界图 | 有限区域、边界条件、作用方向、允许模式 | 频谱、节点位置、模式转换、能量流与稳定窗口 | 滤波/谐振、内部自由度、弦锚定与约束 |
| 相关与编码图 | 已知输入、测量设置、输出分组和边界读写位置 | 单路/联合分布、可区分性、读回误差和有限容量 | 量子统计、信息保存问题、信息膜与维度规则 |

这些是统一工程项目中的不同视图，不另建四套互不相通的软件。理论图的排版不改变真实光路；改物理结构后通过绑定重新取得实验条件。费曼图负责适合它的过程计算，强引力几何和完整量子引力不强行套成同一种拖线画布。

## 4. 把旧费曼设计变成可玩的“过程推演”

[旧科技树§10](../Kamaen_Info_TechTree_Plan.md)已经把外线、传播子、顶点与闭环作为合成语法，这个方向应保留。要调整的是把它们接回有输入、可推演、能验证的过程，不能只检查图连通后给合成评分。

真实费曼图是过程振幅的计算表达；不同图的贡献需要按规则组合，不是探测器已经拍到的粒子实际路线。CERN教学资料对这一点有明确说明：[Flores Castillo，2024，幻灯片23、29、34](https://indico.cern.ch/event/1328015/contributions/5966332/attachments/2909555/5104571/ITWP_9_Aug_2024-FD.pdf)。

| 旧对象 | 玩家能做的事 | 界面与规则 |
| --- | --- | --- |
| 外线 | 指定“准备什么、希望测到什么” | 标能量/频率、动量或对应晶格模式、偏振/态与测量条件；无需首次填写所有量子数 |
| 传播子片 | 给内部传播/响应选择一个有证据的核 | 显示适用条件、可检验谱形和复数贡献；内部线不提供可直接捕获的虚粒子物品 |
| 顶点片 | 选择登记允许的相互作用 | 明确哪种作用改变哪些量；电荷/总能量等按系统检查，晶格/外场/泵浦的交换也需入账 |
| 多图组合 | 比较同一可测结果的不同贡献 | 同一相干结果可组合振幅；可区分末态或失去相干时使用相应概率/密度矩阵规则 |
| 闭环/高阶项 | 检查一个近似为何失效，是否值得增加修正 | 显示当前精度、计算代价和有效范围；高阶项有时增加、有时减少结果，不能作为固定产率加成 |
| 过程蓝图 | 将预测关联到一次现实装置操作 | 输出所需材料状态、激励与读出条件；实际可执行工序另生成，留样试制仍决定产品是否合格 |

初始采用只有少数模式和顶点的有效理论，先可手工检查几张图；进阶才开放更多通道、积分/求和、参数扫描和实际并行计算。共同对称性、符号和计数因子由登记规则处理，不让玩家随意改变一个符号制造无限增强。

### 一个能接回生产的首例：《少掉的频率去了哪里》

1. 玩家在一种已加工晶片中发现较低频的新谱线。先比较“固定差频的能量交换”“固定位置的发射线”“仪器串光”三种解释。
2. 用现有光源、分光与参考做两次激励。教学用能量单位中，第一组入射6、输出4，候选材料激发取走2；换入射8时，差频解释预测输出6，固定发射解释仍预测4。峰位只是观测结果，材料激发的解释还需后续对照。
3. 在过程视图连接入射光、出射光与材料模式，检查总能量关系、对应偏振与选择规则；改变实际样品方向/泵浦条件，再观测某条通道是否按预测减弱。
4. 经过观测约束后，把合格试片用作变频或选择性激励模块，接回探测、材料处理或量子源的前序实验。单次新谱线并不证明非经典光态。

再增加一个有限的相干通道挑战：在明确的同一初态/末态、相干制备与登记测量模板内，两项有效振幅取`A1=0.4`、`A2=0.3*exp(i*phi)`，则`p=|A1+A2|^2=0.25+0.24*cos(phi)`。phi从0变到pi，预测从0.49变到0.01；完全可区分通道的指定例则为0.16+0.09=0.25。

这组数是游戏教学模型，完整模板另包含概率1-p的其他结果，保证归一；它不是任意两条费曼图都满足的实验定律。phi只有在真实结构提供对应控制时才可调。删除理论图中的一项只改变预测，不会删除世界中的过程；要抑制该贡献，必须采取有登记作用的物理操作。

由此产生的玩法是“准备、连过程、守恒检查、选择条件、预测增强或抵消、再试制”。算力用于实际图求值和搜索，不能替玩家凭空证明正确过程。

与物理生产的连接也要可计算：指定输入事件率乘目标通道概率，给出候选转换率；本例每次6→4的事件向材料转移2单位能量，后续按模式保持/弛豫规则进入其他模式或热。它是否累计改变结构，须再满足材料工艺条件。于是选择过程会改变实际输出频段、热负载和加工窗口，图上通过守恒检查本身不会直接发产品。

## 5. 从宇观发现到黑洞、时空与维度的过渡

这里安排两条并行证据链：**宇观观察约束传播与引力；微观制备约束模式与量子统计。** 它们在类视界和信息问题上交汇，随后进入本模组的边界耦合公设。

| 过渡 | 探索/理论问题 | 玩家做什么 | 获得什么能力 |
| --- | --- | --- | --- |
| 光谱到传播 | 两个方向是否来自同一源的不同传播过程 | 跟踪谱线与光变，换仪器排除鬼像，比较有限透镜/介质解释，预测未见图像或到达时间 | 天区关联、传播时延与“错时星图” |
| 传播到强引力 | 哪些观测能约束紧致源，哪些只是当地介质影响 | 比较轨道/谱线、成像或专门探测器取得的波形；把不同观测段分别用于预测与检验 | 强引力源候选、测地与振铃档案；不从单次透镜现象直接宣布黑洞 |
| 强引力到可控类视界 | 指定波包在什么条件下不能逆向越过一段区域 | 在实际流动介质或受控调制的波导中改变传播速度/调制条件，测入射、反射、透射和模式转换 | 有限波段的有效边界实验；反馈隔离、滤波和控制 |
| 类视界到量子信息 | 相似的强度谱是否掩盖不同的输出相关 | 合格制备/计数后测联合统计，比较热背景、受激转换与指定量子模板 | 有条件的模式/统计证据；为后续视界读出提出要求 |
| 信息到边界编码 | 只测外部哪些量足够区分已知输入，哪些信息丢在未测通道 | 有限已知编码、边界读写、错误注入、恢复与容量实验 | 可制造的信息膜与校验方案；继续区分经典记录和未知量子态 |
| 边界到维度 | 额外谱支、传播关系或跨维度差异来自哪里 | 比较材料缺陷/普通腔模/候选边界项，带标定件在已有维度往返；用新边界条件检验预测 | 对戈古尔斯弦残迹和世界特征的约束，再尝试受限耦合与锚定 |

宇观阶段的强引力源可以是仪器中的观测对象，无需先让玩家飞到黑洞旁，也无需在主世界放一个天体级引力方块。引力波观测另需相应低噪、相位/位移测量与实际基线能力，不给普通天线直接增加“引力波模式”。游戏的幅度、长度和时间范围采用声明过的缩放与有限模型，不宣称短小装置达到现实LIGO性能。

类视界的首次问题限定为某个传播场/频带的可达性。在流动介质示例中，检查波包的`dx/dt = v_flow(x) ± c_group(k,x)`及适用色散条件；换频率可能改变是否能逆流越过。光学移动调制要换到相应参考系并登记实际传播模型，不能照抄流体参数。仅有单向阻断不等于形成引力事件视界，更不自动产生霍金辐射。

这一层仍归研究装置，保留旧稿“III型雏形不等于人造视界”。真正可制造的视界、弦锚和维度工程继续由[发展线五](PROGRESSION_05_BOUNDARY_AND_GENESIS.md)的科幻公设及物料/能量规则承接。

### 宇观任务示例：《提前抵达的回声》

粗星录发现两个天区光点具有相近谱线和相似变化。玩家先假设两个独立目标，随后注意到两组变化的先后差；需要搬到更合适的测站、交换读出、改变参考光路，检查本地鬼像和时钟偏差。

确认值得追踪后，把已测位置、谱线与光变交给一个有限传播模型。只凭两条相似曲线不能任意预测第三像；须加入模型所需的几何约束，给出候选位置与时间窗口，再部署观测验证。一次成功的预测形成“错时星图”，也使时空图中的路径有了可测含义。

现实中，Refsdal超新星的再次出现曾由引力透镜模型预测并被观测到，可作为“推演之后去寻找”的任务启发：[NASA，2015](https://science.nasa.gov/missions/hubble/hubble-captures-first-ever-predicted-exploding-star/)。游戏采用不同的有限天区和较短事件窗口，不照搬现实等待时间。

## 6. 猜想如何变成玩法，又不成为一个新的理论名词清单

每项猜想只先回答三件事：与现有解释相比多预测了什么；玩家能改变什么条件；怎样的数据会使它暂时站不住。被排除或只能得到上限的猜想也能形成有效研究成果，不强制所有猜想最终都是真的。

| 理论思想 | 可量化操作候选 | 科学定位与本轮资料 |
| --- | --- | --- |
| 相互作用、叠加与微扰 | 比较少量允许过程、组合振幅、选择测量结果，再增加必要修正 | 适用理论内的计算方法；已核对上述CERN讲义相关页面，游戏只实现有限有效模板 |
| 相对论传播与黑洞振铃 | 从波形一段预测另一段约束，或由几何预测新的时延 | 已有观测研究方法；[LIGO GW150914检验](https://ligo.org/science-summaries/GW150914TestingGR/)说明独立阶段的一致性比较，本次读取合作组说明 |
| 霍金辐射与类引力系统 | 改变有效边界参数，测输出谱与成对相关，并与受激/热背景对照 | 区分引力理论预言、特定介质的类比实验与游戏装置；[de Nova等，Nature 2019](https://www.nature.com/articles/s41586-019-1241-0)，本次读取摘要，不把类比实验当成天体黑洞直接验证 |
| 信息保存与边界描述 | 比较输出单路分布与联合相关，用有限已知输入检查可恢复信息 | [Maldacena 1997](https://arxiv.org/abs/hep-th/9711200)提出特定体系的对偶关系；本次读取摘要。有限编码教学是游戏构造，不声称证明现实世界可由一张通用信息膜完整描述 |
| 额外维度与离散模式 | 寻找候选谱支，比较边界尺寸/条件变化后的谱移关系 | [CERN额外维度说明](https://home.cern/science/physics/extra-dimensions-gravitons-and-tiny-black-holes/)将KK态作为可能检验方向；普通腔模也可有离散谱，发现一串峰不能独立证明额外维度 |
| 卡玛恩边界耦合与戈古尔斯弦 | 原版维度对照、多个材料与独立天区证据共同限制边界项，随后制作锚定载体 | 本模组明确的科幻公设；MC维度、数学额外维度与现实宇宙不能直接画等号 |

信息问题可以先做很直观的任务：两组输出各自都是一半0、一半1，但配对记录可能只出现00/11，也可能四种组合均匀出现。单路外观相同，联合信息不同。先让玩家真的分组、记录、比较，再引入对应统计；这只是经典相关教学，量子纠缠与黑洞信息问题还需各自的态制备和理论条件。

如果后续展开Page曲线、全息关系或纠错，应继续选择有限可运行的体系、明确所计算的熵和输入态。不能把机器输出的Shannon统计值改名，就当作测到了完整量子纠缠熵或解决了黑洞信息问题。

## 7. 本轮建议优先试玩的两条链

第一条是**材料新谱线 → 选择过程解释 → 拼入/出态与顶点 → 预测改变激励后的结果 → 制作实际变频/选择性激励件**。它能直接检验费曼思想的操作是否有趣，并复用中期光电和制程。

第二条是**天区线索 → 实地选择观测条件 → 追踪错时信号 → 传播/时空推演 → 预测并寻找新观测 → 类视界研究需求**。它检验探索、判断与理论是否能够互相推动，并为黑洞/维度留下清晰过渡。

试玩首先看玩家能否依据证据主动选择下一步、能否说清一次预测为什么失败，以及得到的知识能否改善一件实际工具或生产过程。此时再决定更多理论分支与具体物品数量。

保留L1的校准/测量基础，但下一轮不只沿材料表继续填机器：这两条任务应与低温、计数和材料制程同步细化。每段给出新的动作和可探索对象，再据此增加必要设备、算子和理论范围。
