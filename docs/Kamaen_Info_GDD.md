# Kamaen Info - 模组核心设计文档 (GDD)

版本：v0.5 Design Draft  
状态：根据完整科技树、信息系统、非电信息网络与全光计算文档整合后的核心 GDD。  

## 1. 核心定位

Kamaen Info 是一个围绕“物质、能量、信息和熵”展开的 Minecraft NeoForge 科技模组。玩家从圆石的宽频谱中提取基础资源，制造白噪晶种与卡玛恩晶体，再通过向量爆破、共振调谐、信息读取、掺杂晶片与光路工艺、共振信息自动化、全光计算硬件（光控制核、光协处理器、光GPU、光脉冲处理器、光RAM）、世界底噪采样、凝聚态费曼过程、量子光学协处理器、人造视界和黑洞信息设备，最终走向维度创世。

模组不追求在服务端 tick 内真实模拟神经网络、天体级黑洞或完整计算机。核心体验是把宏大的物理与信息概念落到有限、可诊断、可自动化的方块系统中。

主线科技树：

```text
圆石频谱
-> 白噪晶种
-> 卡玛恩晶体
-> 向量爆破与力学合成
-> 共振调谐与信息读取
-> 掺杂晶片与光路工艺
-> 共振信息自动化（频率总线、红石边界触发、光/晶体信号网络）
-> 全光计算硬件（光控制核、光协处理器、光GPU、光脉冲处理器、光RAM）
-> 世界底噪采样
-> 凝聚态费曼过程
-> 量子光学协处理器
-> 人造视界框架
-> 黑洞发电、存储、运算
-> 维度创世
```

## 2. 设计原则

- 前期永不硬卡死：圆石分馏与白噪晶种获取使用确定性进度，随机只影响副产物和品质。
- 宏大概念有限化：爆炸、黑洞、模型、量子光学协处理器和维度创世都以抽象数值、配方、预算和结构评分表现。
- 晶体数据统一：频谱签名、三轴张量、应力、掺杂浓度、噪声指数、相干度和底噪响应贯穿全线。
- 多方块结构缓存：机器只在结构变化时重扫，运行时读取缓存画像和少量动态状态。
- 信息读取有边界：探针只读取已注册 capability、adapter 或 `IKamaenReadable` 数据，不默认反射任意内部字段。
- 电只作为早期供能：FE/电力用于让机器运转、泵浦、加热、刻蚀、退火和驱动执行器，不作为信息传递或计算媒介。信息传递优先使用晶体共振、光路、频率总线、InfoSignal 和红石边界触发。
- 非电信息路线：第 5 阶段组织传感器、频率总线、底噪数据库和共振控制网络；第 6 阶段起进入全光计算，所有计算域信号路径均为光子（激发与湮灭）。五件套为：光控制核（分支/控制/调度，全光 FSM）、光GPU（密集矩阵）、光脉冲处理器（稀疏激活/非线性算子）、光协处理器（数据搬运/互连）、光RAM（短时状态存储）。卡玛恩晶体的 χ⁽²⁾ 非线性特性是全光逻辑的物质基础。详见 `docs/Kamaen_Info_Optical_Computing_Design.md`。
- 模型系统可选拔高：训练、外部 API、自定义模型和量子光学协处理器能优化良率或发现隐藏属性，但主线材料有固定工艺窗口。

## 3. 核心资源与材料

### 3.1 圆石频谱

圆石被定义为包含大量基础物质可能性的宽频谱材料。玩家通过手摇频谱筛、搅拌分馏塔、滤膜和热噪坩埚，把圆石分解为基础粉末、频谱滤渣、均值化圆石和白噪晶种。

代表流程：

```text
圆石 + 水 -> 粗频谱泥浆
粗频谱泥浆 -> 基础粉末 + 频谱滤渣
频谱滤渣 + 热噪坩埚 -> 均值化圆石
均值化圆石 + 频谱滤渣 -> 白噪晶种
```

### 3.2 卡玛恩晶体

卡玛恩晶体是一种各向异性信息材料。它的价值不只是“高级矿物”，而是能记录并调制频谱、张量、应力、掺杂、相干性和底噪响应。

基础属性：

```text
spectrum_signature
axis_tensor
stress
noise_index
coherence
doping_concentration
background_noise_response
```

晶体在不同阶段承担不同角色：

- 力学时代：被向量爆破塑造成导波、抗压、稳谱或偏振晶体。
- 信息时代：作为共振催化器和 InfoSignal 封装介质。
- 光路工艺时代：被掺杂、刻蚀和调谐为导波介质、阈值滤波片、探测结、相位调谐片和激光源前体。
- 凝聚态时代：承载准粒子、拓扑、超导、隧穿和费曼过程。
- 视界时代：参与人造视界约束、全息信息膜和维度级规则编译。

## 4. 合成框架系统

合成框架是贯穿全科技树的研究站和多步骤合成控制平台。它由成型方块、功能方块、传感器、结构材料、作用器、活动机构和接口组成。结构成型后生成 `FrameworkProfile`，用于判断当前工艺精度、可观测参数和可执行流程。

三代框架：

| 等级 | 阶段 | 主要能力 |
| --- | --- | --- |
| I 型力学合成框架 | 爆破、偏振、共振 | 向量、压力、冲击波、应力椭球、晶格对齐 |
| II 型光路工艺框架 | 掺杂、光刻、刻蚀、光学元件 | 频谱、掺杂、导波损耗、阈值、相位精度 |
| III 型视界合成框架 | 凝聚态、底噪、黑洞 | 世界底噪、相干性、准粒子、拓扑、熵流、视界边界 |

摆放位置提供真实参数来源，例如中心距离、轴向排列、对称结构、闭环约束、线路长度差、传感器视线和活动自由度。

## 5. 阶段玩法

### 5.1 圆石初炼

目标是从圆石中稳定提取基础资源，并获得白噪晶种。初级分光镜显示频谱、峰值偏差和白噪潜势。连续处理相同输入会积累谱线污染，需要更换滤膜、调整石材或升级搅拌轴。

### 5.2 向量爆破与力学合成

爆炸室不调用大范围真实爆炸，而是计算 `VectorImpulse`：

```text
direction + strength + waveform_purity + impulse_width
```

理想刚体板、缓冲层、靶座和传感器决定方向匹配、能量窗口、波形纯净度和应力稳定度。玩家通过爆破评分制造粗卡玛恩晶体、导波晶体、抗压晶体、稳谱晶体和偏振晶体。

### 5.3 共振调谐与信息读取

晶体干涉仪读取晶体张量和应力，频谱锁相器把目标物品或机器的固有频谱写入晶体。卡玛恩探针台把可读数据转为统一的 `InfoSignal`：

```text
type
value
frequency_vector
confidence
timestamp
```

`InfoSignal` 可以进入频率总线、红石转换模块、调谐阵列和自动化控制系统。

### 5.4 掺杂晶片与光路工艺

本阶段引入离子注入、退火、光刻、刻蚀和封装，但目的不是制造电气计算机。电力只作为机器供能与泵浦来源；信息路径仍由晶体共振、光路和频率总线承载。P/N 掺杂用于调整折射率、阈值、导波损耗和探测响应，产物主要服务后续全光计算。

代表流程：

```text
稳谱卡玛恩晶体 -> 切片 -> 晶片坯
晶片坯 + 施主掺杂剂 -> N 型卡玛恩晶片
晶片坯 + 受主掺杂剂 -> P 型卡玛恩晶片
N/P 晶片 + 退火 -> 掺杂导波晶片 / 阈值滤波片
掺杂晶片 + 光刻掩膜 + 刻蚀 -> 波导毛坯 / 探测结 / 相位调谐片
稳谱晶体 + 泵浦结构 + 调谐片 -> 单频激光源前体
```

高精度工艺使用相干能。相干能不是更大的 FE，而是由稳谱晶体把普通 FE 整理出的低噪、可锁相工艺能源。在第 6 阶段光计算时代，相干能进一步落实为「维持光路相干所需的能量预算」——即维持 MZI 干涉网络、单频激光源和锁相基准的能耗（消耗模型见 `docs/Kamaen_Info_Optical_Computing_Design.md` 第 7 章）。

### 5.5 共振信息自动化

本阶段不新增电气计算硬件。自动化依赖探针、InfoSignal、频率总线、红石边界触发、共振调谐阵列和底噪数据库。FE/电力只给机器、泵浦、执行器和采样设备供能，不在计算域中承载信息。

信息自动化系统由探针台、频率总线、信号缓存片、信息中心控制器、底噪数据库、红石转换模块和调谐阵列组成。它用于自动化生产、传感器协调、工艺诊断、参数调节和世界底噪采样。

共振信息自动化的核心循环：

```text
探针/传感器读取
-> InfoSignal 频谱化
-> 频率总线组织与缓存
-> 红石边界触发或调谐阵列执行
-> 底噪数据库归档
-> 诊断瓶颈并反向优化晶体、结构和采样节奏
```

系统不做 CPU、GPU、NPU、主板或操作系统模拟。诊断台输出的是信息链路画像，例如读取置信度、频率拥塞、缓存寿命、采样冷却、红石映射延迟、相干能噪声和结构失配。

频率等级：

```text
F1 控制频段：红石转换、触发器、低速 InfoSignal、小型控制器。
F2 数据频段：传感器汇聚、信号缓存、底噪样本、信息中心查询。
F3 调谐频段：多参数工艺调节、调谐阵列、批量采样、光路前置校准。
F4 光频协议：全光计算、光路互连、相干同步。
F5 维度锁相协议：跨维度通信、世界之心、创世编译。
```

诊断台输出多维信息画像，而不是单一等级，包括 `signal_quality`、`route_congestion`、`sample_cooldown`、`cache_life`、`coherence_noise`、`frequency_tier` 和红石映射延迟。

### 5.6 全光计算（五件套全光架构）

本阶段承接第 5 阶段的非电信息网络，将中游计算推进到全光形态——所有计算域信号传递路径均为光子。红石和 FE 仍可存在于边界触发、机器供能和安全停机中，但不承载模型内部信息。设计的物质基础是**卡玛恩晶体的 χ⁽²⁾ 非线性光学特性**，由第 2–3 阶段向量爆破写入的应力张量决定，使光逻辑门、光双稳态腔（寄存器）和光RAM 成为游戏内可实现的元件。

**全光五件套**：

- **光控制核（`photonic_control_core`）**：卡玛恩双稳态晶胞阵列 + 光逻辑门 = 全光有限状态机（FSM）。承担控制、路由、脚本、调度和 I/O，但所有信号路径为光子。晶体品级决定逻辑门保真度——低品级导致随机位翻转。
- **光GPU（`photonic_gpu_unit`）**：MZI 干涉网络做密集矩阵运算（GEMM/FFT/卷积）。不变。
- **光脉冲处理器（`photonic_pulse_processor`）**：卡玛恩饱和吸收体腔 + S 型非线性传输曲线。承担稀疏激活、激活函数近似和低精度时分信号处理。
- **光协处理器（`photonic_coprocessor`）**：纯光数据通路；高带宽搬运/预处理/集群互连。不变（职能不变，内部全光化）。
- **光RAM（`photonic_ram_unit`）**：受激辐射循环腔。短时状态存储（激活缓存和状态寄存器），有寿命上限（20–80 tick），需光控制核定期刷新。

**激发-湮灭基本操作周期**（全光系统的基础操作单元，同时是第 7 阶段费曼图的预习）：
```
激发：光子进入卡玛恩共振腔 → 声子模式激活（信息写入晶体）
传播：声子模式修改探针光子路径 → 逻辑运算发生
湮灭：声子弛豫 → 定向释放光子 → 信息读出
```

**与第 5 阶段的关系**：第 5 阶段不提供电气计算硬件，只提供探针、频率总线、信号缓存、调谐阵列和底噪数据库。进入第 6 阶段后，模型计算由五件套接管，信息路径从“共振/频率总线”升级为“可编译全光结构”。

**与后期的连续性**：
- 第 6 阶段的激发-湮灭周期 = 第 7 阶段费曼蓝图中的吸收/发射顶点（宏观系综 → 单粒子）
- 第 8 阶段量子光学协处理器 = 光逻辑门的量子升级（经典光 → 量子光的连续阶梯）

详见 `docs/Kamaen_Info_Optical_Computing_Design.md`。

### 5.7 世界底噪与宏观信息中心

玩家从读取方块状态推进到读取维度运行时的背景信息场。世界底噪不是单一资源，而是一组可扩展层：

```text
ThermalNoiseLayer
RadiationNoiseLayer
QuantumNoiseLayer
BlockUpdateNoiseLayer
EntityBehaviorLayer
RedstoneNoiseLayer
BiomeNoiseLayer
VoidNoiseLayer
StringResidueLayer
```

信息中心组织探针、传感器、硬件节点、底噪数据库和频率总线，形成长期采样、归档、路由和控制系统。

### 5.8 凝聚态费曼过程

后期材料线使用凝聚态物理概念。费曼图作为准粒子过程的合成语法，而不是高能物理装饰：

```text
外线 = 输入/输出准粒子或场
顶点 = 允许的相互作用
传播子 = 中间态
闭环 = 修正项、噪声、自能
守恒约束 = 电荷、动量、频率、拓扑数、晶格对称性
```

玩家通过底噪样本、准粒子捕获器、费曼过程编译台、低温凝聚腔、拓扑相变炉和隧穿耦合器制造超导卡玛恩环、拓扑绝缘晶体、相变记忆晶体、准粒子滤波器和 4 维电路桥。

本阶段同时产出**单光子源**（量子点 / 参量下转换）和**超导纳米线单光子探测器（SNSPD）**，作为第 5.9 章量子光学协处理器的前置材料。这些产物也可反过来升级第 5.6 章光GPU 的探测器，提升信噪比、降低相干能消耗。

### 5.9 量子光学协处理器

原"量子协处理器"重命名为量子光学协处理器，明确其物理实现路径：**单光子 + 线性光路 + 后选择测量**（玻色采样路线），与第 5.6 章经典光计算形成「经典光 → 量子光」的连续阶梯。它不是万能计算机，只负责微观模拟、路径采样、波函数稳定窗口和凝聚态预测。接收费曼过程蓝图和材料状态，输出合成参数曲线，由 III 型框架执行。

### 5.10 人造视界与黑洞科技

戈古尔斯弦是维度初始边界条件的残留映射。它与世界底噪数据库、凝聚态约束材料和 III 型视界框架合并后，可形成有限多方块内的可控人造视界。

黑洞科技分为三类用途：

- 发电：吸积盘能量抽取、彭罗斯过程模拟、霍金辐射回收、熵流差发电。
- 存储：事件视界信息膜、全息编码、霍金辐射校验、底噪冗余写入。
- 运算：熵梯度搜索、微观态枚举、路径坍缩求解、费曼过程筛选、维度参数冲突检测。

服务端只计算质量评分、稳定度、相干度、熵流、冷却、控制精度、封顶 FE 输出、信息页和运算预算；视觉效果放在客户端表现。

**与第 5.6 光计算的衔接（后期升级）**：本阶段同时引入「长期光RAM / 长期光存储」（基于稀土掺杂晶体受激辐射存储或室温量子点暗态存储，区别于第 6 阶段短时 `photonic_ram_unit`）、「WDM 密集波分复用」（F4 协议升级为单光纤多波长）和「全光网络」（电气退场，控制平面也走光；光逻辑门通过视界材料的非线性光开关在游戏内"黑科技"圆场）。这三件配合视界材料形成本模组的"终极光学层"。

### 5.11 维度创世

最终阶段提取当前维度的信息特征，结合戈古尔斯弦、世界底噪数据库、黑洞运算结果和参数化模板生成新维度。

核心流程：

```text
戈古尔斯弦 + 世界之心频率 + 维度规则候选 -> 创世蓝图
创世蓝图 + 维度参数矩阵 + 视界能量缓存 -> 已编译维度核心
已编译维度核心 + 维度点火环 -> 新维度入口
空间锚 + 已编译维度核心 -> 固定入口锚点
```

维度参数包括地形基底、群系权重、物理规则、资源频谱、实体生成、底噪结构和熵增速率。第一版优先使用预注册模板和固定槽位，避免运行时动态注册灾难。

## 6. 信息系统与模型扩展

信息系统的基础闭环：

```text
世界状态
-> 传感器采样
-> 类型化数据
-> 脚本器预处理/融合
-> 模型外网输入
-> 模型内网调度
-> 参数空间/算子网络推理
-> 输出路由
-> 执行器影响世界
-> 反馈信号回流
```

数据分为 Input、Parameter、State、Activation。loss、reward、metric 和 feedback 不作为特殊第五类数据，而是普通数据节点在训练、评价或调度语境下的角色。

模型系统支持参数晶胞、参数矩阵板、参数晶体簇、参数库、算子、脚本器、触发器、模型内网、模型外网、反馈节点、实验日志和外部 API。它是可选上限玩法，用于优化复杂工艺、自动化实体行为、物流控制、诊断和数据分析。

## 7. 实现边界

- 爆炸室只做向量矩阵和结构评分，不做真实爆炸射线。
- 探针读取统一走 capability、adapter 和白名单接口。
- 信息网络与模型只结算抽象性能画像，不强制运行真实模型、真实电路或真实操作系统。
- 外部 API 可选，必须有延迟、成本、失败、权限、限流、超时和离线 fallback。
- 量子光学协处理器只输出参数窗口与评分，不模拟真实量子态；其物理路径设定为单光子 + 线性光路 + 后选择测量（玻色采样），与第 5.6 光计算阶段形成连续阶梯。
- 全光计算硬件（光控制核/光协处理器/光GPU/光脉冲处理器/光RAM）的相干能、干涉条纹、光路传播等机制只在服务端结算抽象数值（相干度、推理次数、能耗），客户端只渲染光纤亮度、干涉纹理和粒子特效；不做真实光物理模拟。
- 黑洞装置不吸引实体，不模拟真实天体黑洞。
- 维度创世优先使用预注册模板、数据包配置和参数矩阵。
