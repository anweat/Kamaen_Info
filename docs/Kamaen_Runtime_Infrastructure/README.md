# Kamaen Runtime Infrastructure

状态：历史草案 / 暂缓实现。

本目录保留早期计算基础设施玩法草案，包括芯片设计、主板设计、机柜与集群、传感器数据、模型运行时、网络通信、任务调度和 MVP 路线。当前主线已改为“电只供能，信息走晶体共振、频率总线、光路和全光计算”，因此本目录暂不作为当前开发计划依据。

当前开发请优先参考 `../Kamaen_Info_Core_Gameplay_Development_Plan.md`、`../Kamaen_Info_GDD.md` 和 `../Kamaen_Info_TechTree_Plan.md`。

## 阶段口径

项目总 GDD 的早期 MVP 仍是材料与信息读取主线；本目录的 MVP 指“计算基础设施线”的第一条最小链路。

计算基础设施 MVP 只保留本地地址和本地服务解析的兼容接口。多 DNS 是网络子系统第一版必做内容，但排在基础设施 MVP 跑通之后进入第二阶段。

## 文件

- `Complete_Path.md`：完整确定路径，记录本轮已经确认的系统边界、层级、核心对象和玩法关系。
- `MVP_Path.md`：第一阶段最小可实现路线，单独列出要先做什么、暂不做什么和验收目标。

## 核心一句话

玩家设计硬件来承载任务，设计数据格式来连接任务，设计网络来移动任务和数据，再用传感器、模型、诊断和调度反过来优化硬件、工艺与系统结构。
